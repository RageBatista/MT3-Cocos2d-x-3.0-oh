## 一、工具概述

### 1.1 Nuclear 工具集

Nuclear 引擎提供以下工具：

| 工具名称 | 用途 | 平台 |
|----------|------|------|
| EffectEditor | 特效编辑器 | Windows |
| ParticleSystemEditor | 粒子系统编辑器 | Windows |
| SpineAnimationTool | Spine 动画工具 | Windows |
| XAPAnimationTool | XAP 动画工具 | Windows |
| TexturePacker | 纹理打包工具 | Windows |
| ResourceViewer | 资源查看器 | Windows |

### 1.2 工具安装

所有 Nuclear 工具都位于 `tools/nuclear/` 目录下。

## 二、EffectEditor 使用指南

### 2.1 工具简介

EffectEditor 是 Nuclear 引擎的特效编辑器，用于创建和编辑游戏特效。

### 2.2 启动工具

```bash
# Windows
tools/nuclear/EffectEditor.exe
```

### 2.3 界面介绍

EffectEditor 界面分为以下几个区域：

- **菜单栏**: 文件、编辑、视图、帮助
- **工具栏**: 常用操作快捷按钮
- **资源面板**: 显示特效资源列表
- **属性面板**: 显示当前选中对象的属性
- **预览窗口**: 实时预览特效效果
- **时间轴**: 显示特效时间线

### 2.4 创建新特效

1. 点击菜单 `File -> New`
2. 选择特效类型（粒子特效、骨骼特效、网格特效）
3. 设置特效参数
4. 点击 `OK` 创建

### 2.5 编辑特效

#### 添加粒子系统

1. 在资源面板右键，选择 `Add Particle System`
2. 设置粒子系统参数：
   - 粒子数量
   - 粒子生命周期
   - 粒子速度
   - 粒子颜色
   - 粒子纹理

#### 添加骨骼动画

1. 在资源面板右键，选择 `Add Spine Animation`
2. 选择 Spine 动画文件
3. 设置动画参数

#### 添加网格特效

1. 在资源面板右键，选择 `Add Mesh Effect`
2. 选择网格模型
3. 设置材质和着色器

### 2.6 保存特效

1. 点击菜单 `File -> Save`
2. 选择保存路径
3. 输入特效名称
4. 点击 `Save`

### 2.7 导出特效

1. 点击菜单 `File -> Export`
2. 选择导出格式（.effect, .xap）
3. 选择导出路径
4. 点击 `Export`

### 2.8 调试技巧

#### 实时预览

- 在预览窗口中实时查看特效效果
- 使用时间轴控制特效播放进度

#### 性能分析

- 点击菜单 `View -> Performance`
- 查看特效性能指标（粒子数量、Draw Call、FPS）

#### 调试模式

- 点击菜单 `Debug -> Enable Debug`
- 显示特效调试信息（边界框、粒子轨迹）

## 三、ParticleSystemEditor 使用指南

### 3.1 工具简介

ParticleSystemEditor 是 Nuclear 引擎的粒子系统编辑器，用于创建和编辑粒子特效。

### 3.2 启动工具

```bash
# Windows
tools/nuclear/ParticleSystemEditor.exe
```

### 3.3 界面介绍

ParticleSystemEditor 界面分为以下几个区域：

- **菜单栏**: 文件、编辑、视图、帮助
- **工具栏**: 常用操作快捷按钮
- **粒子面板**: 显示粒子系统列表
- **属性面板**: 显示当前选中粒子的属性
- **预览窗口**: 实时预览粒子效果
- **曲线编辑器**: 编辑粒子属性曲线

### 3.4 创建粒子系统

1. 点击菜单 `File -> New`
2. 设置粒子系统参数：
   - 发射器类型（点、线、面、体积）
   - 粒子数量
   - 粒子生命周期
   - 粒子速度
   - 粒子大小
   - 粒子颜色
   - 粒子纹理
3. 点击 `OK` 创建

### 3.5 编辑粒子属性

#### 发射器属性

- **发射器类型**: 点、线、面、体积
- **发射速率**: 每秒发射的粒子数量
- **发射角度**: 粒子发射角度范围
- **发射速度**: 粒子初始速度范围

#### 粒子属性

- **生命周期**: 粒子存活时间
- **大小**: 粒子大小范围
- **颜色**: 粒子颜色（支持颜色渐变）
- **速度**: 粒子速度范围
- **加速度**: 粒子加速度
- **旋转**: 粒子旋转角度和速度
- **纹理**: 粒子纹理

#### 物理属性

- **重力**: 粒子受重力影响
- **风力**: 粒子受风力影响
- **碰撞**: 粒子碰撞检测

### 3.6 使用曲线编辑器

曲线编辑器用于编辑粒子属性随时间变化的曲线。

1. 选择要编辑的属性
2. 在曲线编辑器中添加关键点
3. 调整关键点的值和时间
4. 设置关键点的插值方式（线性、贝塞尔、阶梯）

### 3.7 保存粒子系统

1. 点击菜单 `File -> Save`
2. 选择保存路径
3. 输入粒子系统名称
4. 点击 `Save`

### 3.8 导出粒子系统

1. 点击菜单 `File -> Export`
2. 选择导出格式（.particle, .effect）
3. 选择导出路径
4. 点击 `Export`

### 4.2 启动工具

```bash
# Windows
tools/nuclear/SpineAnimationTool.exe
```

### 4.3 界面介绍

SpineAnimationTool 界面分为以下几个区域：

- **菜单栏**: 文件、编辑、视图、帮助
- **工具栏**: 常用操作快捷按钮
- **骨骼面板**: 显示骨骼列表

- **预览窗口**: 实时预览动画效果

   - 旋转
   - 缩放
   - IK 约束

#### 编辑动画

1. 在动画面板中选择动画
2. 在时间轴中编辑关键帧
3. 设置关键帧的骨骼属性

## 六、TexturePacker 使用指南

### 6.1 工具简介

TexturePacker 是 Nuclear 引擎的纹理打包工具，用于将多个小纹理打包成一个大纹理。

### 6.2 启动工具

```bash
# Windows
tools/nuclear/TexturePacker.exe
```

### 6.3 界面介绍

TexturePacker 界面分为以下几个区域：

- **菜单栏**: 文件、编辑、视图、帮助
- **工具栏**: 常用操作快捷按钮
- **资源面板**: 显示待打包的纹理列表
- **设置面板**: 显示打包设置
- **预览窗口**: 预览打包后的纹理

### 6.4 添加纹理

1. 点击菜单 `File -> Add Textures`
2. 选择要打包的纹理文件
3. 点击 `Open` 添加

### 6.5 设置打包参数

在设置面板中设置以下参数：

- **输出格式**: PNG, PVR, ETC1
- **纹理尺寸**: 1024x1024, 2048x2048, 4096x4096
- **边距**: 纹理之间的边距
- **内边距**: 纹理内部的内边距
- **旋转**: 是否允许旋转纹理
- **裁剪**: 是否裁剪透明区域

### 6.6 打包纹理

1. 点击菜单 `File -> Pack`
2. 选择输出路径
3. 点击 `Pack` 开始打包

### 6.7 导出纹理

1. 点击菜单 `File -> Export`
2. 选择导出格式（.png, .plist）
3. 选择导出路径
4. 点击 `Export`

## 九、常见问题

### 9.1 工具无法启动

**问题**: 工具无法启动

**原因**: 缺少依赖库

**解决方案**:
1. 检查是否安装了 Visual C++ Redistributable
2. 检查 DirectX 是否安装
3. 检查显卡驱动是否更新

### 9.2 特效导出失败

**问题**: 特效导出失败

**原因**: 特效资源路径错误

**解决方案**:
1. 检查特效资源路径是否正确
2. 检查纹理文件是否存在
3. 检查文件权限

### 9.3 动画播放异常

**问题**: 动画播放异常

**原因**: 动画文件损坏

**解决方案**:
1. 重新导入动画文件
2. 检查动画文件格式
3. 使用 ResourceViewer 检查动画文件
