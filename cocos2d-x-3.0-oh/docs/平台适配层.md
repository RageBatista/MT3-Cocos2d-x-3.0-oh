# cocos2d-x 3.0-oh 平台适配层

## 1. 概述

**文件位置**: `cocos/2d/platform/`, `cocos/platform/`

平台适配层为跨平台提供统一的接口抽象，封装不同操作系统的文件系统、图像处理、线程、设备信息等差异。

### 1.1 平台定义

**文件**: `cocos/base/CCPlatformConfig.h`

```cpp
// 平台标识
```

## 2. CCFileUtils - 文件系统工具

**文件**: `cocos/2d/platform/CCFileUtils.h`

```cpp
class FileUtils {
public:
    static FileUtils* getInstance();
    static void destroyInstance();
    
    // 路径管理
    virtual void addSearchPath(const std::string& path, bool front = false);
    virtual void setSearchPaths(const std::vector<std::string>& searchPaths);
    virtual const std::vector<std::string>& getSearchPaths() const;
    virtual std::string fullPathForFilename(const std::string& filename) const;
    virtual std::string fullPathFromRelativeFile(const std::string& filename,
                                                 const std::string& relativeFile) const;
    
    // 文件读取
    virtual std::string getStringFromFile(const std::string& filename);
    virtual Data getDataFromFile(const std::string& filename);
    virtual unsigned char* getFileData(const std::string& filename,
                                       const char* mode, ssize_t* size);
    virtual unsigned char* getFileDataFromZip(const std::string& zipFilePath,
                                              const std::string& filename,
                                              ssize_t* size);
    
    // 文件操作
    virtual bool isFileExist(const std::string& filename) const;
    virtual bool isAbsolutePath(const std::string& path) const;
    virtual bool createDirectory(const std::string& dirPath);
    virtual bool removeFile(const std::string& filepath);
    virtual bool removeDirectory(const std::string& dirPath);
    virtual bool renameFile(const std::string& path, const std::string& oldname,
                            const std::string& name);
    virtual bool renameFile(const std::string& oldfullpath, const std::string& newfullpath);
    
    // 目录信息
    virtual long getFileSize(const std::string& filepath);
    virtual std::string getFileExtension(const std::string& filePath) const;
    virtual std::string getWritablePath() const;
    
    // 资源路径
    virtual void setDefaultResourceRootPath(const std::string& path);
    virtual void setPopupNotify(bool notify);
    
    // 平台特定
    CC_DEPRECATED_ATTRIBUTE static void setResourceDirectory(const std::string& dir);
    std::string getSuitableFOpen(const std::string& filenameUtf8) const;
};
```

## 8. OpenHarmony 平台特定实现

**文件位置**: `cocos/2d/platform/ohos/`

OHOS 平台提供以下特定实现：
- `CCGL.h` - OHOS OpenGL ES 绑定
- `CCStdC.h` - 标准C库适配
- 文件系统的 OHOS 特定路径处理
- `CCUserDefault-ohos.cpp` - OHOS持久化存储

## 9. 使用示例

### 9.1 文件读取
```cpp
// 获取文件工具单例
auto fileUtils = FileUtils::getInstance();

// 添加搜索路径
fileUtils->addSearchPath("res/");

// 获取文件完整路径
std::string fullPath = fileUtils->fullPathForFilename("image.png");

// 读取文件内容
std::string content = fileUtils->getStringFromFile("config.json");
```
