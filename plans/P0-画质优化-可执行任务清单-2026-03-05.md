## 2. 目标与成功标准

### 2.1 P0 目标

1. 打通画质参数链路：配置 -> `EngineParameter` -> 渲染器。
2. 让夜景 `ColorBalance` 在当前 Cocos2d 渲染后端真实生效。
3. iOS 端实现 MSAA 0/2/4 配置化与失败降级。
4. 形成可灰度发布、可一键回滚的上线包。

### 2.2 发布门禁（必须满足）

1. 视觉门禁：白天外景、夜晚外景、地下宫殿三场景 A/B 对比通过。
2. 稳定门禁：0 个阻断级崩溃、0 个黑屏。
3. 性能门禁：Win32 平均 FPS 回退 < 8%，iOS 平均 FPS 回退 < 10%。
4. 回滚门禁：关闭新开关后，行为回归基线（允许轻微统计误差）。

## 3. 范围与边界

### 3.1 本期范围（In Scope）

1. `engine/renderer`：`StateManager` 与 `Cocos2dRenderer` 特效状态链路补齐。
2. `client/FireClient/Application/Framework`：`EngineParameter` 显式赋值链路补齐。
3. `engine/world`：夜景 effect/param 调用一致性修复。
4. `client/FireClient/FireClient`：iOS EAGLView MSAA 配置化。
5. `cocos2d-2.0-rc2-x-2.0.1/cocos2dx/shaders`：动态注册或加载 `ColorBalance` shader。

### 3.2 非本期范围（Out of Scope）

1. 升级 VS 工具链（v120 约束保持不变）。
2. 升级 Cocos2d-x 主版本。
3. FireClient.lib ABI 改造。
4. 大规模资源重制（仅做必要验证）。

## 9. 配置开关与回滚策略

| 开关名 | 作用 | 默认策略 | 回滚策略 |
|------|------|------|------|
| `QualityP0Enable` | 总开关 | 灰度开启 | 关闭后回归基线路径 |
| `NightShaderEnable` | 夜景 shader 开关 | 灰度开启 | 关闭后禁用新夜景分支 |
| `MSAAEnable` | iOS MSAA 开关 | 机型分档 | 置 0 强制关闭 |

回滚执行顺序：
1. 先关闭 `MSAAEnable`，确认 iOS 稳定性恢复。
2. 再关闭 `NightShaderEnable`，确认视觉回到旧路径。
3. 最后关闭 `QualityP0Enable`，回退全部 P0 行为。
