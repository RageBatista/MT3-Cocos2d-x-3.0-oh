### 2.3 测试详情

#### evaluateDim 测试组（8 个）

测试 [`evaluateDim()`](../src/shared/services/dim-evaluator.ts:4) 对 7 种 DimNode 类型的求值：

```typescript
const mockCtx: DimEvaluationContext = {
  parentWidth: 800,
  parentHeight: 600,
  widgetDimensions: new Map([
    ['titlebar', { x: 0, y: 0, w: 800, h: 30 }],
  ]),
  imageDimensions: new Map([
    ['TaharezLook/ButtonNormal', { width: 256, height: 64 }],
  ]),
  fontMetrics: new Map([
    ['default', { lineSpacing: 16, baseline: 12, horzExtent: 100 }],
  ]),
};
```

| 测试用例 | 输入 | 期望输出 | 验证点 |
|---------|------|---------|--------|
| AbsoluteDim | `{ type: 'AbsoluteDim', value: 42 }` | `42` | 直接返回值 |
| UnifiedDim | `{ scale: 0.5, offset: 10, dimType: 'Width' }` | `410` | `0.5 * 800 + 10` |
| ImageDim | `{ imageset: 'TaharezLook', image: 'ButtonNormal', dimType: 'Width' }` | `256` | 从 imageDimensions 查找 |
| WidgetDim | `{ widget: 'titlebar', dimType: 'Height' }` | `30` | 从 widgetDimensions 查找 |
| FontDim | `{ font: 'default', metric: 'LineSpacing', padding: 4 }` | `20` | `16 + 4` |
| DimOperator Add | `Add(AbsoluteDim(10), AbsoluteDim(20))` | `30` | 递归求值 + 加法 |
| DimOperator Subtract | `Subtract(UnifiedDim(1,0,Width), AbsoluteDim(20))` | `780` | `800 - 20` |
| PropertyDim | `{ name: 'SomeProp' }` | `0` | 未支持返回 0 |

#### evaluateArea 测试组（2 个）

测试 [`evaluateArea()`](../src/shared/services/dim-evaluator.ts:116) 的两种 Area 模式：

| 测试用例 | Area 模式 | 期望 PixelRect |
|---------|----------|---------------|
| Left+Width | left=10, top=20, width=100, height=50 | `{x:10, y:20, w:100, h:50}` |
| Left+Right | left=10, top=20, right=110, bottom=70 | `{x:10, y:20, w:100, h:50}` |

#### pixelToDim 测试组（3 个）

测试 [`pixelToDim()`](../src/shared/services/dim-evaluator.ts:151) 的三种生成策略：

| 测试用例 | 策略 | 输入 | 期望 |
|---------|------|------|------|
| absolute | `'absolute'` | 100px | `{ type: 'AbsoluteDim', value: 100 }` |
| unified-relative | `'unified-relative'` | 400px / 800px parent | `{ scale: ≈0.5, offset: 0 }` |
| hybrid | `'hybrid'` | 400px / 800px parent | `{ scale: ≈0.5 }` |

#### formatDimExpr 测试组（3 个）

测试 [`formatDimExpr()`](../src/shared/services/dim-evaluator.ts:187) 的格式化输出：

| 测试用例 | 验证点 |
|---------|--------|
| AbsoluteDim | 输出包含数值 `"42"` |
| UnifiedDim | 输出包含 scale、offset、dimType |
| DimOperator | 输出包含运算符和左右操作数 |

describe('computeWriteback', () => {
  it('preserves UnifiedDim structure on move', () => {
    const originalArea = {
      left: { type: 'UnifiedDim', scale: 0.1, offset: 0, dimType: 'LeftEdge' },
      top: { type: 'AbsoluteDim', value: 0 },
      right: { type: 'UnifiedDim', scale: 0.9, offset: 0, dimType: 'RightEdge' },

  });
});

## 5. 质量保障措施

### 5.1 类型检查

```bash
npm run typecheck    # tsc --noEmit
```

TypeScript 严格模式提供编译时保障，覆盖所有 `src/` 下的 `.ts` 和 `.tsx` 文件。

### 5.2 代码检查

```bash
npm run lint         # eslint src --ext .ts,.tsx
```

### 5.3 持续集成建议

建议在 CI 中添加以下步骤：

```yaml
# .github/workflows/test.yml
steps:
  - run: npm ci
  - run: npm run typecheck
  - run: npm run lint
  - run: npm test
```
