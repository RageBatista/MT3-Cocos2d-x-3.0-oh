## 1. 数据流总览

LnF Editor 的核心数据流遵循 **单向数据流** 模式：

```
XML 文件 → 主进程解析 → IPC 传输 → Zustand Store → React 渲染 → 用户交互 → Store 更新 → IPC → 主进程序列化 → XML 文件
```

### 2.3 Area/Dim 解析

[`parseArea()`](../src/main/services/parser.ts:330) 将 XML `<Area>` 元素解析为 [`AreaDef`](../src/shared/model/types.ts:66)：

```xml
<Area>
  <Dim type="LeftEdge"><AbsoluteDim value="10" /></Dim>
  <Dim type="TopEdge"><AbsoluteDim value="20" /></Dim>
  <Dim type="Width"><UnifiedDim scale="0.5" offset="0" type="Width" /></Dim>
  <Dim type="Height"><AbsoluteDim value="50" /></Dim>
</Area>
```

解析为：

```typescript
{
  left:  { type: 'AbsoluteDim', value: 10 },
  top:   { type: 'AbsoluteDim', value: 20 },
  width: { type: 'UnifiedDim', scale: 0.5, offset: 0, dimType: 'Width' },
  height: { type: 'AbsoluteDim', value: 50 },
}
```

[`parseDimNode()`](../src/main/services/parser.ts:356) 支持 7 种 Dim 类型：

| Dim 类型 | XML 元素 | 解析结果 |
|---------|---------|---------|
| AbsoluteDim | `<AbsoluteDim value="N" />` | `{ type: 'AbsoluteDim', value: N }` |
| UnifiedDim | `<UnifiedDim scale="S" offset="O" type="T" />` | `{ type: 'UnifiedDim', scale, offset, dimType }` |
| ImageDim | `<ImageDim imageset="..." image="..." dimension="T" />` | `{ type: 'ImageDim', imageset, image, dimType }` |
| WidgetDim | `<WidgetDim widget="..." dimension="T" />` | `{ type: 'WidgetDim', widget, dimType }` |
| FontDim | `<FontDim font="..." metric="..." padding="N" />` | `{ type: 'FontDim', font, metric, padding }` |
| PropertyDim | `<PropertyDim name="..." />` | `{ type: 'PropertyDim', name }` |
| DimOperator | `<DimOperator op="Add">...</DimOperator>` | `{ type: 'DimOperator', op, left, right }` |

## 3. 状态管理

### 3.1 Store 结构

[`useEditorStore`](../src/renderer/stores/editor-store.ts:87) 使用 Zustand + Immer 中间件：

```typescript
interface EditorStore {
  files: {
    activeFilePath: string | null;          // 当前活动文件
    openedFiles: Map<string, FileState>;    // 所有打开的文件
  };
  selection: {
    widgetLookName: string | null;          // 当前选中的 WidgetLook
    selectedNodeIds: string[];              // 选中的图层节点 ID
    hoveredNodeId: string | null;           // 悬停的节点 ID
  };
  canvas: CanvasViewport;                   // 视口（offset, scale, grid...）
  preview: {
    activeStates: string[];                 // 激活的预览状态
    parentWidth: number;                    // 模拟父容器宽度（默认 1136）
    parentHeight: number;                   // 模拟父容器高度（默认 640）
  };
  history: {
    undoStack: HistoryEntry[];              // 撤销栈
    redoStack: HistoryEntry[];              // 重做栈
  };
  dirty: boolean;                           // 未保存标记
}
```

### 3.2 FileState 结构

每个打开的文件对应一个 [`FileState`](../src/renderer/stores/editor-store.ts:15)：

```typescript
interface FileState {
  filePath: string;
  fileIndex: FileIndex | null;
  loadedWidgetLooks: Map<string, WidgetLook>;  // 按名称索引
  dirty: boolean;
  imagesets: Map<string, ImagesetResource>;     // 已加载的 imageset
  schemePath: string | null;                    // 关联的 scheme 文件
}
```

### 4.2 Dim 求值链路

[`evaluateArea()`](../src/shared/services/dim-evaluator.ts:116) 将 `AreaDef` 转换为 `PixelRect`：

```typescript
// AreaDef:
{
  left:  { type: 'UnifiedDim', scale: 0.1, offset: 5, dimType: 'LeftEdge' },
  top:   { type: 'AbsoluteDim', value: 0 },
  width: { type: 'UnifiedDim', scale: 0.8, offset: 0, dimType: 'Width' },
  height: { type: 'UnifiedDim', scale: 1.0, offset: 0, dimType: 'Height' },
}

// DimEvaluationContext:
{ parentWidth: 1136, parentHeight: 640, ... }

// evaluateArea() 结果:
{ x: 118, y: 0, w: 909, h: 640 }
```

[`evaluateDim()`](../src/shared/services/dim-evaluator.ts:4) 的递归求值：

```
evaluateDim(UnifiedDim{scale:0.1, offset:5, dimType:LeftEdge}, ctx)
  → resolveDimBase('LeftEdge', ctx) → ctx.parentWidth = 1136
  → 0.1 * 1136 + 5 = 118.6 → Math.round → 119
```

### 5.1 拖拽流程

```

  │
  ├── 构建 DimEvaluationContext

  ├── hitTestDragMode(mouseX, mouseY, area, viewport) [interaction.ts:4]
  │   ├── 屏幕坐标 → 画布坐标: sx = (mouseX - offsetX) / scale

  │   │   [dim-writeback.ts:45]
  │   │   │
  │   │   ├── 判断 Area 模式（usesWidth/usesHeight/usesRight/usesBottom）
  │   │   │
  │   │   ├── 对每个受影响的边：
  │   │   │   └── writebackDim(originalDim, newPixelValue, dimType, parentSize)
  │   │   │       [dim-writeback.ts:141]
  │   │   │       │

  │   │   │       ├── UnifiedDim → 保持 scale，调整 offset
  │   │   │       │   （offset 超过 parentSize 50% 时重新计算 scale/offset）
  │   │   │       ├── ImageDim/WidgetDim/FontDim/PropertyDim → 降级为 pixelToDim()
```

### 5.2 回写策略示例

原始 UnifiedDim：

```typescript
{ type: 'UnifiedDim', scale: 0.5, offset: 0, dimType: 'Width' }
// parentWidth = 1136 → 当前值 = 568
```

拖拽后新宽度 = 700px：

```typescript
// 策略：保持 scale，调整 offset
newOffset = 700 - 0.5 * 1136 = 132
// offset = 132 < parentSize * 0.5 = 568 → 可接受
结果: { type: 'UnifiedDim', scale: 0.5, offset: 132, dimType: 'Width' }
```

如果新宽度 = 50px（offset 过大）：

```typescript
newOffset = 50 - 0.5 * 1136 = -518
// |offset| = 518 > 568 * 0.5 = 284 → 重新计算
scale = round(50/1136 * 1000) / 1000 = 0.044
offset = round(50 - 0.044 * 1136) = round(50.016) = 50
结果: { type: 'UnifiedDim', scale: 0.044, offset: 50, dimType: 'Width' }
```
