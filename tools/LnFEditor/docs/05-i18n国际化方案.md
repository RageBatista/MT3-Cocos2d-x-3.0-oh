## 1. 架构概述

LnF Editor 实现了一套轻量级 i18n 系统，位于 [`src/renderer/services/i18n.ts`](../src/renderer/services/i18n.ts)（548 行），不依赖第三方 i18n 库。

核心组件：

| 组件 | 类型 | 职责 |
|------|------|------|
| `I18nManager` | 类 | 语言管理、翻译、监听器通知 |
| `useTranslation()` | React Hook | 绑定翻译函数到组件，语言切换时自动重渲染 |
| `zhCN` / `enUS` | 常量对象 | 语言包（内联定义） |
| `MESSAGE_MAPS` | 常量映射 | 语言包注册表 |

## 2. I18nManager 类

[`I18nManager`](../src/renderer/services/i18n.ts:454) 是 i18n 系统的核心：

```typescript
class I18nManager {
  private currentLocale: Locale = 'zh-CN';          // 当前语言，默认中文
  private listeners: Set<() => void> = new Set();    // 语言变化监听器

  getLocale(): Locale;                               // 获取当前语言
  setLocale(locale: Locale): void;                   // 切换语言（触发监听器）
  t(key: string, vars?: Record<string, string | number>): string;  // 翻译
  onChange(listener: () => void): () => void;         // 注册监听器，返回取消函数
  getAvailableLocales(): Locale[];                   // 获取可用语言列表
}
```

### 2.1 翻译流程

[`t()`](../src/renderer/services/i18n.ts:473) 方法的翻译链路：

```
t('toolbar.openTitle')
  │
  ├── resolveKeyPath(zhCN, 'toolbar.openTitle') [行501]
  │   → 'toolbar'.split('.') → ['toolbar', 'openTitle']
  │   → zhCN['toolbar']['openTitle'] → '打开 LookNFeel 文件 (Ctrl+O)'
  │
  └── interpolate('打开 LookNFeel 文件 (Ctrl+O)', vars) [行514]
      → 无 vars → 直接返回
```

**回退机制**：如果当前语言包中找不到键，回退到英文（[行 478–481](../src/renderer/services/i18n.ts:478)）；如果英文也没有，返回键本身。

### 2.2 插值变量

[`interpolate()`](../src/renderer/services/i18n.ts:514) 支持 `{variableName}` 占位符：

```typescript
// 语言包定义
'status.zoom': '缩放: {percent}%'

// 调用
t('status.zoom', { percent: 150 })
// → '缩放: 150%'

// 实现
result = result.replace(new RegExp(`\\{${key}\\}`, 'g'), String(val));
```

### 2.3 键路径解析

[`resolveKeyPath()`](../src/renderer/services/i18n.ts:501) 支持嵌套点路径：

```typescript
resolveKeyPath(zhCN, 'search.target.all')
// → zhCN['search']['target']['all'] → '全部'
```

## 3. useTranslation Hook

[`useTranslation()`](../src/renderer/services/i18n.ts:530) 是 React 集成点：

```typescript
export function useTranslation(): {
  t: (key: string, vars?: Record<string, string | number>) => string;
  locale: Locale;
  setLocale: (locale: Locale) => void;
}
```

**实现原理**（[行 535–547](../src/renderer/services/i18n.ts:535)）：

```typescript
function useTranslation() {
  const [, forceUpdate] = React.useState(0);

  React.useEffect(() => {
    const unsubscribe = i18n.onChange(() => forceUpdate(c => c + 1));
    return unsubscribe;
  }, []);

  return {
    t: (key, vars) => i18n.t(key, vars),
    locale: i18n.getLocale(),
    setLocale: (locale) => i18n.setLocale(locale),
  };
}
```

当 `i18n.setLocale()` 被调用时，所有使用 `useTranslation()` 的组件都会通过 `forceUpdate` 触发重渲染。

## 4. 语言包结构

### 4.1 支持的语言

| Locale | 常量 | 说明 |
|--------|------|------|
| `zh-CN` | [`zhCN`](../src/renderer/services/i18n.ts:23) | 简体中文（默认） |
| `en-US` | [`enUS`](../src/renderer/services/i18n.ts:234) | 英文 |

### 4.2 翻译域

语言包按功能域组织，共 14 个顶级域：

| 域 | 键数量 | 说明 | 示例键 |
|----|--------|------|--------|
| `app` | 2 | 应用全局 | `app.title`, `app.loading` |
| `toolbar` | 8 | 工具栏 | `toolbar.open`, `toolbar.save`, `toolbar.openTitle` |
| `menu` | 14 | 菜单 | `menu.file`, `menu.edit`, `menu.open`, `menu.save` |
| `panel` | 12 | 面板标题 | `panel.navigator`, `panel.properties`, `panel.layers` |
| `canvas` | 5 | 画布 | `canvas.noFile`, `canvas.dragMove`, `canvas.dragResize` |
| `property` | 23 | 属性编辑 | `property.name`, `property.area`, `property.colour` |
| `dim` | 22 | Dim 编辑器 | `dim.absolute`, `dim.unified`, `dim.switchTo` |
| `template` | 8 | 模板 | `template.button`, `template.createFromTemplate` |
| `search` | 9 | 搜索替换 | `search.title`, `search.query`, `search.results` |
| `contextMenu` | 11 | 右键菜单 | `contextMenu.undo`, `contextMenu.delete` |
| `status` | 8 | 状态栏 | `status.ready`, `status.modified`, `status.zoom` |
| `imageBrowser` | 8 | 图像浏览器 | `imageBrowser.title`, `imageBrowser.stats` |
| `virtualList` | 4 | 虚拟列表 | `virtualList.search`, `virtualList.itemCount` |
| `error` | 5 | 错误消息 | `error.fileOpen`, `error.parse` |

## 5. 集成方式

### 5.1 在组件中使用

```typescript
import { useTranslation } from '../services/i18n';

function MyComponent() {
  const { t, locale, setLocale } = useTranslation();
  
  return (
    <div>
      <h1>{t('app.title')}</h1>
      <p>{t('status.zoom', { percent: 100 })}</p>
      <button onClick={() => setLocale('en-US')}>English</button>
      <button onClick={() => setLocale('zh-CN')}>中文</button>
    </div>
  );
}
```

### 5.2 在非组件代码中使用

```typescript
import { i18n } from './i18n';

// 直接使用全局实例
const title = i18n.t('app.title');
i18n.setLocale('en-US');
```

### 5.3 系统语言检测

应用启动时通过 IPC 获取系统语言偏好：

```typescript
// 主进程 [index.ts:364]
ipcMain.handle('get-locale', async () => {
  return app.getLocale();  // 返回如 'zh-CN', 'en-US'
});
```

渲染进程可在初始化时调用 `window.lnfAPI.getLocale()` 获取系统语言并设置默认语言。

## 6. 添加新翻译的步骤

### 6.1 添加新键

1. 在 [`zhCN`](../src/renderer/services/i18n.ts:23) 对象中添加中文翻译
2. 在 [`enUS`](../src/renderer/services/i18n.ts:234) 对象中添加对应英文翻译
3. 在组件中通过 `t('domain.key')` 使用

### 6.2 添加新语言

1. 在 [`Locale`](../src/renderer/services/i18n.ts:15) 类型中添加新语言代码
2. 创建新的语言包对象（参照 `zhCN` 结构）
3. 在 [`MESSAGE_MAPS`](../src/renderer/services/i18n.ts:447) 中注册
4. 在语言切换 UI 中添加选项

### 6.3 添加新翻译域

1. 在 `zhCN` 和 `enUS` 中添加新的顶级键对象
2. 确保两个语言包的结构完全一致
3. 在使用该域的组件中通过 `t('newDomain.key')` 引用

## 7. 设计特点

| 特点 | 说明 |
|------|------|
| 零依赖 | 不使用 i18next 等第三方库，减少打包体积 |
| 类型安全 | `Locale` 类型约束可用语言 |
| 运行时切换 | 通过监听器模式实现语言热切换 |
| 回退机制 | 中文 → 英文 → 键本身 |
| 插值支持 | `{variable}` 占位符语法 |
| 嵌套键路径 | 点分隔的键路径解析 |
