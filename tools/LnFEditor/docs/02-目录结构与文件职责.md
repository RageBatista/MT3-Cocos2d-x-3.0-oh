## 1. 顶层目录结构

```
LnFEditor/
├── electron.vite.config.ts     # 三目标构建配置
├── package.json                # 依赖声明 + electron-builder 配置
├── tsconfig.json               # TypeScript 编译选项
├── resources/                  # 应用图标资源
│   └── icon.ico
├── src/                        # 源码根目录
│   ├── main/                   # Electron 主进程
│   ├── preload/                # Preload 桥接层
│   ├── renderer/               # 渲染进程（React SPA）
│   └── shared/                 # 共享类型与服务
├── dist/                       # 构建输出（gitignore，构建时自动生成）
└── release/                    # electron-builder 输出（gitignore，打包时自动生成）
```

## 3. Preload 层 (`src/preload/`)

### 3.1 [`index.ts`](../src/preload/index.ts)（22 行）

**职责**：通过 `contextBridge` 安全暴露 IPC 方法到渲染进程。

暴露 `window.lnfAPI` 对象，包含 15 个方法：

```typescript
const api = {
  openLookNFeel, loadWidgetLook, openScheme,
  readImageBase64, saveLookNFeel, scanImagesets,
  loadImagesets, discoverResources, syncSchemeMappings,
  validateReferences, savePng, getAppVersion, getLocale,
};
contextBridge.exposeInMainWorld('lnfAPI', api);
```

同时导出 `LnfAPI` 类型供渲染进程类型检查使用（[`export type LnfAPI = typeof api`](../src/preload/index.ts:21)）。
