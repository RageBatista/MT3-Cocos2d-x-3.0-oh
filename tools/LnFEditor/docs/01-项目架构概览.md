## 1. 项目定位

LnF Editor 是一款基于 Electron + React 的桌面应用，用于**可视化编辑 CEGUI 0.7.1 的 LookNFeel XML 文件**。它面向 MT3 项目（梦幻西游 MG 版本）的 UI 开发人员，提供所见即所得的控件外观编辑能力。

核心能力：

- 打开/解析 `.looknfeel` XML 文件
- 可视化预览 WidgetLook 控件外观
- 拖拽交互编辑组件位置和尺寸
- Dim 表达式 AST 可视化编辑
- Imageset 纹理资源加载与预览
- XML 序列化保存（含格式保留）
- 搜索替换、引用验证、PNG 导出
- 插件系统扩展

### 2.1 安全边界

- **主进程** 拥有完整 Node.js 访问权限（文件系统、sharp、dialog）
- **渲染进程** 通过 [`contextIsolation: true`](../src/main/index.ts:20) 隔离，不直接访问 Node.js
- **Preload 层** 通过 [`contextBridge.exposeInMainWorld('lnfAPI', api)`](../src/preload/index.ts:19) 暴露受限 API
- 渲染进程只能通过 `window.lnfAPI` 的 15 个方法与主进程通信

### 3.2 数据传输格式

IPC 通信统一使用 JSON 序列化：

```
渲染进程                              主进程
────────                              ─────
window.lnfAPI.openLookNFeel()  ──→   ipcMain.handle('open-looknfeel')
                               ←──   return { filePath, fileIndex, widgetLooks }
                                      // widgetLooks: WidgetLook[] (JSON)
```

**大对象传输策略**：
- WidgetLook 列表通过 JSON 整体传输（[`parseLookNFeelFile()`](../src/main/services/parser.ts:104) 返回完整数组）
- 大文件支持按索引延迟加载（[`load-widgetlook`](../src/main/index.ts:67) + [`WidgetLookIndex`](../src/shared/model/types.ts:199)）
- 图像通过 Base64 Data URL 传输（[`read-image-base64`](../src/main/index.ts:108)）

## 6. 关键设计决策

### 6.1 大文件延迟加载

通过 [`buildFileIndex()`](../src/main/services/parser.ts:40) 预扫描文件构建 `WidgetLookIndex[]`，每个条目记录行号范围和字节偏移。渲染进程可按需通过 `load-widgetlook` IPC 单独加载某个 WidgetLook，避免一次性解析包含数百个控件的大文件。

### 6.2 Dim 表达式 AST

CEGUI 的 Dim 表达式是递归嵌套结构（7 种节点类型 + 运算符），编辑器将其解析为 [`DimNode`](../src/shared/model/types.ts:51) 递归联合类型，支持：

- 可视化编辑（[`DimEditor.tsx`](../src/renderer/components/DimEditor.tsx)）
- 运行时求值（[`evaluateDim()`](../src/shared/services/dim-evaluator.ts:4)）
- 拖拽回写（[`dim-writeback.ts`](../src/renderer/services/dim-writeback.ts)）

### 6.3 LRU 纹理缓存

[`TextureCacheManager`](../src/renderer/services/texture-cache.ts:27) 实现 LRU 缓存策略：

- 最大容量 200 个子图像（[`TEXTURE_CACHE_MAX_SIZE`](../src/shared/constants/index.ts:70)）
- 图集加载后预裁剪所有子图像到独立 Canvas
- 通过 `SubImageCache` 接口与渲染引擎解耦

### 6.4 历史记录

Undo/Redo 采用快照模式（[`HistoryEntry`](../src/shared/model/editor.ts:68)），最大深度 50（[`HISTORY_MAX_DEPTH`](../src/shared/constants/index.ts:73)）。每次修改前将当前 WidgetLook 完整序列化为 JSON 快照。
