## 项目信息

### 项目概述

ExcelParse2 是一个基于 WPF 的数据生成工具，用于将 Excel/CSV/TXT 格式的策划配置数据转换为游戏客户端和服务器端所需的数据文件和代码。

### 核心功能

- 支持三种输入格式：Excel (.xlsx, .xlsm)、CSV (GB2312编码)、TXT (CSV格式)
- 支持多种输出格式：客户端 Bin/Xml/C++/Lua/PKG，服务器 Xml/Java
- 一键生成客户端和服务器数据
- 支持单表导出模式
- 支持历史 Bean 选择
- 生成详细日志文件

### 技术栈

- **开发环境**: Visual Studio 2013 (v120)
- **框架**: .NET Framework 4.5, WPF
- **依赖**: CSTools, NPOI (Excel 读取)
- **语言**: C#
