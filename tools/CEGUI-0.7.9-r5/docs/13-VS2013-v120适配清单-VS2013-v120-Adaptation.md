# VS2013 v120 适配清单与改造步骤（CEGUI 0.7.9-r5）

本文描述如何将 `CEGUI-0.7.9-r5` 的 VS2010 工程 **适配到 VS2013 + v120**，用于与 MT3 统一工具链。

---

## 1. 适配目标

- **目标编译器**：MSVC 18.0（VS2013）
- **目标 Toolset**：`v120`
- **保持功能**：最小改动、可复现、与现有依赖一致

---

## 2. 风险与前置检查

### 2.1 工程现状

- `projects/premake/CEGUI.sln` 为 **VS2010 格式**（Format 11.00）
- `CEGUIOgreRenderer.vcxproj` 指定 `<PlatformToolset>v100</PlatformToolset>`
- 其余工程 **未显式设置 Toolset**（默认跟随 VS）

### 2.2 依赖版本风险

若要使用 v120，必须保证以下依赖 **也由 v120 编译**（否则链接/运行时不稳定）：

- `freetype`, `pcre`, `expat`, `zlib`, `libpng`, `jpeg`
- `lua`, `toluapp`, `SILLY`, `tinyxml`, `xerces-c`
- `d3dx9` / `dxerr`（来自 DXSDK，通常可与 v120 共存）
- `OgreMain`（如启用 Ogre 渲染器）

> 当前 `dependencies/` 中的库 **未标注 toolset**，建议用 `dumpbin /headers` 验证。

---

## 3. 适配策略（推荐）

### 方案 A：最小侵入适配（推荐）

1. **不重新运行 premake**（避免重写 config.h/工程）
2. 用 VS2013 打开 `CEGUI.sln`，允许升级
3. 批量设置 `PlatformToolset = v120`
4. 按需禁用 Ogre / DevIL / FreeImage / Corona 模块

### 方案 B：改造 config.lua + 重新生成

1. 修改 `projects/premake/config.lua`
2. 运行 premake 生成工程
3. 用 VS2013 升级并设置 v120

> 方案 B 会覆盖 `cegui/include/config.h`，请确认默认模块配置是否匹配。

---

## 4. 具体改造步骤（方案 A）

### Step 1：备份工程文件

```powershell
Copy-Item tools\CEGUI-0.7.9-r5\projects\premake -Destination tools\CEGUI-0.7.9-r5\projects\premake.bak -Recurse
```

### Step 2：打开 VS2013 并升级

- 打开 `projects/premake/CEGUI.sln`
- VS2013 会提示升级项目，选择 **升级**

### Step 3：设置 PlatformToolset 为 v120

在 VS2013 中：

1. 右键解决方案 → `Configuration Manager`
2. 对所有项目 & 配置，进入 `Project Properties`
3. `Configuration Properties → General → Platform Toolset` 设为 `v120`

**注意**：`CEGUIOgreRenderer.vcxproj` 明确写死 v100，需手工改为 v120。

### Step 4：禁用未准备的模块（可选）

若未提供 DevIL/FreeImage/Corona/Ogre 依赖，建议：

- 在 VS 中卸载对应项目
- 或先不编译这些项目

## 5. 依赖库 toolset 校验方法

```powershell
# 示例：检查 freetype.lib toolset
cmd /c "dumpbin /headers tools\CEGUI-0.7.9-r5\dependencies\lib\dynamic\freetype.lib | findstr \"linker version\""
```

期望结果：

- v120 对应 **linker version 12.00**

## 6. v120 构建命令示例

```powershell
cmd /c "call %VS120COMNTOOLS%..\\..\\VC\\vcvarsall.bat x86 && msbuild tools\\CEGUI-0.7.9-r5\\projects\\premake\\CEGUI.sln /m /p:Configuration=Release /p:Platform=Win32"
```

## 7. 常见问题

### 7.1 v100 工具集缺失

- 如果工程仍引用 v100，VS2013 会提示无法编译。
- 解决：确保项目属性中 `PlatformToolset` 全部改为 v120。

### 7.2 Ogre 编译失败

- 需要 Ogre SDK (v120 编译) + Boost
- 如果没有，建议禁用 Ogre 渲染器模块

### 7.3 DevIL/FreeImage/Corona 依赖配置
