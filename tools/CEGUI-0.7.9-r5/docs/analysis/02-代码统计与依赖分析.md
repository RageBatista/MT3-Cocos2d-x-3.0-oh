## 1. 项目概述

CEGUI (Crazy Eddie's GUI System) 是一个跨平台的 GUI 库，专为游戏和图形应用程序设计。0.7.9 版本是 0.7.x 系列的最后一个稳定版本。

### 4.2 内部模块依赖关系

#### 4.2.1 核心依赖层次

```
Level 0 (最底层):
├── CEGUIBase.h          # 基础定义、宏
├── CEGUIConfig.h        # 配置
├── CEGUIVersion.h       # 版本
└── CEGUIVector.h        # 基础数据结构
    ├── CEGUIRect.h
    ├── CEGUISize.h
    ├── CEGUIcolour.h
    └── CEGUIUDim.h

Level 1 (基础组件):
├── CEGUIString.h        # 字符串封装
├── CEGUIRefCounted.h     # 引用计数
├── CEGUIIteratorBase.h   # 迭代器
└── CEGUIProperty.h      # 属性系统

Level 2 (事件系统):
├── CEGUIEvent.h         # 事件定义
├── CEGUIEventArgs.h     # 事件参数
├── CEGUIEventSet.h      # 事件集合
├── CEGUIBoundSlot.h     # 事件槽
└── CEGUISubscriberSlot.h # 订阅槽

Level 3 (资源系统):
├── CEGUIResourceProvider.h  # 资源提供者接口
├── CEGUIImageset.h          # 图像集
├── CEGUIFont.h              # 字体
├── CEGUIScheme.h            # GUI 方案
├── CEGUITexture.h           # 纹理
└── CEGUIImage.h             # 图像

Level 4 (窗口系统):
├── CEGUIWindow.h        # 窗口基类
├── CEGUIWindowManager.h # 窗口管理器
└── CEGUIWindowFactory.h # 窗口工厂

Level 5 (渲染系统):
├── CEGUIRenderer.h           # 渲染器接口
├── CEGUIRenderingSurface.h   # 渲染表面
├── CEGUIRenderQueue.h        # 渲染队列
└── CEGUIRenderEffect.h       # 渲染效果

Level 6 (最高层 - 系统核心):
└── CEGUISystem.h        # 系统核心（依赖所有以上层级）
```

### 4.3 编译时依赖

#### 4.3.1 头文件依赖

```cpp
// 典型的头文件包含顺序

// 1. CEGUI 配置和版本
#include "CEGUIConfig.h"
#include "CEGUIVersion.h"

// 2. 基础数据结构
#include "CEGUIVector.h"
#include "CEGUIRect.h"
#include "CEGUIcolour.h"

// 3. 字符串和异常
#include "CEGUIString.h"
#include "CEGUIExceptions.h"

// 4. 核心接口
#include "CEGUIWindow.h"
#include "CEGUIEventSet.h"

// 5. 具体实现
#include "elements/CEGUIPushButton.h"
#include "RendererModules/OpenGL/CEGUIOpenGLRenderer.h"
```

#### 4.3.2 库文件链接顺序

```
链接顺序 (重要):
1. CEGUIBase[_d].lib
2. CEGUIOpenGLRenderer[_d].lib
3. OpenGL32.lib
4. GLU32.lib
5. 依赖库:
   ├── freetype[_d].lib
   ├── pcre[_d].lib
   ├── expat[_d].lib
   ├── SILLY[_d].lib / DevIL[_d].lib
   └── lua[_d].lib (可选)
```
