## 💡 使用建议

- **文档维护**：阅读 `02-文档维护指南` 了解文档版本管理、审查流程、自动化验证和反馈渠道。
- **项目概览**：从 `03-项目综述` 开始了解项目背景和架构。
- **环境准备**：按照 `04-环境准备` → `05-依赖清单` 配置开发环境。
- **编译构建**：参考 `06-编译构建流程` → `07-从零构建` → `08-产物校验` 完成编译。
- **快速入门**：阅读 `09-快速入门` 快速上手 CEGUI。
- **深入学习**：学习 `10-核心概念` 理解 CEGUI 内部机制。
- **Cocos2D 集成**：参考 `11-Cocos2DRenderer集成` 在 Cocos2D 中使用 CEGUI。
- **高级配置**：查看 `12-模块级依赖清单` 和 `13-VS2013-v120适配清单` 进行高级配置。
- **需要记录复现**：使用 `07-从零构建` 中的附录A：构建日志模板。
- **需要快速检查**：使用 `08-产物校验` 中的自动校验脚本。
- **遇到问题**：查看 `07-从零构建` 中的第6章：常见问题。
- **需要清理重建**：查看 `07-从零构建` 中的第5章：清理与重建。
