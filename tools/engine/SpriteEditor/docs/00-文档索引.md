## 事实基线

- 该工程是 **Win32 单文档 MFC 工具**，不是 MDI。
- 运行时渲染由 [CSpriteEditorView::OnTimer](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorView.cpp#L2746-L2762) 驱动，不再由 `OnIdle()` 主导。
- 核心数据与业务入口集中在 [CSpriteEditorDoc](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.h#L67-L558)。
- 打包主算法位于 [SpritePackCoreService](file:///e:/MT3/tools/engine/SpriteEditor/SpritePackCoreService.cpp#L181-L575)，采用 MaxRects 风格装箱。
- PNG 导出位于 [PngExporter](file:///e:/MT3/tools/engine/SpriteEditor/PngExporter.cpp#L1-L1403)，包含尺寸/内存上限保护、GDI+ 高质量缩放和 Alpha 边缘抗锯齿。
- `DirtyFlags` 与 `CommandManager` 已接入主线，但旧状态字段仍部分保留，属于“新旧并存”而非“全量迁移完成”。
- `EquipmentLayer.h/.cpp` 与 `BatchProcessor.h` 已存在，但不是当前主流程的唯一实现入口。
