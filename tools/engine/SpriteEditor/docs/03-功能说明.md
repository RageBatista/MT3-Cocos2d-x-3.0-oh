## 2. 界面布局

```text
┌──────────────────────────────────────────────────────────┐
│ 菜单栏 / 工具栏                                          │
├──────────────┬──────────────────────────┬───────────────┤
│ 左：动画操作  │ 中上：主渲染视图          │ 右：动作控制   │
│              │ 中下：装备选择             │               │
├──────────────┴──────────────────────────┴───────────────┤
│ 状态栏                                                   │
└──────────────────────────────────────────────────────────┘
```

### 左侧：CAnimationOpView

- 模型列表与动作列表
- 打开/新建/删除/重命名动画
- 音量与频率滑块

### 中上：CSpriteEditorView

- 主渲染区
- 鼠标拖拽调整、缩放、选择、轨迹控制点编辑
- 调试叠加层、边界框、十字线、像素列表等可视化

### 中下：CEquipSelectView

- 12 层装备显示、切换、删除、重载、染色
- 装备下拉选择
- 染色模式开关、资源操作按钮

### 右侧：CActionControlView

- 播放控制、方向、帧序、缩放、偏移、边界框设置
- 应用到全方向 / 全帧等批量操作

## 3. 动画与模型操作

### 3.1 打开动画

支持两类入口：

- 菜单/按钮方式调用 [CSpriteEditorDoc::OpenAnimationFile](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L2996-L)
- 主窗口拖拽 `.ani` 文件，由 [CMainFrame::OnDropFiles](file:///e:/MT3/tools/engine/SpriteEditor/MainFrm.cpp#L54-L131) 处理

拖拽限制：

- 仅接受 `.ani`
- 更适合 `client\resource\res` 下资源路径
- 会尝试做 native 路径 → PFS 路径转换

### 3.2 模型/动作维护

已实现的常见操作：

- 新建模型
- 删除模型
- 查看模型信息
- 打开动作
- 新建动作
- 删除动作
- 动作重命名
- 动画组管理
- 动画引用管理

相关对话框：

- `AnimationInfoDlg`
- `AnimationGroupManagerDlg`
- `AnimationRefManagerDlg`
- `RenameActionDlg`
- `ModelInfoDlg`

## 4. 播放与编辑功能

### 4.1 播放控制

播放状态由 `sPlayState` 维护，支持：

- 自动播放
- 循环播放
- 单次播放
- 上一帧 / 下一帧 / 第一帧 / 最后一帧
- 指定方向播放

渲染触发并非 `OnIdle()` 主循环，而是 [CSpriteEditorView::OnTimer](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorView.cpp#L2746-L2755)。

### 4.2 偏移与位置调整

支持：

- 模型偏移微调
- 基点显示与编辑
- 边界框显示与编辑
- 标题位置调整
- 特效位置调整
- 坐骑高度调整
- 轨迹控制点调整

快捷调整：

- `Ctrl + Arrow` 会调用 [CSpriteEditorDoc::AdjustOffset](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L2959-L2967)

### 4.3 轨迹叠加层

若启用轨迹叠加，主视图会绘制二次贝塞尔曲线：

- 计算函数见 [EvalQuadraticBezier](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorView.cpp#L139-L149)
- 可通过 `Alt + 鼠标拖拽` 调整控制点

## 5. 装备层功能

### 5.1 层数与操作类型

当前界面按 12 层工作，支持：

- 显示/隐藏
- 新建/选择装备
- 重载装备

- 调整颜色

虽然工程中存在 `EquipmentLayer.h/.cpp`，但主流程仍围绕 `m_CurEquips` 与 `CEquipSelectView` 工作；当前 UI 已采用统一消息分发函数，而不是旧式每层一套分散处理器。

装备面板可调用：

- [ChangeDye](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorView.cpp#L163-L176) 对应的文档方法
- `HSLAdjustDlg` 打开颜色调整对话框

## 6. PNG 导出

### 6.1 导出模式

已实现三个入口：

- [OnExportPngSequence](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L1325-L1328)
- [OnExportPngSequenceHd2](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L1330-L1333)
- [OnExportPngSequenceHd4](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L1335-L1338)

对应输出缩放：

- 标准 1x
- HD x2
- HD x4

### 6.2 导出特性

[PngExporter](file:///e:/MT3/tools/engine/SpriteEditor/PngExporter.cpp) 具备：

- 输出目录自动创建
- metadata 导出
- 多方向/多帧/多 region 逐项导出
- GDI+ 高质量缩放
- Alpha 边缘平滑
- 图像尺寸与总内存保护

### 6.3 导出限制

- 仅在 `.ani` 图片资源已完整加载后允许导出
- 宽高超过内部阈值或内存计算超限会失败

## 7. 打包功能

### 7.1 手动打包

[CSpriteEditorDoc::OnPack](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L1878-L) 用于交互式打包：

- 选择源目录
- 读取图片序列
- 推导方向与时间等参数
- 调用打包核心服务生成图集和新 ANI

### 7.2 `pack.ini` 批处理

[CSpriteEditorDoc::OnToolPack](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L1753-L) 会优先检查 `pack.ini`：

- 若文件存在，可选择是否使用批处理
- 由 [PackFromIni](file:///e:/MT3/tools/engine/SpriteEditor/SpriteEditorDoc.cpp#L2849-L) 解析 section/key
- 使用 Win32 `GetPrivateProfile*` 系列读取配置

### 7.3 打包核心算法

`SpritePackCoreService` 实际完成：

- 碎图装箱
- 图集尺寸计算
- 图集渲染输出
- ANI 中贴图引用重写

适用场景：

- 图片序列转 `.ani`
- 旧动画重新整理为图集形式
- 批量离线资源构建

## 9. 当前限制与注意事项

- 仅面向 Win32/MFC 工具链，不具备跨平台 GUI 实现
- `DirtyFlags`、`CommandManager`、`EquipmentLayerManager` 并非全模块统一收敛完成态
- `pack.ini` 使用 Win32 INI 读取，依赖 section/key 名称约定
- 部分错误处理仍以 `AfxMessageBox` 或 `MessageBoxW` 为主，不适合无界面完全自动化
- 仍存在历史兼容逻辑与新结构并存的情况
