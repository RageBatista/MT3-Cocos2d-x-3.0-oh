## 1. 数据流向总览

### 1.1 主循环数据流

```
WM_TIMER (33ms)
  │
  ▼
CEffectEditorView::OnTimer()
  ├── CEffectEditorDoc::Tick(dt)
  │     ├── [Effect模式] m_pToolsEffect->Update(dt)
  │     │     └── GEffect::Update(dt)
  │     │           └── 遍历各 Clip → EffectClip::Update(dt)
  │     │                 ├── 位置关键帧插值
  │     │                 ├── 缩放关键帧插值
  │     │                 ├── 旋转关键帧插值
  │     │                 └── 颜色关键帧插值
  │     ├── [Sebind模式] m_ToolsSebind.Tick(m_pSprite, dt)
  │     │     └── Sebind::Tick(dir, action, frame, pos)
  │     │           └── Effect::Tick → 各 Clip 更新
  │     └── m_pSprite->Tick(dt)
  │           └── 根据时间推进帧号
  │
  └── CEffectEditorView::RenderEffect()
        ├── CEffectEditorDoc::Draw(m_pRenderer)
        │     ├── [Effect模式]
        │     │     ├── m_pToolsEffect->RenderBack()   ← 后层 Clip
        │     │     ├── m_pSprite->Render()            ← 角色 (可选)
        │     │     └── m_pToolsEffect->RenderFront()  ← 前层 Clip
        │     ├── [Sebind模式]
        │     │     ├── m_ToolsSebind.GetEffect()->RenderBack()
        │     │     ├── m_pSprite->Render()
        │     │     └── m_ToolsSebind.GetEffect()->RenderFront()
        │     ├── 绘制 Clip 中心十字 (m_bDrawClipCenter)
        │     └── INotify::OnRender() → CTimeBarView/CRoleProp 刷新
        ├── 绘制背景 (纯色/图片)
        ├── 绘制包围盒 (TS_BOUNDS_RECT 工具)
        └── 绘制选中 Clip 控制框
```

## 3. 撤销/重做数据流

### 3.1 操作执行流程

```
用户操作 (如修改 Clip 位置)
  │
  ▼
CEffectEditorDoc::ModifyAdjPosForSelectedClip(adjPoint)
  │
  ├── 创建 CActionSetClipPos
  │     ├── BEFORE_ACTION: 记录当前所有选中 Clip 的位置
  │     └── AFTER_ACTION: 记录修改后的位置
  │
  ├── m_pActionList->DoOneAction(pAction)
  │     ├── 截断 m_Iter 之后的 redo 历史 (释放 CAction)
  │     ├── 入队 m_ActionList
  │     ├── 超出 MAX_LENGTH(50) 则淘汰队首
  │     └── SetModifiedFlag()
  │
  └── 执行实际修改: SetLocation(adjPoint)
```

### 3.2 撤销流程

```
用户按 Ctrl+Z
  │
  ▼
CEffectEditorDoc::OnEditUndo()
  │
  ▼
CActionList::UndoOneAction()
  │
  ├── 检查 CanUndo()
  ├── m_Iter 回退
  └── TodoAction((*m_Iter))
        └── 根据 CAction::eActionType 分发:
              ├── ACTION_MODIFY_START_END_FRAME → ModifyStartEndFrame(BEFORE)
              ├── ACTION_MODIFY_LAYER → ModifyLayer(BEFORE)
              ├── ACTION_SET_CLIP_POS → SetLocation(BEFORE)
              ├── ACTION_SET_CLIPS_DOUBLE_KEYS → 还原关键帧 (BEFORE)
              └── ... (共 15 种操作类型)
```

### 3.3 重做流程

```
用户按 Ctrl+Y
  │
  ▼
CActionList::RedoOneAction()
  │
  ├── 检查 CanRedo()
  ├── m_Iter 前进
  └── TodoAction((*m_Iter))
        └── 根据 CAction::eActionType 分发:
              └── 与撤销相同，但使用 AFTER_ACTION 索引
```

## 4. 关键算法逻辑

### 4.1 旋转计算算法 (IEffectClipControl::GetRotationRadian)

**源文件**: `EffectEditorView.cpp`  
**触发条件**: `TS_FRAME_ROTATE` 工具激活，鼠标拖动时

```
算法步骤:
1. 计算鼠标位置相对于 Clip 中心的向量 V = mousePos - clipCenter
2. 计算上一帧鼠标位置相对于 Clip 中心的向量 U = lastMousePos - clipCenter
3. 计算叉积 cross = U.x * V.y - U.y * V.x
   - cross > 0: 逆时针旋转
   - cross < 0: 顺时针旋转
4. 计算点积 dot = U.x * V.x + U.y * V.y
5. 计算角度 angle = atan2(|cross|, dot)
6. 根据叉积符号调整方向:
   - cross >= 0: angle 保持正值 (逆时针)
   - cross < 0: angle 取负 (顺时针)
7. 累加到当前旋转角度: m_RotationAngle += angle
8. 返回 m_RotationAngle
```

**数学原理**: 利用二维向量的叉积判断旋转方向，点积和叉积的 `atan2` 计算精确旋转角度。

### 4.2 缩放计算算法 (IEffectClipControl::GetScale)

**源文件**: `EffectEditorView.cpp`  
**触发条件**: `TS_FRAME_SIZE` 工具激活，鼠标拖动缩放控制点时

```
算法步骤:
1. 确定命中的控制点 (8 个: 四角 + 四边中点)
2. 计算对角控制点作为锚点 anchorPt
3. 计算鼠标到锚点的向量 V_mouse = mousePos - anchorPt
4. 计算原始控制点到锚点的向量 V_orig = ctrlPt - anchorPt
5. 如果 Clip 有旋转:
   a. 计算旋转矩阵 M = RotationMatrix(-clipRotation)
   b. 将 V_mouse 旋转回未旋转空间: V_mouse' = M * V_mouse
   c. 将 V_orig 旋转回未旋转空间: V_orig' = M * V_orig
6. 计算缩放比例:
   - 水平缩放: scaleX = V_mouse'.x / V_orig'.x
   - 垂直缩放: scaleY = V_mouse'.y / V_orig'.y
7. 对角控制点: scaleX 和 scaleY 均有效
   水平边中点: 仅 scaleX 有效，scaleY = 原值
   垂直边中点: 仅 scaleY 有效，scaleX = 原值
8. 钳位: scale 值不能为 0 或负数
9. 返回 (scaleX, scaleY)
```

**数学原理**: 通过逆旋转矩阵将当前鼠标向量变换回 Clip 的局部坐标系，再与原始向量比较计算缩放比例。

### 4.3 贝塞尔曲线采样算法

**源文件**: `BezierControl.cpp`  
**核心方法**: `SampleLine()` / `SampleAllLines()`

```
算法步骤 (对每条曲线):
1. 获取切线点列表 tangentPoints
2. 如果点数 < 2，跳过
3. 计算总弧长:
   a. 遍历相邻切线点对 (tp[i], tp[i+1])
   b. 对每段计算贝塞尔曲线弧长:
      - 使用 3 次贝塞尔公式:
        B(t) = (1-t)³P0 + 3(1-t)²tP1 + 3(1-t)t²P2 + t³P3
      - P0 = tp[i].pos, P1 = tp[i].nextCtrlPt
      - P2 = tp[i+1].prevCtrlPt, P3 = tp[i+1].pos
      - 将 t ∈ [0,1] 细分为 100 段
      - 累加相邻采样点距离
4. 均匀采样:
   a. 目标采样数 = m_nSampleCount
   b. 采样间距 = totalArcLength / (sampleCount - 1)
   c. 遍历曲线段，按弧长均匀采样
   d. 每个采样点记录: {pos, u(参数), id}
5. 存入 m_SamplePoints[lineID]
```

**数学原理**: 三次贝塞尔曲线参数化表示，通过弧长参数化实现均匀采样。

### 4.4 关键帧插值算法

**源文件**: `ToolsEffect.cpp` (`Update` 方法)  
**触发条件**: 非播放态时手动更新 Clip 属性

```
算法步骤 (对每个 Clip):
1. 获取当前帧号 currentFrame
2. 位置插值 (KT_POS):
   a. 查找当前帧两侧的关键帧 (prev, next)
   b. 如果无关键帧，使用默认位置
   c. 如果只有一侧有关键帧，使用该关键帧值
   d. 线性插值: t = (frame - prevFrame) / (nextFrame - prevFrame)
      value = prevValue + t * (nextValue - prevValue)
3. 缩放插值 (KT_SCALE): 同位置插值
4. 旋转插值 (KT_ROTATION): 同位置插值 (单值)
5. 透明度插值 (KT_ALPHA): 同位置插值 (单值)
6. 颜色插值 (KT_COLOR):
   a. 同位置插值，但各通道 (R/G/B/A) 独立插值
   b. 使用 ReverseColor() 转换存储格式后插值
```

### 4.5 Sprite 帧推进算法

**源文件**: `Sprite.cpp` (`Tick` 方法)

```
算法步骤:
1. 累加时间: m_nCurTime += deltaTime
2. 如果有动作 (m_pAction != NULL):
   a. 获取动作帧数 frameCount = m_pAction->GetFrameCount()
   b. 获取动作总时间 totalTime = m_pAction->GetTotalTime()
   c. 如果 totalTime > 0:
      - 计算浮点帧: m_fCurFrame = (float)m_nCurTime / totalTime * frameCount
      - 取整帧号: m_nCurFrame = (int)m_fCurFrame
      - 循环: m_nCurFrame %= frameCount
3. 如果无动作:
   - 帧号保持不变
```

### 4.6 包围盒控制点命中检测

**源文件**: `EffectEditorView.cpp`  
**触发条件**: `TS_BOUNDS_RECT` 工具激活

```
算法步骤:
1. 计算包围盒 8 个控制点坐标:
   - 四角: (left,top), (right,top), (right,bottom), (left,bottom)
   - 四边中点: 各边中点
2. 坐标变换:
   - 逻辑坐标 → 客户端坐标 (考虑背景偏移和缩放)
3. 遍历 8 个控制点:
   - 计算鼠标位置到控制点的距离
   - 如果距离 < 阈值 (5 像素)，命中该控制点
4. 返回命中的控制点索引 (0-7)，未命中返回 -1
```

### 4.7 特效层渲染混合算法

**源文件**: `Sprite.cpp` (`Render` 方法)

```
算法步骤 (对每个组件):
1. 获取组件动画帧图片 pImage
2. 检查该层是否为特效层 (m_FlagEffectLayer 位掩码)
3. 如果是特效层:
   a. 设置混合模式: XPTEXBM_ADDITIVE_ALPHA
   b. 计算正弦波 alpha:
      - alpha = (sin(m_nCurTime * 0.005f) + 1.0f) * 0.5f
      - 应用到顶点色
   c. 图片缩放: scale = XP_EFFECT_SCALE (1.2)
4. 如果不是特效层:
   a. 使用默认混合模式
5. 根据方向处理镜像:
   - 方向 0/5/6/7: 特效层优先渲染 (先于普通层)
   - 方向 1/2/3/4: 正常渲染顺序
6. 渲染图片: pRenderer->Render(pImage, ...)
```

## 5. 曲线编辑器数据流

### 5.1 双值曲线编辑 (位置/缩放)

```
CDlgPropDoubleCurve
  │
  ├── 初始化:
  │     ├── 遍历选中 Clip:
  │     │     ├── 获取关键点: clip->GetToolsKeyPoints(kt)
  │     │     ├── 获取采样点: clip->GetSamplePoints(kt)
  │     │     └── 合并到编辑器数据
  │     ├── 设置 BezierControl 线条数 = 2 (X/Y)
  │     ├── 设置坐标范围
  │     └── 填充控制点和采样点
  │
  ├── 用户编辑:
  │     ├── 添加/移动/删除控制点
  │     ├── BezierControl 自动重采样
  │     └── INotify::OnSampleCount() → 更新采样数
  │
  └── 确认 (IDOK):
        ├── 获取切线点: m_Bezier.GetTangentPoints()
        ├── 获取采样点: m_Bezier.GetSamplePoints()
        ├── 构建关键帧映射: keyMap[frame] = value

  │
  ├── 选中 Clip:
  │     m_Notify->OnSelectedItem(objId)
  │       └── CTimeBarView → Doc->SelectClip((AbstractEffectClip*)objId)
  │
  ├── 拖动 Clip:
  │     m_Notify->OnModify(obj)
  │       └── CTimeBarView:
  │             ├── Doc->ModifyStartEndFrame(clip, obj.startFrame, obj.endFrame, this)
  │             └── Doc->ModifyLayer(clip, obj.layer)
  │
  ├── 拖动播放线:
  │     m_Notify->OnDragingPlayFrame(frame)
  │       └── CTimeBarView → Doc->SetPlayingFrame(frame)
  │
  ├── 拖动最大帧线:
  │     m_Notify->OnModifyMaxFrame(nMaxFrame)
  │       └── CTimeBarView → Doc->SetTotalFrameNum(nMaxFrame)
  │
  └── 拖动分隔条:
        m_Notify->OnModifySpare(pos)
          └── CTimeBarView → Doc->SetDivideLayer(pos)
```

## 9. 关键帧数据结构

### 9.1 关键帧类型

| KeyType | 枚举值 | 值类型 | 曲线编辑器 |
|---------|--------|--------|-----------|
| `KT_POS` | 位置关键帧 | `FPOINT` (x, y) | CDlgPropDoubleCurve |
| `KT_SCALE` | 缩放关键帧 | `FPOINT` (x, y) | CDlgPropDoubleCurve |
| `KT_ROTATION` | 旋转关键帧 | `float` (弧度) | CDlgPropSingleCurve |
| `KT_ALPHA` | 透明度关键帧 | `float` (0-255) | CDlgPropSingleCurve |
| `KT_COLOR` | 颜色关键帧 | `XPCOLOR` (ARGB) | CDlgPropColor |

### 9.2 关键帧存储格式

```
EffectClip 内部存储:
  ├── m_PosKeyPoints    — 位置关键点 (KP_VECTOR)
  ├── m_PosSamplePoints — 位置采样点 (SP_VECTOR)
  ├── m_ScaleKeyPoints  — 缩放关键点
  ├── m_ScaleSamplePoints — 缩放采样点
  ├── m_RotKeyPoints    — 旋转关键点
  ├── m_RotSamplePoints — 旋转采样点
  ├── m_AlphaKeyPoints  — 透明度关键点
  ├── m_AlphaSamplePoints — 透明度采样点
  └── m_ColorKeys       — 颜色关键帧 (map<int, XPCOLOR>)
```

### 9.3 关键帧 XML 格式

```xml
<clip l="层级" sf="起始帧" ef="结束帧">
  <!-- 位置关键帧 -->
  <pkps>帧1,x1,y1;帧2,x2,y2;...</pkps>
  <psps>采样点数据</psps>
  <!-- 缩放关键帧 -->
  <skps>...</skps>
  <ssps>...</ssps>
  <!-- 旋转关键帧 -->
  <rkps>...</rkps>
  <rsps>...</rsps>
  <!-- 透明度关键帧 -->
  <akps>...</akps>
  <asps>...</asps>
  <!-- 颜色关键帧 -->
  <cks>帧1,A1,R1,G1,B1;帧2,A2,R2,G2,B2;...</cks>
</clip>
```
