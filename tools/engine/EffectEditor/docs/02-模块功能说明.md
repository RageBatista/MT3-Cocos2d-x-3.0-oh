## 1. 应用入口模块

### 1.1 CEffectEditorApp

**源文件**: `EffectEditor.h` / `EffectEditor.cpp`  
**基类**: `CWinApp`  
**职责**: 应用程序生命周期管理、全局资源初始化

#### 核心成员

| 成员 | 类型 | 说明 |
|------|------|------|
| `m_ExePath` | `CString` | 可执行文件所在目录路径 |
| `m_pFileIOMgr` | `Nuclear::CFileIOManager*` | PFS 文件 I/O 管理器 |
| `m_pEngine` | `Nuclear::EngineBase*` | 引擎实例指针 |

#### 核心方法

| 方法 | 说明 |
|------|------|
| `InitInstance()` | 初始化 PFS、MFC、OLE、单文档模板、命令行处理 |
| `ExitInstance()` | 销毁 `m_pFileIOMgr` |
| `GetExePath()` | 返回可执行文件目录 |
| `GetCfgFilePath()` | 返回配置文件路径 (`ExePath\EffectEditorCfg.ini`) |
| `GetFileIOManager()` | 返回 PFS 文件 I/O 管理器 |
| `GetEngine()` / `SetEngine()` | 获取/设置引擎实例 |
| `OnBatchExport()` | 批量导出特效文件：递归遍历源目录 `.geffect` 文件，加载后以指定 flag 保存到目标目录 |
| `OnAppAbout()` | 显示关于对话框 |

#### 初始化流程

1. 创建 `CFileIOManager` 并调用 `Init(true, true)` 初始化 PFS
2. 初始化通用控件 (`InitCommonControlsEx`)
3. 调用 `AfxOleInit()` 初始化 OLE
4. 注册单文档模板：`CEffectEditorDoc` + `CMainFrame` + `CEffectEditorView`
5. 处理命令行参数
6. 显示主窗口并启用拖放

## 4. 特效逻辑模块

**源文件**: `ToolsEffect.h` / `ToolsEffect.cpp`  
**基类**: `Nuclear::GEffect`  
**职责**: 特效编辑代理，提供编辑器所需的 Clip 增删改操作

#### 核心方法

| 方法 | 说明 |
|------|------|
| `AddClip(layer, startFrame, endFrame)` | 创建并添加新 Clip 到指定层 |
| `AddClip(clip, layer)` | 添加已有 Clip 到指定层 |

| `DelClip(clip)` | 删除 Clip (从层列表移除并释放) |

| `ModifyStartEndFrame(clip, start, end)` | 修改 Clip 起止帧 |

#### 保存格式

```xml
<root t_f="总帧数" d_l="前后分层" b_l="左" b_t="上" b_r="右" b_b="下" fps="帧率" bT="绑定类型" hasA="是否有独立音频">
  <clip>...</clip>
  <clip>...</clip>
</root>
```

音频 Clip 在 `EFFECT_IO_EDIT` 模式下保存到独立的 `audio.inf` 文件。

### 4.3 Sprite

**源文件**: `Sprite.h` / `Sprite.cpp`  
**基类**: 无 (独立类)  
**职责**: 角色 Sprite 编辑代理，管理模型/动作/组件/帧

#### 核心成员

| 成员 | 类型 | 说明 |
|------|------|------|
| `m_pEngine` | `Nuclear::EngineBase*` | 引擎实例 |
| `m_ModelName` | `std::wstring` | 当前模型名 |
| `m_CurActionName` | `std::wstring` | 当前动作名 |
| `m_pAction` | `const Nuclear::Action*` | 当前动作数据 |
| `m_CurComponents` | `vector<Nuclear::Component*>` | 当前组件列表 |
| `m_Colors` | `vector<Nuclear::XPCOLOR>` | 各组件颜色 |
| `m_Direction` | `Nuclear::XPDIRECTION` | 当前方向 |
| `m_Position` | `Nuclear::CPOINT` | 当前位置 |

#### 核心方法

| 方法 | 说明 |
|------|------|
| `SetModel(modelname)` | 设置模型：加载层信息、初始化组件/颜色数组、设置特效层标记 |
| `SetAction(action_name)` | 设置动作：通过 SpriteManager 查找动作引用 |
| `SetComponent(sc, resource, color)` | 设置指定层组件 |
| `GetComponent(sc)` | 获取指定层组件名 |
| `SetDirection(dir)` | 设置方向 |
| `SetPosition(pos)` | 设置位置 |
| `SetFrame(frame)` | 设置当前帧号 |
| `Tick(deltaTime)` | 帧推进：根据时间计算当前帧 |
| `Render()` | 渲染：遍历组件绘制动画帧，处理特效层混合模式 |

#### 特效层渲染逻辑

Sprite 渲染时识别特效层 (`m_FlagEffectLayer` 位掩码)：
- 特效层使用 `XPTEXBM_ADDITIVE_ALPHA` 混合模式
- 特效层使用正弦波 alpha 渐变效果
- 特效层图片缩放 `XP_EFFECT_SCALE` 倍
- 特效层在特定方向 (0/5/6/7) 优先渲染

## 5. 撤销/重做模块

### 5.1 CActionList

**源文件**: `Action.h` / `Action.cpp`  
**职责**: 管理操作历史队列，支持撤销/重做

#### 核心成员

| 成员 | 类型 | 说明 |

| 方法 | 说明 |

### 8.1 bezier::CBezierControl

**源文件**: `BezierControl.h` / `BezierControl.cpp`

**职责**: 贝塞尔曲线编辑器，用于编辑关键帧插值曲线

#### 工作模式

| 模式 | 说明 |
|------|------|
| `WORK_MODE_CURVE` | 曲线编辑模式：显示工具栏、Y 轴编辑、线条过滤 |
| `WORK_MODE_SAMPLEING` | 采样模式：隐藏工具栏和 Y 轴，显示采样点 |

#### 工具状态

| 状态 | ID | 功能 |
|------|-----|------|
| `MOUSE_STATE_ARROW` | `ID_BZ_TOOL_ARROW` | 选择/移动控制点 |
| `MOUSE_STATE_ADD` | `ID_BZ_TOOL_ADD` | 添加控制点 |
| `MOUSE_STATE_REMOVE` | `ID_BZ_TOOL_REMOVE` | 删除控制点 |
| `MOUSE_STATE_CONVERT` | `ID_BZ_TOOL_CONVERT` | 转换控制点类型 (平滑/尖角) |

#### 数据结构

| 结构 | 说明 |
|------|------|

| `TangentPointContanters` | 多条线的切线点容器 (`vector<list<TangentPoint>>`) |
| `SamplePointContanters` | 多条线的采样点容器 (`vector<list<SamplePoint>>`) |

#### 核心方法

| 方法 | 说明 |

| `SetLineName(id, name)` | 设置线条名称 |
| `AddPoint(line, point)` | 添加控制点 |
| `CleanPoints(line)` | 清除指定线控制点 |
| `CleanAllLinePoints()` | 清除所有线控制点 |
| `SetSampleCount(count)` | 设置采样数 |
| `SetSamples(spc)` | 设置采样点 |
| `SetWorkMode(mode)` | 切换工作模式 |
| `SetMinX/SetMaxX/SetMinY/SetMaxY` | 设置坐标范围 |
| `GetTangentPoints()` | 获取切线点数据 |
| `GetSamplePoints()` | 获取采样点数据 |

#### 坐标变换

| 方法 | 说明 |
|------|------|
| `TransToLogic(in, out)` | 客户端坐标 → 逻辑坐标 |

| `TransToLogicVector(in, out)` | 客户端向量 → 逻辑向量 |
