## 1. 系统概述

EffectEditor 是 MT3 项目中的**特效编辑器**，基于 MFC (Microsoft Foundation Classes) 框架构建的 Win32 桌面应用程序，用于创建、编辑和导出游戏特效资源。它支持两种特效文件类型：

| 文件类型 | 枚举值 | 扩展名 | 说明 |
|----------|--------|--------|------|
| Effect 特效文件 | `EFT_EFFECT` | `.geffect` | 独立特效，包含多层 Clip、帧动画、粒子、音频等 |
| Sebind 绑定文件 | `EFT_SEBIND` | `.sebind` | 将特效绑定到角色 Sprite 的特定方向/动作上 |

### 1.1 技术栈

- **UI 框架**: MFC (单文档模板 SDI)
- **渲染引擎**: Nuclear 引擎 (`Nuclear::EngineBase`)
- **图形 API**: OpenGL 2.0 (通过 `Nuclear::Renderer`)
- **音频**: DirectSound (`Nuclear::DirectSoundManager`)
- **文件系统**: PFS (`Nuclear::CFileIOManager`)
- **序列化**: XMLIO (自研 XML 读写库)
- **构建工具**: VS2013 v120

### 1.2 代码规模

| 类别 | 文件数 | 说明 |
|------|--------|------|
| 核心 MFC 类 | 5 | App/Doc/View/MainFrame |
| 特效逻辑层 | 3 | ToolsEffect/ToolsSebind/Sprite |
| 撤销/重做系统 | 1 | Action/CActionList |
| 属性面板 | 7 | AniPicProp/AniEffectProp/ParticleProp/AudioProp/RoleProp/EffectProp/TabPropPanel |
| 曲线编辑 | 3 | BezierControl/DlgPropDoubleCurve/DlgPropSingleCurve |
| 时间轴 | 2 | TimeBarCtrl/TimeBarView |
| 工具/辅助 | 8 | ToolView/ToolsPanel/PropertyView/AddEditClipDlg/AudioFileDialog/ColorBarCtrl/DlgPropColor/DlgSelNewFileType/InputDialog/CrashDump |

## 4. 双模式架构 (Effect / Sebind)

EffectEditor 的核心设计是**双模式架构**，同一套 UI 框架根据文件类型切换行为：

### 4.1 Effect 模式 (EFT_EFFECT)

- 特效作为独立实体编辑
- 支持多层 Clip (最多 `MAX_CLIP_LAYER` 层)
- 每层可包含多个 Clip，按起始帧排序
- 支持 Clip 的增删改、位置/旋转/缩放关键帧编辑
- 前后分层渲染 (`RenderBack` / `RenderFront`)

### 4.2 Sebind 模式 (EFT_SEBIND)

- 特效绑定到角色 Sprite 的特定方向/动作
- 只有单层 (layer 0)
- Clip 由方向+动作唯一确定
- Sprite 帧驱动特效播放
- 选中 Clip 自动锁定为当前方向/动作对应的 Clip

### 4.3 模式切换点

Doc 层通过 `m_EffectFileType` 在所有操作中进行分支判断：

```cpp
switch (m_EffectFileType) {
case EFT_EFFECT:
    // 操作 CToolsEffect
    break;
case EFT_SEBIND:
    // 操作 CToolsSebind + Sprite
    break;
}
```

涉及的关键方法：`Tick()`, `Draw()`, `SetPlayingFrame()`, `GetPlayingFrame()`, `GetClipListByLayer()`, `GetTotalFrames()`, `GetFPS()`, `GetBindType()`, `GetDivideLayer()`, `AddEffectClip()`, `DelEffectClip()`, `ResetEffectForBind()` 等。

## 5. 撤销/重做系统架构

### 5.1 命令模式设计

采用经典 Command Pattern，每个操作封装为 `CAction` 子类实例：

```
CAction (抽象基类)
  ├── CActionModifyStartEndFrame — 修改 Clip 起止帧
  ├── CActionModifyLayer — 修改 Clip 层级
  ├── CActionModifyClipAni — 修改 Clip 动画资源
  ├── CActionSetDivideLayer — 设置前后分层位置
  ├── CActionSetTotalFrame — 设置总帧数
  ├── CActionSetFps — 设置 FPS
  ├── CActionSetBindType — 设置绑定类型
  ├── CActionSetBoundsRect — 设置包围盒
  ├── CActionDelAddClip — 增删 Clip
  ├── CActionSetClipPos — 设置 Clip 位置
  ├── CActionSetClipFps — 设置 Clip FPS
  ├── CActionSetClipVertexColor — 设置 Clip 顶点色
  ├── CActionSetClipPlayModeAndTime — 设置 Clip 播放模式与时间
  ├── CActionSetClipsDoubleKeys — 设置双值关键帧 (位置/缩放)
  ├── CActionSetClipSingleKeys — 设置单值关键帧 (旋转/透明度)
  ├── CActionSetClipColorKeys — 设置颜色关键帧 (单 Clip, m_pClip + m_KeyMaps[2])
```

### 5.2 CActionList 管理器

- 维护 `std::list<CAction*>` 双端队列
- 迭代器 `m_Iter` 指向当前执行位置
- 最大历史长度 `MAX_LENGTH = 50`
- `DoOneAction()`: 新操作入队，截断 redo 历史
- `UndoOneAction()`: 回退到 `BEFORE_ACTION` 状态
- `RedoOneAction()`: 前进到 `AFTER_ACTION` 状态
- 每个操作存储 `[BEFORE_ACTION=0]` 和 `[AFTER_ACTION=1]` 两份数据快照

## 6. 渲染架构

### 6.1 渲染循环

```
CMainFrame (MFC 框架)
  └── WM_TIMER → CEffectEditorView::OnTimer()
        └── Tick() → CEffectEditorDoc::Tick(dt)
              ├── m_pSprite->Tick(dt)           — Sprite 帧推进
              ├── m_pToolsEffect->Update(dt)    — Effect 模式更新
              └── m_ToolsSebind.Tick(...)       — Sebind 模式更新
        └── RenderEffect() → CEffectEditorDoc::Draw(pRenderer)
              ├── m_pToolsEffect->RenderBack()  — 后层渲染
              ├── m_pSprite->Render()           — 角色渲染
              ├── m_pToolsEffect->RenderFront() — 前层渲染
              └── INotify::OnRender()           — 通知 UI 刷新
```

### 6.2 CEffectEditorView 作为 EngineBase

`CEffectEditorView` 实现了 `Nuclear::EngineBase` 接口，为引擎各子系统提供运行环境：

| EngineBase 虚方法 | 实现返回 |
|-------------------|---------|
| `GetRenderer()` | `m_pRenderer` |
| `GetEffectManager()` | `m_pEffectManager` |
| `GetAniManager()` | `m_pAnimationManager` |
| `GetSpriteManager()` | `m_pSpriteMgr` |
| `GetConfigManager()` | `m_pConfigMgr` |
| `GetSoundManager()` | `m_pSoundManager` |
| `GetFileIOManager()` | `theApp.GetFileIOManager()` |
| `GetViewport()` | `m_ClientRect` |
| `GetTick()` | `Nuclear::GetMilliSeconds()` |

## 7. 文件 I/O 架构

### 7.1 保存流程

```
CEffectEditorDoc::OnSaveDocument()
  └── CToolsEffect::SaveEffect(path, flag)
        ├── XMLIO::CFileWriter → 获取 Root 节点
        ├── 写入属性: t_f(总帧), d_l(分层), b_l/b_t/b_r/b_b(包围盒), fps, bT(绑定类型)
        ├── 遍历所有层所有 Clip:
        │     ├── 音频 Clip → soundcliproot 节点 (独立 audio.inf)
        │     └── 其他 Clip → root 下 clip 节点
        └── fw.SaveNative(path)
```

### 7.2 加载流程

```
CEffectEditorDoc::OnOpenDocument()
  └── CToolsEffect::LoadEffect(root, flag)
        ├── 读取属性
        ├── 遍历 clip 节点创建 EffectClip
        └── AssureResource() 加载资源
```

### 7.3 批量导出

`CEffectEditorApp::OnBatchExport()` 支持递归遍历指定目录下所有 `.geffect` 文件，重新加载后以指定 flag 保存到目标目录。

## 8. 交互工具架构

### 8.1 工具状态机

`CEffectEditorView` 通过 `eToolState` 枚举管理当前工具：

| 工具状态 | 枚举值 | 功能 |
|----------|--------|------|
| `TS_ARROW` | `ID_TOOL_ARROW` | 选择/移动特效位置/平移背景 |
| `TS_BOUNDS_RECT` | `ID_TOOL_BOUNDS_RECT` | 编辑包围盒 |
| `TS_MOVE` | `ID_TOOL_MOVE` | 移动选中 Clip |
| `TS_FRAME_POS` | `ID_TOOL_FRAME_POS` | 编辑 Clip 位置关键帧 |
| `TS_FRAME_ROTATE` | `ID_TOOL_FRAME_ROTATE` | 编辑 Clip 旋转关键帧 |
| `TS_FRAME_SIZE` | `ID_TOOL_FRAME_SIZE` | 编辑 Clip 缩放关键帧 |

### 8.2 IEffectClipControl 回调

`CEffectEditorView` 实现 `Nuclear::IEffectClipControl` 接口，在旋转/缩放工具激活时作为控制回调：

- `GetRotationRadian(angle)`: 实时计算鼠标拖拽产生的旋转角度
- `GetScale(scale)`: 实时计算鼠标拖拽产生的缩放比例

## 9. 通知机制

### 9.1 INotify 接口

```cpp
class INotify {
public:
    virtual void OnRender() {};
};
```

实现类：`CRoleProp`, `CTimeBarView`

`CEffectEditorDoc` 维护 `NotifySet m_NotifySet`，在 `Draw()` 末尾遍历调用 `OnRender()`，驱动 UI 同步刷新。

### 9.2 TimeBarNotify 接口

```cpp
class TimeBarNotify {
    virtual bool OnUnSelectedAllItem();
    virtual bool OnDragingPlayFrame(int frame);
    virtual bool OnDragingPlayPos(float pos);
    virtual bool OnUnSelectedItem(DWORD objID);
    virtual bool OnSelectedItem(DWORD objID);
    virtual bool OnModifyMaxFrame(int nMaxFrame);
    virtual bool OnModifySpare(int pos);
    virtual bool OnModify(const ClipObj& obj);
};
```

实现类：`CTimeBarView`，桥接时间轴控件与 Doc 层操作。

### 9.3 IToolsNotify 接口

```cpp
class IToolsNotify {
    virtual void OnAddClip();
    virtual void OnToolsControl(UINT nID);
};
```

实现类：`CToolView`，桥接工具面板与主框架命令路由。

### 9.4 bezier::INotify 接口

```cpp
namespace bezier {
    class INotify {
        virtual void OnClick();
        virtual void OnSampleCount(int sampleCount);
        virtual void OnSamplesReady(bool bReady);
    };
}
```

实现类：`CDlgPropDoubleCurve`, `CDlgPropSingleCurve`，响应贝塞尔曲线编辑器事件。
