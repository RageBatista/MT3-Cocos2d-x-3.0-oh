## 1. 应用程序模块 (CImageEditorApp)

**文件**: [`ImageEditor.h`](../ImageEditor.h), [`ImageEditor.cpp`](../ImageEditor.cpp)

### 1.1 功能概述

`CImageEditorApp` 是应用程序的入口类，继承自 `CWinApp`，负责：

1. **MFC 初始化** — 初始化公共控件、OLE 库、文档模板
2. **PFS 文件系统初始化** — 创建并初始化 `Nuclear::CFileIOManager`
3. **资源路径计算** — 根据工作目录推算 `res` 资源路径
4. **空闲渲染驱动** — 在 `OnIdle()` 中驱动主视图的渲染循环
5. **清理退出** — 在 `ExitInstance()` 中销毁 PFS 文件管理器

### 1.2 关键成员

| 成员 | 类型 | 说明 |
|------|------|------|
| [`m_pFileIOManager`](../ImageEditor.h:22) | `Nuclear::CFileIOManager*` | PFS 文件系统管理器实例 |
| [`m_strResPath`](../ImageEditor.h:27) | `CString` | 资源根目录路径 |
| [`theApp`](../ImageEditor.h:40) | `CImageEditorApp` | 全局唯一应用程序实例 |

### 1.3 初始化流程

```
InitInstance()                                    [ImageEditor.cpp:50]
  ├── InitCommonControlsEx()                      // 公共控件初始化
  ├── AfxOleInit()                                // OLE 初始化
  ├── SetRegistryKey()                            // 注册表设置
  ├── LoadStdProfileSettings(4)                   // MRU 文件列表
  ├── new CMultiDocTemplate(...)                  // 注册文档模板
  ├── new CMainFrame → LoadFrame()                // 创建 MDI 主框架
  ├── new CFileIOManager() → Init(true, true)     // PFS 初始化

  ├── ParseCommandLine() → ProcessShellCommand()  // 命令行处理
  └── ShowWindow() → UpdateWindow()               // 显示主窗口
```

### 1.4 空闲渲染机制

[`OnIdle()`](../ImageEditor.cpp:203) 在 MFC 空闲时被调用，获取当前活动文档的 `CImageEditorView` 并调用 `Render()`。这形成了一个持续的渲染循环，确保视图内容实时更新。

## 4. 文档模块 (CImageEditorDoc)

**文件**: [`ImageEditorDoc.h`](../ImageEditorDoc.h), [`ImageEditorDoc.cpp`](../ImageEditorDoc.cpp)

### 4.1 功能概述

`CImageEditorDoc` 继承自 `CDocument`，是 MFC Document/View 架构中的文档类，负责：

1. **图像数据管理** — 持有 `PImg` 对象，管理图像集数据

## 5. 渲染视图模块 (CImageEditorView)

**文件**: [`ImageEditorView.h`](../ImageEditorView.h), [`ImageEditorView.cpp`](../ImageEditorView.cpp)

### 5.1 功能概述

`CImageEditorView` 是核心视图类，同时继承 `CView` 和 `Nuclear::EngineBase`，负责：

1. **DirectX 9 渲染** — 使用 Nuclear `Renderer` 绘制图像和编辑辅助线
2. **鼠标交互** — 左键拖拽绘制边框、移动边框顶点、添加/调整遮挡点
3. **右键菜单** — 删除遮挡点
4. **滚动支持** — 水平/垂直滚动浏览大图
5. **缩放支持** — 根据信息面板的缩放比例调整渲染
6. **定时器渲染** — 30ms 定时器驱动持续渲染
7. **引擎子系统管理** — 创建并管理 SpriteManager、ConfigManager、AniManager

### 5.2 交互模式

视图根据当前标志位进入不同的交互模式：

| 模式 | 标志 | 行为 |
|------|------|------|
| **普通模式** | 默认 | 左键单击设置重心；左键拖拽绘制新边框；拖拽顶点移动边框 |
| **设置遮挡模式** | `m_bSetMaskpt == true` | 左键单击添加遮挡多边形顶点 |
| **调整遮挡模式** | `m_bAdjustMaskpt == true` | 左键拖拽移动遮挡点；右键删除遮挡点 |

### 5.3 渲染内容

[`DrawPic()`](../ImageEditorView.cpp:291) 在每帧绘制以下内容：

1. **图像子图** — 根据 `PImg` 中的 `m_vectorRct` 加载并绘制各子图
2. **重心标记** — 红色 X 形交叉线标记重心位置
3. **边框** — 绿色菱形边框线 + 红色圆形顶点标记
4. **遮挡多边形** — 青色多边形线 + 蓝色圆形顶点标记
5. **半透明效果** — 当精灵在遮挡区域内时，图像变为半透明（已注释）

**文件**: [`ImageInfoView.h`](../ImageInfoView.h), [`ImageInfoView.cpp`](../ImageInfoView.cpp)

### 6.1 功能概述

`CImageInfoView` 继承自 `CFormView`，基于对话框模板 `IDD_VIEW_IMAGEINFO` 创建，是左侧的文件浏览和控制面板，负责：

1. **文件列表** — 显示当前目录的文件列表（`CListCtrl`）
2. **文件搜索** — 按文件名搜索
3. **缩放控制** — 滑块控制缩放比例（1%~400%）
4. **纹理格式选择** — 下拉框选择输出纹理格式
5. **遮挡模式切换** — 复选框切换设置/调整遮挡模式
6. **批处理操作** — PIC 转 IMG、批量设置重心/边框、文件另存为
7. **文件版本转换** — 旧版本 .set 文件转换为新版本

## 7. 状态视图模块 (CImageStatusView)

**文件**: [`ImageStatusView.h`](../ImageStatusView.h), [`ImageStatusView.cpp`](../ImageStatusView.cpp)

### 7.1 功能概述

`CImageStatusView` 继承自 `CView`，位于分割窗口底部，负责显示当前图像的元数据信息：

1. **图像尺寸** — 显示图片宽×高

3. **重心坐标** — 显示重心 (x, y)

### 7.2 绘制逻辑

[`OnDraw()`](../ImageStatusView.cpp:29) 使用 GDI `CDC::TextOut()` 在固定位置绘制文本信息。同时，它会同步更新 `CImageInfoView` 中的格式下拉框选择。
