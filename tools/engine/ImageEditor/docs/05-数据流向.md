## 1. 应用程序启动数据流

```
用户双击 ImageEditor.exe
  │
  ▼
CImageEditorApp::InitInstance()                    [ImageEditor.cpp:50]
  │
  ├──► InitCommonControlsEx()                      ← Windows 公共控件
  ├──► AfxOleInit()                                ← OLE 库
  ├──► new CMultiDocTemplate(...)                  ← 注册文档/视图/框架映射
  │      ├── CImageEditorDoc  (Document)
  │      ├── CChildFrame      (MDI Child Frame)
  │      └── CImageEditorView (Default View)
  │
  ├──► new CMainFrame → LoadFrame(IDR_MAINFRAME)   ← 创建主窗口
  │      ├── m_wndToolBar (工具栏)
  │      └── m_wndStatusBar (状态栏)
  │
  ├──► new CFileIOManager → Init(true, true)       ← 初始化 PFS 文件系统
  │
  ├──► 计算资源路径: workdir\res
  │
  └──► ProcessShellCommand(cmdInfo)                 ← 处理命令行
         └──→ 显示主窗口
```

## 2. 文件打开数据流

```
用户: 文件→打开 (Ctrl+O)
  │
  ▼
CImageEditorDoc::OnFileOpen()                      [ImageEditorDoc.cpp:212]
  │
  ├──► CFileDialog (*.set 过滤)
  │      └── 用户选择文件 → filePath
  │
  ▼
CImageEditorDoc::OnOpenDocument(filePath)           [ImageEditorDoc.cpp:152]
  │
  ├──► _tfopen_s(filePath, "rb")                   ← 打开文件二进制读
  │
  ├──► m_imgObject.ResetImgObject()                ← 重置旧数据
  │
  ├──► m_imgObject.Load(f)                         ← PImg 反序列化
  │      │
  │      │   读取到 PImg 结构:
  │      │   ├── m_nFileWidth, m_nFileHeight       (图像尺寸)
  │      │   ├── CenterPoint                       (重心坐标)
  │      │   ├── pos[4]                            (边框顶点: 左/下/右/上)
  │      │   ├── m_vectorRct                       (子图矩形列表)
  │      │   ├── m_mask                            (遮挡多边形顶点)
  │      │   ├── m_texfmt                          (纹理格式)
  │      │   └── m_nSourceVersion                  (文件版本号)
  │      │
  │      └── fclose(f)
  │
  ├──► 版本检查: m_imgObject.GetSourceVersion() < NEWVER
  │      └── SetModifiedFlag(true)                 ← 旧版本标记为已修改
  │
  ├──► GetImageEditorView()->SetViewSize()          ← 设置视图尺寸
  │
  ├──► GetImageEditorView()->InitBorderCentPos()    ← 初始化边框缓存
  │      │
  │      │   复制数据到视图缓存:
  │      │   ├── m_pointBorderCent[4]              ← 边框中心点
  │      │   ├── m_pointBorderVertex[4]            ← 边框顶点
  │      │   └── m_imgMasks                        ← 遮挡多边形
  │
  ├──► GetImageInfoView()->UpdateControlState(false) ← 禁用控件
  │
  ├──► UpdateAllViews(NULL)                        ← 通知所有视图刷新
  │      │
  │      ├──► CImageEditorView::OnUpdate()         (MFC 默认 → Invalidate)
  │      ├──► CImageInfoView::OnUpdate()           (空实现)
  │      └──► CImageStatusView::OnUpdate()         (MFC 默认 → Invalidate)
  │
  └──► SetTitle(filePath)                          ← 设置窗口标题
```

## 3. 渲染数据流

```
定时器 (30ms) / OnIdle()
  │
  ▼
CImageEditorView::Render()                         [ImageEditorView.cpp:190]
  │
  ├──► [首次] CreateRenderer(&m_pRenderer, ...)    [ImageEditorView.cpp:205]
  │      └──► Renderer::SetSourceRect()            ← 设置渲染区域
  │
  ├──► m_pRenderer->Begin(bkColor)                 ← 开始渲染场景
  │      └── bkColor = pDoc->GetBackGroundColor()  ← ARGB 背景色
  │
  ├──► DrawPic()                                   [ImageEditorView.cpp:291]
  │      │
  │      ├──► [首次] 加载图片纹理
  │      │      ├── 释放旧纹理 (m_vectorPicID)
  │      │      ├── 获取文件名 (去掉扩展名)
  │      │      ├── for each m_vectorRct[i]:
  │      │      │    fileName_N = fileName + "_0", "_1", ...
  │      │      │    handle = Renderer::LoadPictureFromNativePath()
  │      │      │    m_vectorPicID.push_back(handle)
  │      │      └── SetPicInit(true)
  │      │
  │      ├──► 绘制图像子图
  │      │      fZoomRate = pDoc->GetImageInfoView()->GetCurrentZoomRate()
  │      │      for each m_vectorPicID[i]:
  │      │          计算源矩形 (考虑缩放和滚动偏移)
  │      │          计算 UV 坐标 (du, dv, coefU, coefV)
  │      │          Renderer::DrawPicture(param)
  │      │
  │      ├──► 绘制重心标记
  │      │      centerPointX = imgFile.CenterPoint.x * zoomRate - scrollX
  │      │      centerPointY = imgFile.CenterPoint.y * zoomRate - scrollY
  │      │      Renderer::DrawLine(X 形交叉, 红色 0xffff0000)
  │      │
  │      ├──► 绘制边框
  │      │      for i=0..3:
  │      │          p[i] = imgFile.pos[i] * zoomRate - scrollOffset
  │      │          Renderer::DrawLine(p[i], p[i+1], 绿色 0xff00ff00)
  │      │          Renderer::DrawEllipse(p[i], r=3, 红色, WIREFRAME)
  │      │
  │      └──► 绘制遮挡多边形
  │             for i=0..cnt:
  │                 pt = m_imgMasks[i] * zoomRate
  │                 Renderer::DrawLine(pt[i], pt[i+1], 青色 0xff00ffa0)
  │                 Renderer::DrawEllipse(pt[i], r=3, 蓝色, WIREFRAME)
  │
  └──► m_pRenderer->End()                          ← 结束渲染场景
```

## 4. 鼠标交互数据流（边框编辑）

```
用户: 左键按下 (普通模式)
  │
  ▼
CImageEditorView::OnLButtonDown()                  [ImageEditorView.cpp:432]
  │
  ├──► 检查是否点击了边框顶点 (距离 < 3px)
  │      ├── 是 → m_bMoveBorder = true, 记录顶点索引
  │      └── 否 → 继续
  │
  ├──► SetCapture()                                ← 捕获鼠标
  ├──► m_initialPoint = point                      ← 记录起始点
  │
  ▼
用户: 鼠标移动 (拖拽)
  │
  ▼
CImageEditorView::OnMouseMove()                    [ImageEditorView.cpp:557]
  │
  ├──► [移动边框顶点模式]
  │      ├── 计算对角点
  │      ├── ComputerImgFilePos(对角点, 鼠标点)    ← 计算新边框
  │      ├── InvertLine() × 4                      ← 擦除旧线 + 绘制新线
  │      └── SetImgFilePos(imgFile)                ← 更新 PImg 数据
  │
  ├──► [绘制新边框模式]
  │      ├── ComputerImgFilePos(起始点, 鼠标点)    ← 计算菱形边框
  │      └── InvertLine() × 4                      ← 橡皮筋线
  │
  ▼
用户: 左键释放
  │
  ▼
CImageEditorView::OnLButtonUp()                    [ImageEditorView.cpp:765]
  │
  ├──► [移动边框顶点]
  │      └── SetImgFilePos(imgFile)                ← 写入最终坐标
  │
  ├──► [绘制新边框]
  │      ├── ComputerImgFilePos(起始点, 释放点)
  │      └── SetImgFilePos(imgFile)
  │
  ├──► [单击 (未拖拽)]
  │      └── imgFile.CenterPoint = point + scrollOffset  ← 设置重心
  │
  ├──► pDoc->UpdateAllViews(NULL)                  ← 通知所有视图刷新
  ├──► pDoc->SetModifiedFlag(true)                 ← 标记文档已修改
  ├──► m_bDrawBorder = false
  ├──► m_bMoveBorder = false
  └──► ReleaseCapture()                            ← 释放鼠标捕获
```

## 5. 鼠标交互数据流（遮挡编辑）

### 5.1 添加遮挡点

```
用户: 勾选"设置遮挡" → 左键单击
  │
  ▼
CImageEditorView::OnLButtonDown()                  [ImageEditorView.cpp:218]
  │
  └──► m_bSetMaskpt == true
       ├── pt = point / m_fZoomRate                ← 反缩放
       ├── imgFile.m_mask.push_back(pt)            ← 写入 PImg
       ├── m_imgMasks.push_back(pt)                ← 写入本地缓存
       └── pDoc->SetModifiedFlag(true)
```

### 5.2 调整遮挡点

```
用户: 勾选"调整遮挡" → 左键拖拽遮挡点
  │
  ▼
CImageEditorView::OnLButtonDown()
  │
  └──► m_bAdjustMaskpt == true
       ├── 遍历 m_imgMasks 查找距离 < 3px 的点
       ├── 找到 → m_nCurSelMaskpt = i, SetCapture()
       │
       ▼
OnMouseMove()
  │
  └──► m_bModifyMask == true
       └── m_imgMasks[i] += delta                  ← 更新本地缓存
       │
       ▼
OnLButtonUp()
  │
  └──► imgFile.m_mask[i] = m_imgMasks[i]          ← 同步到 PImg
       ├── pDoc->UpdateAllViews(NULL)
       └── pDoc->SetModifiedFlag(true)
```

### 5.3 删除遮挡点

```
用户: 右键点击遮挡点 → "删除遮挡点"
  │
  ▼
CImageEditorView::OnRButtonDown()                  [ImageEditorView.cpp:1125]
  │
  └──► m_bAdjustMaskpt == true
       ├── 查找距离 < 3px 的遮挡点
       ├── 弹出右键菜单 (IDR_MENU2)
       │
       ▼
CImageEditorView::OnDelmask()                      [ImageEditorView.cpp:1161]
  │
  ├──► m_imgMasks.erase(it + m_nRButtonSelpt)      ← 删除本地缓存
  └──► imgFile.m_mask.erase(it + m_nRButtonSelpt)  ← 删除 PImg 数据
```

  │      │   └── 纹理格式

## 7. 缩放数据流

```
用户: 拖动缩放滑块
  │
  ▼
CImageInfoView::OnHScroll()                        [ImageInfoView.cpp:231]
  │
  ├──► m_fZoomRate = sliderPos / 100.0f            ← 更新缩放比例
  │   (滑块范围 1~400, 对应 1%~400%)
  │
  ▼
CImageEditorView::Render() → DrawPic()
  │
  └──► fZoomRate = pDoc->GetImageInfoView()->GetCurrentZoomRate()
       ├── 子图位置: vectorRct[i] * fZoomRate
       ├── 滚动偏移: scrollPos * fZoomRate
       ├── 边框位置: imgFile.pos[i] * fZoomRate
       ├── 遮挡位置: m_imgMasks[i] * fZoomRate
       └── 重心位置: CenterPoint * fZoomRate
```

## 8. 背景色设置数据流

```
用户: 操作→设置背景色
  │
  ▼
CImageEditorDoc::OnSetbkcolor()                    [ImageEditorDoc.cpp:263]
  │
  ├──► CColorDialog → DoModal()                    ← 弹出颜色选择器
  ├──► dlg.GetColor() → COLORREF (BGR)
  ├──► BGR → ARGB 转换:
  │      m_dwBKcolor = 0xFF000000 | (B)<<16 | (G)<<8 | (R)
  │
  └──► GetImageEditorView()->Invalidate(false)     ← 触发重绘
       │
       ▼
CImageEditorView::Render()
  └──► m_pRenderer->Begin(bkColor)                ← 使用新背景色
```
