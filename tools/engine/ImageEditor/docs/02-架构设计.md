## 1. 系统架构概述

ImageEditor 采用 **MFC MDI Document/View** 架构模式，结合 Nuclear 引擎的 DirectX 9 渲染管线，实现图像集文件的编辑功能。

### 2.2 关键多重继承

[`CImageEditorView`](../ImageEditorView.h:22) 同时继承自：
- `CView` — MFC 视图基类，处理 Windows 消息和绘制
- `Nuclear::EngineBase` — Nuclear 引擎基类，提供引擎子系统访问接口

```cpp
class CImageEditorView : public CView, public Nuclear::EngineBase
```

`EngineBase` 要求实现以下虚函数接口：
- [`GetFileIOManager()`](../ImageEditorView.h:95) — 返回 PFS 文件管理器
- [`GetSpriteManager()`](../ImageEditorView.h:99) — 返回精灵管理器
- [`GetConfigManager()`](../ImageEditorView.h:103) — 返回配置管理器
- [`GetAniManager()`](../ImageEditorView.h:107) — 返回动画管理器
- [`GetEffectManager()`](../ImageEditorView.h:112) — 返回特效管理器（返回 NULL）
- [`GetRenderer()`](../ImageEditorView.h:118) — 返回 D3D 渲染器
- [`GetViewport()`](../ImageEditorView.h:122) — 返回视口矩形
- [`GetTick()`](../ImageEditorView.h:132) — 返回当前时钟
- [`GetApp()`](../ImageEditorView.h:133) — 返回应用接口（返回 NULL）

## 3. Document/View 架构

### 3.1 文档模板注册

在 [`CImageEditorApp::InitInstance()`](../ImageEditor.cpp:50) 中注册 MDI 文档模板：

```cpp
CMultiDocTemplate* pDocTemplate;
pDocTemplate = new CMultiDocTemplate(
    IDR_ImageEditorTYPE,
    RUNTIME_CLASS(CImageEditorDoc),    // 文档类
    RUNTIME_CLASS(CChildFrame),        // 子框架类
    RUNTIME_CLASS(CImageEditorView)    // 默认视图类
);
```

### 3.2 一文档三视图

每个 `CImageEditorDoc` 对应三个视图，通过 `CChildFrame` 中的分割窗口管理：

```
CChildFrame
└── m_wndSplitter (水平 1×2)
    ├── [0,0] CImageInfoView     (左侧, 宽 350px)
    └── [0,1] m_wndSplitter2 (垂直 2×1)
        ├── [0,0] CImageEditorView  (右上, 主渲染区)
        └── [1,0] CImageStatusView  (右下, 状态信息)
```

分割窗口在 [`CChildFrame::OnCreateClient()`](../ChildFrm.cpp:63) 中创建：

1. `m_wndSplitter` — 水平分割为 1 行 2 列
   - 列 0：`CImageInfoView`（固定宽度 350px）
   - 列 1：嵌套分割器 `m_wndSplitter2`
2. `m_wndSplitter2` — 垂直分割为 2 行 1 列
   - 行 0：`CImageEditorView`（主渲染区，占大部分高度）
   - 行 1：`CImageStatusView`（底部状态区）

### 3.3 视图获取方式

[`CImageEditorDoc`](../ImageEditorDoc.cpp:46) 提供了三个便捷方法获取各视图指针：

- [`GetImageEditorView()`](../ImageEditorDoc.cpp:46) — 遍历视图列表，`dynamic_cast` 为 `CImageEditorView*`
- [`GetImageInfoView()`](../ImageEditorDoc.cpp:60) — 遍历视图列表，`dynamic_cast` 为 `CImageInfoView*`
- [`GetImageStatusView()`](../ImageEditorDoc.cpp:74) — 遍历视图列表，`dynamic_cast` 为 `CImageStatusView*`

## 4. 模块职责划分

| 模块 | 类 | 职责 |
|------|-----|------|
| **应用程序** | `CImageEditorApp` | 初始化 MFC、PFS、资源路径；空闲时触发渲染 |
| **主框架** | `CMainFrame` | 创建工具栏、状态栏；管理 MDI 子窗口 |
| **子框架** | `CChildFrame` | 创建三视图分割布局 |
| **分割窗口** | `CViewExSplitWnd` | 扩展 `CSplitterWnd`，重写活动面板检测 |
| **文档** | `CImageEditorDoc` | 管理 `PImg` 数据；文件打开/保存/序列化 |
| **渲染视图** | `CImageEditorView` | DirectX 渲染、鼠标交互、边框/遮挡编辑 |
| **信息面板** | `CImageInfoView` | 文件列表浏览、缩放控制、格式选择 |
| **状态视图** | `CImageStatusView` | 显示图像尺寸、重心、边框顶点坐标 |
| **速度对话框** | `CDialogSetPlaySpeed` | 设置播放 FPS |

## 5. 渲染管线

### 5.1 渲染触发链

```
CImageEditorApp::OnIdle()                    [ImageEditor.cpp:203]
  → CImageEditorDoc::GetImageEditorView()
  → CImageEditorView::Render()               [ImageEditorView.cpp:190]
    → Renderer::Begin(bkColor)
    → CImageEditorView::DrawPic()            [ImageEditorView.cpp:291]
      → Renderer::LoadPictureFromNativePath() (首次加载)
```
