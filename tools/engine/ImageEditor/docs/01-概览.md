## 1. 项目定位

ImageEditor 是 MT3 游戏引擎工具链中的**图像集编辑器**，用于编辑 `.set` 格式的图像集文件（ImageSet）。它提供了一个基于 MFC MDI 的 Windows 桌面应用程序，允许美术人员：

- 打开、浏览和编辑 `.set` 图像集文件
- 设置图像的重心点（Center Point）
- 绘制和调整菱形边框（Border），用于游戏中的碰撞检测和渲染排序
- 添加、调整和删除遮挡多边形（Mask Polygon），用于遮挡关系计算
- 调整缩放比例查看图像
- 设置背景颜色
- 批量转换图像文件格式

## 2. 技术栈

| 技术 | 版本/说明 |
|------|-----------|
| **框架** | MFC (Microsoft Foundation Classes) |
| **应用类型** | MDI (Multiple Document Interface) |
| **编译器** | MSVC v120 (Visual Studio 2013) |
| **字符集** | Unicode |
| **渲染** | DirectX 9 (通过 Nuclear 引擎 `Renderer` 封装) |
| **图像格式** | Nuclear `PImg` 自定义二进制格式 (`.set`) |
| **文件系统** | PFS (通过 `Nuclear::CFileIOManager`) |
| **平台** | Win32 (x86) |

## 5. 构建配置

### 5.1 构建变体

| 配置 | 输出文件名 | MFC 链接 | 运行时库 |
|------|-----------|----------|----------|
