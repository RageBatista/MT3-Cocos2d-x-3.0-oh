## 1. 菱形边框计算算法 (ComputerImgFilePos)

**位置**: [`ImageEditorView.cpp:857`](../ImageEditorView.cpp:857)

### 1.1 算法目的

根据鼠标拖拽的起始点和终止点，计算 32° 俯视角下的菱形边框四个顶点坐标。这是 ImageEditor 的核心算法，用于确定图像在游戏世界中的碰撞/渲染边界。

### 1.2 算法原理

游戏采用 32° 俯视角（实际代码中使用 58° 的余角），将屏幕上的矩形拖拽区域转换为菱形边框。

**投影参数**:
- 俯视角: 32° (代码中 `cos(58/57.3f)` ≈ `cos(1.0126 rad)` ≈ `cos(58°)`)
- 58° 是 90° - 32° 的结果

### 1.3 算法步骤

```cpp
void CImageEditorView::ComputerImgFilePos(
    const CPoint& initialPoint,   // 拖拽起始点
    const CPoint& point)          // 拖拽终止点
{
    // 步骤 1: 记录对角线两端点
    // 左上角 (pos[0])
    m_fPosx[0] = (float)initialPoint.x;
    m_fPosy[0] = (float)initialPoint.y;
    // 右下角 (pos[2])
    m_fPosx[2] = (float)point.x;
    m_fPosy[2] = (float)point.y;

    // 步骤 2: 计算菱形偏移
    float dx = (float)(point.x - initialPoint.x);
    float dy = (float)((point.y - initialPoint.y) / cos(58/57.3f));
    
    // 步骤 3: 分解为菱形两个轴的分量
    float a = (dx + dy) / 2.0f;   // 右上方分量
    float b = (dy - dx) / 2.0f;   // 左上方分量

    // 步骤 4: 计算右上角 (pos[3])
    m_fPosx[3] = a + initialPoint.x;
    m_fPosy[3] = a * cos(58/57.3f) + initialPoint.y;

    // 步骤 5: 计算左下角 (pos[1])
    m_fPosx[1] = -b + initialPoint.x;
    m_fPosy[1] = b * cos(58/57.3f) + initialPoint.y;

    // 步骤 6: 计算各边中点
    for(int i=0; i<4; i++) {
        int j = (i+1)>3 ? 0:(i+1);
        m_pointBorderCent[i].x = (int)(m_fPosx[i] + m_fPosx[j]) / 2;
        m_pointBorderCent[i].y = (int)(m_fPosy[i] + m_fPosy[j]) / 2;
    }
}
```

### 1.4 几何示意

```
                    pos[3] (右上)
                   ╱            ╲
                 ╱                ╲
               ╱                    ╲
    pos[0] (左上) ────── center ────── pos[2] (右下)
               ╲                    ╱
                 ╲                ╱
                   ╲            ╱
                    pos[1] (左下)

    菱形轴:
    - 水平轴: pos[0] → pos[2] (屏幕 X 方向)
    - 垂直轴: pos[1] → pos[3] (受 cos(58°) 压缩)
```

### 1.5 数学推导

设起始点为 `(x0, y0)`，终止点为 `(x2, y2)`：

```
dx = x2 - x0
dy = (y2 - y0) / cos(58°)

菱形右上角:
  x3 = x0 + (dx + dy) / 2
  y3 = y0 + (dx + dy) / 2 × cos(58°)

菱形左下角:
  x1 = x0 - (dy - dx) / 2
  y1 = y0 + (dy - dx) / 2 × cos(58°)
```

## 2. 边框方向分类算法 (SetImgFilePos)

**位置**: [`ImageEditorView.cpp:882`](../ImageEditorView.cpp:882)

### 2.1 算法目的

将计算后的四个顶点坐标（`m_fPosx[4]`, `m_fPosy[4]`）分类为左、下、右、上四个方向，并写入 `PImg` 数据结构。

### 2.2 算法步骤

```cpp
void CImageEditorView::SetImgFilePos(PImg& ImgFile)
{
    // 步骤 1: 在四个顶点中找到 X/Y 方向的极值点
    int IndexMAX_x, IndexMIN_x, IndexMAX_y, IndexMIN_y;
    float fmax_x = -100, fmin_x = 1000000;
    float fmax_y = -100, fmin_y = 1000000;

    for(i=0; i<4; i++) {
        if(m_fPosx[i] > fmax_x) { IndexMAX_x = i; fmax_x = m_fPosx[i]; }
        if(m_fPosx[i] < fmin_x) { IndexMIN_x = i; fmin_x = m_fPosx[i]; }
        if(m_fPosy[i] > fmax_y) { IndexMAX_y = i; fmax_y = m_fPosy[i]; }
        if(m_fPosy[i] < fmin_y) { IndexMIN_y = i; fmin_y = m_fPosy[i]; }
    }

    // 步骤 2: 按方向赋值
    // X 最小的点 → 左 (enum_left)
    ImgFile.pos[enum_left].x = m_fPosx[IndexMIN_x] + scrollX;
    ImgFile.pos[enum_left].y = m_fPosy[IndexMIN_x] + scrollY;

    // X 最大的点 → 右 (enum_right)
    ImgFile.pos[enum_right].x = m_fPosx[IndexMAX_x] + scrollX;
    ImgFile.pos[enum_right].y = m_fPosy[IndexMAX_x] + scrollY;

    // Y 最大的点 → 下 (enum_bottom)
    ImgFile.pos[enum_bottom].x = m_fPosx[IndexMAX_y] + scrollX;
    ImgFile.pos[enum_bottom].y = m_fPosy[IndexMAX_y] + scrollY;

    // Y 最小的点 → 上 (enum_up)
    ImgFile.pos[enum_up].x = m_fPosx[IndexMIN_y] + scrollX;
    ImgFile.pos[enum_up].y = m_fPosy[IndexMIN_y] + scrollY;

    // 步骤 3: 同步到本地边框顶点缓存
    for(i=0; i<4; i++) {
        m_pointBorderVertex[i] = CPoint(ImgFile.pos[i].x, ImgFile.pos[i].y);
    }
}
```

### 2.3 方向定义

| 枚举值 | 含义 | 判定条件 |
|--------|------|----------|
| `enum_left` (0) | 左 | X 坐标最小 |
| `enum_bottom` (1) | 下 | Y 坐标最大（屏幕坐标系 Y 向下） |
| `enum_right` (2) | 右 | X 坐标最大 |
| `enum_up` (3) | 上 | Y 坐标最小 |

## 3. 橡皮筋线算法 (InvertLine)

**位置**: [`ImageEditorView.cpp:842`](../ImageEditorView.cpp:842)

### 3.1 算法目的

使用 GDI 的 R2_NOT（异或）光栅操作模式绘制"橡皮筋线"，实现拖拽时的实时视觉反馈。橡皮筋线在第二次绘制同一位置时会自动擦除，无需额外的背景恢复。

### 3.2 实现

```cpp
void CImageEditorView::InvertLine(CDC* pDC, CPoint ptFrom, CPoint ptTo)
{
    int nOldMode = pDC->SetROP2(R2_NOT);  // 设置异或模式
    pDC->MoveTo(ptFrom);
    pDC->LineTo(ptTo);
    pDC->SetROP2(nOldMode);                // 恢复原模式
}
```

### 3.3 使用模式

在 `OnMouseMove()` 中，橡皮筋线的使用遵循"擦旧画新"模式：

```
1. 绘制旧线 (擦除) → InvertLine(from, oldTo)    // 异或擦除
2. 计算新坐标
3. 绘制新线 (显示) → InvertLine(from, newTo)    // 异或绘制
```

## 4. 两点距离算法 (Computer2PointDis)

**位置**: [`ImageEditorView.cpp:850`](../ImageEditorView.cpp:850)

### 4.1 实现

```cpp
float CImageEditorView::Computer2PointDis(CPoint pt1, CPoint pt2)
{
    float dis = powf((float)(pt1.x - pt2.x), 2.0f) 
              + powf((float)(pt1.y - pt2.y), 2.0f);
    dis = sqrt(dis);
    return dis;
}
```

### 4.2 用途

用于判断鼠标点击是否接近某个关键点（边框顶点或遮挡点）。**命中判定阈值为 3 像素**：

```cpp
float dis = Computer2PointDis(point, borderVertex);
if(dis < 3) {
    // 命中该点
}
```

## 5. 缩放与坐标变换

### 5.1 缩放比例

缩放比例由 `CImageInfoView` 中的滑块控制：

- 滑块范围: 1 ~ 400
- 缩放比例: `m_fZoomRate = sliderPos / 100.0f`
- 范围: 1% ~ 400%

### 5.2 坐标变换规则

所有渲染坐标都经过缩放变换：

```
屏幕坐标 = 世界坐标 × m_fZoomRate - 滚动偏移
```

反向变换（鼠标坐标转世界坐标）：

```
世界坐标 = 屏幕坐标 / m_fZoomRate + 滚动偏移
```

### 5.3 缩放应用位置

| 场景 | 正向变换 (世界→屏幕) | 反向变换 (屏幕→世界) |
|------|---------------------|---------------------|
| 绘制子图位置 | `vectorRct[i].left * fZoomRate` | — |
| 绘制边框顶点 | `imgFile.pos[i] * fZoomRate` | — |
| 绘制遮挡点 | `m_imgMasks[i] * fZoomRate` | — |
| 鼠标设置重心 | — | `point / m_fZoomRate + scrollPos` |
| 鼠标添加遮挡 | — | `point / m_fZoomRate` |
| 鼠标命中检测 | `vertex * fZoomRate` (转为屏幕) | — |

## 7. 纹理 UV 坐标计算

**位置**: [`ImageEditorView.cpp:291`](../ImageEditorView.cpp:291) (DrawPic 函数内)

### 7.1 算法目的

当图像子图部分可见（被滚动裁剪）时，计算正确的纹理 UV 坐标，确保只渲染可见部分。

### 7.2 计算

```cpp
// 源矩形（屏幕坐标）
srcRct.left = vectorRct[i].left * fZoomRate - fScrollPosX;
srcRct.top = vectorRct[i].top * fZoomRate - fScrollPosY;
srcRct.right = min(srcRct.left + fWidth, clientRight);
srcRct.bottom = min(srcRct.top + fHeight, clientBottom);

// UV 偏移
float du = max(0, (fScrollPosX - vectorRct[i].left) / fWidth);
float dv = max(0, (fScrollPosY - vectorRct[i].top) / fHeight);

// UV 范围
m_fcoefU = min(1.0f, srcRct.Width() / fWidth + du);
m_fcoefV = min(1.0f, srcRct.Height() / fHeight + dv);

FRECT srcUV(du, dv, m_fcoefU, m_fcoefV);
```

### 7.3 UV 坐标示意

```
纹理空间:
(0,0)────────────────────(1,0)
  │                          │
  │    (du,dv)─────────┐    │
  │      │  可见区域    │    │
  │      │              │    │
  │      └────(coefU,coefV) │
  │                          │
(0,1)────────────────────(1,1)
```

## 8. 颜色格式转换

**位置**: [`ImageEditorDoc.cpp:263`](../ImageEditorDoc.cpp:263)

### 8.1 BGR → ARGB 转换

`CColorDialog::GetColor()` 返回 COLORREF 格式（0x00BBGGRR），需转换为 ARGB 格式（0xAARRGGBB）：

```cpp
COLORREF color = dlg.GetColor();  // 0x00BBGGRR
m_dwBKcolor = (0xffffffff & 0xff000000)             // Alpha = 0xFF
            | (color & 0x000000ff) << 16             // R → 位置 16-23
            | (color & 0x0000ff00)                    // G 保持位置 8-15
            | (color & 0x00ff0000) >> 16;            // B → 位置 0-7
```

## 10. 命中检测算法

### 10.1 边框顶点命中检测

在 `OnLButtonDown()` 和 `OnMouseMove()` 中，遍历四个边框顶点，计算鼠标点到顶点的距离：

```cpp
for(int i=0; i<4; i++) {
    CPoint borderVertex = m_pointBorderVertex[i] - CPoint(scrollX, scrollY);
    borderVertex.x = (int)(borderVertex.x * m_fZoomRate);
    borderVertex.y = (int)(borderVertex.y * m_fZoomRate);
    
    float dis = Computer2PointDis(point, borderVertex);
    if(dis < 3) {
        // 命中第 i 个顶点
    }
}
```

### 10.2 遮挡点命中检测

类似地，遍历遮挡多边形的所有顶点：

```cpp
for(int i=0; i<cnt; i++) {
    Nuclear::FPOINT fpt = m_imgMasks.at(i).ToFPOINT();
    CPoint pt;
    pt.x = (int)(fpt.x * m_fZoomRate + 0.5f);  // 四舍五入
    pt.y = (int)(fpt.y * m_fZoomRate + 0.5f);
    
    float dis = Computer2PointDis(point, pt);
    if(dis < 3) {
        // 命中第 i 个遮挡点
    }
}
```

**注意**: 遮挡点的命中检测使用了 `+ 0.5f` 进行四舍五入，而边框顶点没有。这可能导致微小的精度差异。
