## 🎯 使用指南

### 查找技能
1. 打开 [skills-index.md](skills-index.md)
2. 使用关键词搜索
3. 选择合适的技能
4. 查看详细文档

### 查找命令
1. 打开 [commands-index.md](commands-index.md)
2. 按功能分类浏览
3. 查看使用示例
4. 执行命令

### 查找代理
1. 打开 [agents-index.md](agents-index.md)
2. 按任务类型选择
3. 查看触发条件
4. 使用代理

### 查找错误
1. 打开 [errors-index.md](errors-index.md)
2. 按错误码搜索
3. 查看解决方案
4. 执行修复
