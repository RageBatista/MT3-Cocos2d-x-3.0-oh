# 生成代码规则

> **优先级**: 🔴 强制性
> **适用范围**: xbean, gnet, tolua++ 生成的代码

---

## 核心原则

```yaml
🚨 重要: 永远不要手动修改生成的代码!

原因:
  - 下次代码生成会覆盖修改
  - 可能破坏框架一致性
  - 调试时难以定位问题
```

---

## xbean 系统

### 生成代码位置

```
server/**/xbean/*.java    # 禁止手动修改
```

### 正确的修改流程

```bash
# 1. 编辑 xbean 定义文件
vim server/tools/jgs/xbean.xml

# 2. 重新生成代码
cd server/tools/jgs
ant xbean

# 3. 编译验证
ant compile
```

### xbean.xml 示例

```xml
<xbean name="Player" key="int playerId">
    <variable name="name" type="string" />
    <variable name="level" type="int" default="1" />
    <variable name="exp" type="long" default="0" />
</xbean>
```

## gnet 系统

### 生成代码位置

```
server/**/rpc/*.java      # 禁止手动修改
```

### 正确的修改流程

```bash
# 1. 编辑协议定义文件
vim server/tools/jgs/protocol.xml

# 2. 重新生成代码
cd server/tools/jgs
ant gnet

# 3. 编译验证
ant compile
```

### protocol.xml 示例

```xml
<protocol name="Login">
    <rpc name="login">
        <argument name="username" type="string" />
        <argument name="password" type="string" />
        <result name="code" type="int" />
        <result name="message" type="string" />
    </rpc>
</protocol>
```

## tolua++ 系统

### 生成代码位置

```
client/**/tolua++/*.cpp   # 禁止手动修改
```

### 正确的修改流程

```bash
# 1. 编辑 .pkg 定义文件
vim client/tolua++-pkgs/MyClass.pkg

# 2. 重新生成绑定
cd client/tolua++-pkgs
./generate.sh

# 3. 编译验证
msbuild mt3.win32.vcxproj
```

### .pkg 文件示例

```cpp
// MyClass.pkg
class MyClass {
    MyClass();
    ~MyClass();

    void setName(const char* name);
    const char* getName();

    static MyClass* create();
};
```

## 识别生成代码

### 特征标记

```java
// xbean 生成的代码通常包含:
// @generated
// DO NOT EDIT - This file is auto-generated

// gnet 生成的代码通常包含:
// Generated by gnet
// Auto-generated code
```

### 文件模式

```yaml
xbean 生成文件:
  - 位于 xbean/ 目录
  - 实现 xbean.Pod 或类似接口
  - 包含序列化/反序列化方法

gnet 生成文件:
  - 位于 rpc/ 目录
  - 实现 RPC 接口
  - 包含协议编解码方法

tolua++ 生成文件:
  - 位于 tolua++/ 目录
  - 文件名通常为 *_tolua.cpp
  - 包含 Lua 绑定代码
```

## 常见错误

### 错误 1: 手动添加字段

```java
// ❌ 错误: 在 xbean 生成的类中添加字段
public class Player extends xbean.Pod {
    private int level;
    private int customField;  // 手动添加的字段会被覆盖!
}

// ✅ 正确: 在 xbean.xml 中添加字段
<variable name="customField" type="int" />
```

### 错误 2: 修改协议方法

```java
// ❌ 错误: 修改 gnet 生成的方法
public void onLogin(String username, String password) {
    // 添加自定义逻辑 - 会被覆盖!
}

// ✅ 正确: 在业务层添加逻辑
public class LoginHandler {
    public void handleLogin(String username, String password) {
        // 自定义逻辑
    }
}
```

### 错误 3: 修改 Lua 绑定

```cpp
// ❌ 错误: 修改 tolua++ 生成的绑定
static int tolua_MyClass_setName00(lua_State* L) {
    // 添加自定义逻辑 - 会被覆盖!
}

// ✅ 正确: 修改 .pkg 文件或 C++ 原始类
```

## 验证生成代码

```bash
# 检查 xbean 生成是否最新
cd server/tools/jgs
ant xbean -Dcheck=true

# 检查 gnet 生成是否最新
ant gnet -Dcheck=true

# 对比生成文件的时间戳
ls -la src/*/xbean/*.java
ls -la src/*/rpc/*.java
```
