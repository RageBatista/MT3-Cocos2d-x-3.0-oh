# 验证门禁规则

> **优先级**: 🔴 强制性  
> **适用范围**: 代码改动、配置改动、提测与发布前

---

## 最低门禁

1. 构建门禁
- 至少完成与改动范围对应的最小构建验证。

2. 规则门禁
- 不得违反工具链约束（Win32 v120 / Android NDK r16 + Ant + JDK8 / Server JDK 1.7-1.8）。
- 不得手工修改生成代码路径（xbean/rpc/tolua++）而无再生成依据。

3. 安全门禁
- 禁止提交密钥、凭证、`.env` 等敏感信息。

4. 回归门禁
- Bug 修复必须包含回归步骤或测试点。

---

## 报告要求

所有验证结果必须输出 PASS/FAIL，并包含：

- 构建结果
- 安全检查结果
- 回归结果
- 残留风险
- 回滚方案
