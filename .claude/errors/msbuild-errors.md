## MSB8020: 工具集不匹配

### 错误描述

```
error MSB8020: 无法找到 v140 的生成工具 (平台工具集 = 'v140')
```

### 典型症状

- 使用 VS2015+ 打开 v120 项目
- 关键词: "无法找到", "平台工具集"

### 根本原因

项目文件指定的工具集在当前 VS 中不存在:

- v120 = VS2013
- v140 = VS2015
- v141 = VS2017
- v142 = VS2019
- v143 = VS2022

### 解决方案

**方案 A: 安装 v120 工具集** (推荐 - MT3 项目必须)
```yaml
1. 打开 Visual Studio Installer
2. 修改 VS2015/2017/2019/2022
3. 单个组件 → "MSVC v120 - VS2013 C++ x64/x86 生成工具"
4. 安装后重新打开项目
```

**方案 B: 修改项目文件** (⚠️ MT3 禁止,会导致 ABI 不兼容)
```xml
<!-- 不要在 MT3 项目中这样做! -->
<PlatformToolset>v143</PlatformToolset>
```

**参考**: [项目规则: 工具链约束](../RULES.md#编译工具链)

## MSB3073: 命令退出码非零

### 错误描述

```
error MSB3073: 命令 "...\tolua++cegui.exe ..." 已退出,代码为 1
```

### 典型症状

- 预构建/后构建命令失败
- 关键词: "退出,代码为"

### 根本原因

项目配置的自定义命令执行失败:

1. **预构建事件**: 代码生成工具 (tolua++, xbean, gnet)
2. **后构建事件**: 文件复制,部署脚本

### 调查步骤

```yaml
步骤 1: 定位命令
  - Read: project.vcxproj → <PreBuildEvent> 或 <PostBuildEvent>
  - 提取命令: tolua++cegui.exe ...

步骤 2: 手动执行命令
  - Bash: "path\to\command.exe" args
  - 查看实际错误信息

步骤 3: 检查依赖
  - 命令依赖的文件是否存在
  - 环境变量是否正确
```

### 解决方案

**常见场景 1: tolua++ 失败**
```yaml
原因: .pkg 文件语法错误
修复: 检查 tolua++-pkgs/*.pkg 文件
```

**常见场景 2: 文件复制失败**
```yaml
原因: 目标路径不存在或权限不足
修复: 创建目录或提升权限
```

## MSB4019: 导入的项目未找到

### 错误描述

```
error MSB4019: 未找到导入的项目 "...\Microsoft.Cpp.Default.props"
```

### 根本原因

MSBuild 无法找到平台工具集的配置文件

### 解决方案

**检查 VS 安装完整性**:
```yaml
1. Visual Studio Installer → 修改
2. 工作负荷 → "使用 C++ 的桌面开发"
3. 修复安装
```
