# jnidb - mkdb 原生数据库工具

## 1. 工具概述

### 1.1 用途说明

jnidb 是 MT3 游戏服务器 mkdb 数据库的原生 C++ 工具，专门用于数据库页的压缩和解压缩操作。该工具通过直接操作 mkdb 的底层存储页，实现以下核心功能：

- **数据库压缩**：将 mkdb 数据页压缩，减少磁盘占用
- **数据库解压**：将压缩的数据页还原为原始格式
- **批量处理**：支持整个数据库目录的批量转换
- **透明遍历**：遍历所有数据页，自动处理压缩/解压逻辑
- **快照支持**：每处理 1000 条记录创建快照，确保数据一致性

### 1.2 典型使用场景

- **数据库迁移**：将生产环境数据库压缩后迁移到测试环境
- **存储优化**：压缩历史数据，释放磁盘空间
- **备份恢复**：压缩数据库备份，减少备份存储成本
- **性能测试**：解压缩数据库用于性能基准测试
- **数据检查**：通过压缩/解压验证数据完整性

### 1.3 关键特性

- **原生性能**：C++ 实现，直接操作 mkdb 底层 API
- **批量转换**：自动遍历目录中的所有数据库文件
- **增量快照**：每 1000 条记录创建快照和提交日志
- **双向操作**：支持压缩（-c）和解压（-d）
- **目录输出**：生成带 `_c` 或 `_d` 后缀的输出目录
- **统计信息**：可选的压缩率统计（需定义 `__STATISTIC`）

## 4. 配置与使用

### 4.1 基本命令格式

```bash
dbtool [-c | -d] <DBdir>
```

**参数说明**：

- `-c`：压缩模式（compress）
- `-d`：解压模式（decompress）
- `<DBdir>`：mkdb 数据库目录路径

### 4.2 压缩数据库

```bash
# 压缩数据库目录
./dbtool -c /data/gamedb
```

输出目录：`/data/gamedb_c/`

### 4.3 解压数据库

```bash
# 解压数据库目录
./dbtool -d /data/gamedb_c
```

输出目录：`/data/gamedb_c_d/`

## 6. 注意事项

### 6.1 安全注意事项

- **必须先备份**：在执行压缩/解压前务必备份原始数据
- **验证完整性**：处理后验证文件数量和大小
- **测试恢复**：在测试环境先验证压缩/解压流程

### 6.2 性能考虑

- 典型数据库（~10GB）：5-15 分钟
- 大数据库（>50GB）：30-60 分钟
- 建议在 I/O 性能较好的磁盘上执行
