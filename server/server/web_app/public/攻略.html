普陀山

普陀山门派定位

辅助治疗核心，队伍中“奶位”稳定。新手组队友好，容错高，适合长期养成。

门派技能
开局流程：先别管别的，只做主线可直升 65；65 前不建议做师门（文档提示有 bug 风险），剧情做完再加帮派、做日常、点修。
队伍搭配：“奶 + 封”基本必带；输出按喜好选。
封系推荐：方寸（满经脉可定身 2 个）。
法系推荐：魔王（暴击伤害高，地煞术机制强）。
输出门派：花果（暴击几率大）、月宫（可封可输出）、狮驼（秒 7 但出手慢）等。
材料与宠物（文档整理）
材料：日常怪掉千叶碎片/长生锁。千叶碎片可合成千叶莲露，给宝宝吃可降 20 级但属性不降（每只最多 5 次）。长生锁可换孩子技能等。
宠物：神兽可过渡（文档提到神鸡过渡性价比高）；后期合宠追 12 技能全红；合之前先把成长/资质与必带技能处理好。
装备：可打无级别；停级建议做 100 无级别（只做武器），其他部位按停级做对应等级装备以带物爆/法爆等特效；文档提示无级别与物爆/法爆类特效不可共存。

普陀山攻略

  1. 开局：主线优先到 65，剧情结束再做师门/加帮派点修。
  2. 门派定位：辅助治疗核心，适合新手与长期养成。
  3. 队伍结构：奶封必带；封系优先方寸；法系优先魔王。
  4. 宠物路线：神兽过渡 → 合宠追 12 技能全红。
  5. 材料路线：千叶碎片/长生锁/转盘兑换与特卖道具。
