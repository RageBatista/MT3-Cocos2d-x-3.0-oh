# 部署指南

## 1. 环境要求

### 1.1 服务器要求

#### 操作系统
- Linux（推荐CentOS 7+、Ubuntu 18.04+）
- Windows Server 2016+

#### 硬件要求
| 资源 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 2核 | 4核+ |
| 内存 | 4GB | 8GB+ |
| 硬盘 | 50GB | 100GB+ |

### 1.2 软件要求

#### PHP环境
- **版本**：PHP >= 8.0
- **必需扩展**：
  - PDO
  - PDO_MySQL
  - mbstring
  - curl
  - json
  - openssl
  - gd
  - zip
  - fileinfo
  - session
  - xml（用于phpspreadsheet）
  - dom（用于phpspreadsheet）
  - simplexml（用于phpspreadsheet）

#### 数据库
- **类型**：MySQL 8.0+ 或 MariaDB 10.3+
- **字符集**：utf8mb4

#### Web服务器
- Nginx 1.18+（推荐）
- Apache 2.4+

#### 其他服务
- Redis 5.0+（可选，用于缓存）
- Java JRE 8+（用于JMX工具）

## 3. Web服务器配置

### 3.1 Nginx配置

#### 配置文件示例
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/mt3_web/public;
    index index.php index.html;

    # 日志配置
    access_log /var/log/nginx/mt3_web_access.log;
    error_log /var/log/nginx/mt3_web_error.log;

    # PHP配置
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.0-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # 静态文件配置
    location ~* \.(jpg|jpeg|gif|png|css|js|ico|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 禁止访问敏感文件
    location ~ /\.(?!well-known).* {
        deny all;
    }

    # 禁止访问.env文件
    location ~ /\.env {
        deny all;
    }

    # URL重写
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }
}
```

#### 重启Nginx
```bash
sudo systemctl restart nginx
```

### 3.2 Apache配置

#### 配置文件示例
```apache
<VirtualHost *:80>
    ServerName your-domain.com
    DocumentRoot /var/www/mt3_web/public

    <Directory /var/www/mt3_web/public>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted

        # 禁止访问敏感文件
        <FilesMatch "^\.env">
            Require all denied
        </FilesMatch>
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/mt3_web_error.log
    CustomLog ${APACHE_LOG_DIR}/mt3_web_access.log combined
</VirtualHost>
```

#### 启用重写模块
```bash
sudo a2enmod rewrite
```

#### 重启Apache
```bash
sudo systemctl restart apache2
```

## 5. 生产环境优化

### 5.1 PHP优化

#### php.ini配置
```ini
; 内存限制
memory_limit = 256M

; 执行时间限制
max_execution_time = 300

; 上传文件大小限制
upload_max_filesize = 20M
post_max_size = 20M

; 错误报告
display_errors = Off
log_errors = On
error_log = /var/log/php/error.log

; OPcache配置
opcache.enable = 1
opcache.memory_consumption = 128
opcache.interned_strings_buffer = 8
opcache.max_accelerated_files = 4000
opcache.revalidate_freq = 60
opcache.fast_shutdown = 1
opcache.enable_cli = 1
```

### 5.2 数据库优化

#### my.cnf配置
```ini
[mysqld]
# 连接数
max_connections = 500

# 缓冲区大小
innodb_buffer_pool_size = 1G
innodb_log_file_size = 256M
innodb_log_buffer_size = 8M

# 查询缓存
query_cache_size = 64M
query_cache_type = 1

# 慢查询日志
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2
```

### 5.3 Nginx优化

#### nginx.conf配置
```nginx
# 工作进程数
worker_processes auto;

# 连接数
events {
    worker_connections 1024;
}

# 缓冲区大小
client_body_buffer_size 10m;

# Gzip压缩
gzip on;
gzip_vary on;
gzip_min_length 1024;
gzip_types text/plain text/css text/xml text/javascript application/x-javascript application/xml+rss application/json application/javascript;
```

### 6.2 HTTPS配置

#### 获取SSL证书
```bash
# 使用Let's Encrypt
sudo apt-get install certbot
sudo certbot certonly --webroot -w /var/www/mt3_web/public -d your-domain.com
```

#### Nginx HTTPS配置
```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    root /var/www/mt3_web/public;

    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 其他配置...
}

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

### 6.3 防火墙配置

#### UFW防火墙
```bash
# 启用UFW
sudo ufw enable

# 允许SSH
sudo ufw allow 22/tcp

# 允许HTTP
sudo ufw allow 80/tcp

# 允许HTTPS
sudo ufw allow 443/tcp

# 查看状态
sudo ufw status
```

#### iptables防火墙
```bash
# 允许HTTP
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# 允许HTTPS
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 保存规则
sudo iptables-save
```

## 8. 备份策略

### 8.1 数据库备份

#### 自动备份脚本
```bash
#!/bin/bash
# 数据库备份脚本
BACKUP_DIR="/backup/mysql"
DATE=$(date +%Y%m%d_%H%M%S)
MYSQL_USER="root"
MYSQL_PASS="your_password"
MYSQL_DB="mhxy"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
mysqldump -u$MYSQL_USER -p$MYSQL_PASS $MYSQL_DB | gzip > $BACKUP_DIR/mhxy_$DATE.sql.gz

# 删除7天前的备份
find $BACKUP_DIR -name "mhxy_*.sql.gz" -mtime +7 -delete

echo "Backup completed: mhxy_$DATE.sql.gz"
```

#### 定时任务
```bash
# 添加到crontab
crontab -e

# 每天凌晨2点备份
0 2 * * * /path/to/backup.sh
```

### 8.2 文件备份

#### 备份脚本
```bash
#!/bin/bash
# 文件备份脚本
BACKUP_DIR="/backup/files"
SOURCE_DIR="/var/www/mt3_web"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份文件
tar -czf $BACKUP_DIR/mt3_web_$DATE.tar.gz $SOURCE_DIR

# 删除7天前的备份
find $BACKUP_DIR -name "mt3_web_*.tar.gz" -mtime +7 -delete

echo "Backup completed: mt3_web_$DATE.tar.gz"
```

## 10. 更新部署

### 10.1 代码更新流程
```bash
# 1. 备份当前版本
cp -r /var/www/mt3_web /backup/mt3_web_old

# 2. 拉取最新代码
cd /var/www/mt3_web
git pull origin master

# 3. 安装依赖
composer install --no-dev --optimize-autoloader

# 4. 清理缓存
php think clear

# 5. 设置权限
chmod -R 755 runtime
chmod -R 777 public/uploads

# 6. 重启服务
sudo systemctl restart nginx
sudo systemctl restart php8.0-fpm
```

### 10.2 数据库更新流程
```bash
# 1. 备份数据库
mysqldump -u root -p mhxy | gzip > /backup/mysql/mhxy_pre_update.sql.gz

# 2. 导入更新
mysql -u root -p mhxy < database/update.sql

# 3. 验证更新
mysql -u root -p -e "USE mhxy; SHOW TABLES;"
```
