# 监控指南

## 1. 日志监控

### 1.1 日志文件位置

#### 日志目录
```
runtime/log/
```

#### 日志文件命名规则
- `YYYYmmdd.log`：按日期分割的日志文件（例如：20240115.log）

**注意**：项目不使用单独的sql.log文件，SQL日志记录在按日期分割的日志文件中，仅在APP_DEBUG=true时记录。

### 1.2 日志级别

#### 日志级别说明
| 级别 | 说明 | 使用场景 |
|------|------|----------|
| info | 一般信息 | 正常操作记录、GM命令执行、玩家认证等 |
| warning | 警告信息 | 潜在问题、恶意IP、频率限制等 |
| error | 错误信息 | 程序错误、认证失败、数据库错误等 |

**注意**：项目实际使用的日志级别为info、warning、error，不包含debug和critical级别。

#### 查看最新日志

#### 查看GM命令日志


### 1.4 日志分析

#### 统计错误数量
```bash

```

#### 统计攻击次数
```bash

```

#### 查找特定IP的日志


#### 查找特定用户的操作


### 1.5 日志轮转

#### 配置日志轮转
创建 `/etc/logrotate.d/mt3_web` 文件：
```
/path/to/mt3_web/runtime/log/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 0644 www-data www-data
}
```

#### 测试日志轮转
```bash
sudo logrotate -d /etc/logrotate.d/mt3_web
```

## 2. 性能监控

### 2.1 PHP性能监控

#### 查看PHP-FPM状态
```bash
# 查看PHP-FPM进程状态
sudo systemctl status php8.0-fpm

# 查看PHP-FPM进程数
ps aux | grep php-fpm | wc -l

# 查看PHP-FPM内存使用
ps aux | grep php-fpm | awk '{sum+=$4} END {print sum}'
```

#### PHP-FPM慢日志
编辑 `/etc/php/8.0/fpm/pool.d/www.conf`：
```ini
slowlog = /var/log/php8.0-fpm-slow.log
request_slowlog_timeout = 5s
```

查看慢日志：
```bash
tail -f /var/log/php8.0-fpm-slow.log
```

#### OPcache监控
```bash
# 查看OPcache状态
php -r "var_dump(opcache_get_status());"
```

#### 查看MySQL状态


#### 查看慢查询

```bash
mysql -u root -p -e "SELECT table_schema AS 'Database', ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS 'Size (MB)' FROM information_schema.tables GROUP BY table_schema;"
```

## 4. 告警配置

### 4.1 日志告警

#### 使用Logwatch
安装Logwatch：
```bash
sudo apt-get install logwatch
```

配置 `/etc/logwatch/conf/logwatch.conf`：
```
LogDir = /var/log
TmpDir = /var/cache/logwatch
MailTo = admin@example.com
Range = yesterday
Detail = High
```

#### 使用Fail2ban
安装Fail2ban：
```bash
sudo apt-get install fail2ban
```

配置 `/etc/fail2ban/jail.local`：
```ini
[mt3-web-security]
enabled = true
port = http,https
filter = mt3-web-security
logpath = /path/to/mt3_web/runtime/log/*.log
maxretry = 5
bantime = 3600
findtime = 600
```

创建 `/etc/fail2ban/filter.d/mt3-web-security.conf`：
```ini
[Definition]
failregex = Security Attack: .* ip:<HOST>
ignoreregex =
```

### 4.2 系统资源告警

#### 使用Monit
安装Monit：
```bash
sudo apt-get install monit
```

配置 `/etc/monit/monitrc`：
```
set daemon 60
set logfile /var/log/monit.log
set alert admin@example.com

check process php-fpm with pidfile /var/run/php/php8.0-fpm.pid
    start program = "/usr/sbin/service php8.0-fpm start"
    stop program = "/usr/sbin/service php8.0-fpm stop"
    if failed host localhost port 9000 protocol http then restart
    if 5 restarts within 5 cycles then timeout

check process nginx with pidfile /var/run/nginx.pid
    start program = "/usr/sbin/service nginx start"
    stop program = "/usr/sbin/service nginx stop"
    if failed host localhost port 80 protocol http then restart
    if 5 restarts within 5 cycles then timeout

check process mysql with pidfile /var/run/mysqld/mysqld.pid
    start program = "/usr/sbin/service mysql start"
    stop program = "/usr/sbin/service mysql stop"
    if failed host localhost port 3306 protocol mysql then restart
    if 5 restarts within 5 cycles then timeout
```

### 4.3 自定义告警脚本

#### 创建告警脚本
创建 `/usr/local/bin/mt3_web_alert.sh`：
```bash
#!/bin/bash

LOG_FILE="/path/to/mt3_web/runtime/log/$(date +%Y%m%d).log"
ALERT_FILE="/tmp/mt3_web_alert.log"

# 检查错误数量
ERROR_COUNT=$(grep -c "error" "$LOG_FILE" 2>/dev/null || echo 0)

# 检查攻击数量
ATTACK_COUNT=$(grep -c "Security Attack" "$LOG_FILE" 2>/dev/null || echo 0)

# 发送告警
if [ "$ERROR_COUNT" -gt 100 ]; then
    echo "$(date): 错误数量过多: $ERROR_COUNT" >> "$ALERT_FILE"
    # 发送邮件或短信
fi

if [ "$ATTACK_COUNT" -gt 50 ]; then
    echo "$(date): 攻击数量过多: $ATTACK_COUNT" >> "$ALERT_FILE"
    # 发送邮件或短信
fi
```

#### 添加到crontab
```bash
# 每小时检查一次
0 * * * * /usr/local/bin/mt3_web_alert.sh
```

### 5.3 ELK Stack

#### 安装Elasticsearch
```bash
sudo apt-get install elasticsearch
```

#### 安装Logstash
```bash
sudo apt-get install logstash
```

#### 配置Logstash
创建 `/etc/logstash/conf.d/mt3_web.conf`：
```
input {
  file {
    path => "/path/to/mt3_web/runtime/log/*.log"
    start_position => "beginning"
  }
}

filter {
  grok {
    match => { "message" => "%{TIMESTAMP_ISO8601:timestamp} \[%{DATA:level}\] %{GREEDYDATA:message}" }
  }
}

output {
  elasticsearch {
    hosts => ["localhost:9200"]
    index => "mt3_web-%{+YYYY.MM.dd}"
  }
}
```

#### 安装Kibana
```bash
sudo apt-get install kibana
```
