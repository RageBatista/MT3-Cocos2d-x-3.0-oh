# 配置指南（源码对齐版）

> 技术细节参考：[`../03-参考_Reference/03-配置文件说明.md`](../03-参考_Reference/03-配置文件说明.md)

## 1. 配置优先级

当前项目配置来源按优先级理解为：

1. `.env` / `.env.local`
2. `config/*.php`
3. 代码默认值

注意：部分配置在 `config/*.php` 是固定值，不会被 `.env` 直接覆盖（例如 `config/app.php` 的 `app_debug`）。

## 2. `.env` 最小必填项

## 2.1 数据库

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=mhxy
DB_USER=root
DB_PASS=your_password
DB_CHARSET=utf8mb4
```

## 2.2 后台与玩家安全

```ini
ADMIN_AUTH_SECRET_KEY=change_me_admin_auth_secret
MASTER_VERIFY_PASSWORD=change_me_master_verify_password
OP_SECRET_SALT=change_me_op_secret_salt_at_least_32_chars
PLAYER_AUTH_ENABLED=true
```

## 2.3 JMX

```ini
JMX_AUTH_ENABLED=true
JMX_USERNAME=super_admin
JMX_PASSWORD=change_me
JMX_TOKEN=change_me
```

## 2.4 运行环境

```ini
APP_DEBUG=false
APP_ENV=production
```

## 3. 常见配置文件怎么改

## 3.1 `config/database.php`

来源：`DB_*` 变量。  
改动后优先做数据库连通性测试，再访问后台验证查询页。

## 3.2 `config/security.php`

核心分组：

1. `admin_auth`
2. `player_auth`
3. `pay_callback`
4. `debug_endpoints`
5. `jmx_auth`

建议生产保持：

1. `pay_callback.replay_protection_enabled=true`
2. `pay_callback.idempotency_enabled=true`
3. `pay_callback.log_masking_enabled=true`
4. `debug_endpoints.pay_callback_probe_enabled=false`

## 3.3 `config/player.php`

常用项：

1. `auth_enabled`
2. `op_secret_salt`
3. `signature_timeout`
4. `item_whitelist_cache_ttl`
5. `pet_whitelist_cache_ttl`
6. `tcp_direct_enabled`

## 3.4 `config/transfer.php`

关键开关：

```php
'gm_migration_enabled' => env('TRANSFER_GM_MIGRATION_ENABLED', false),
```

默认 `false`，表示转区执行为绑定级迁移（`binding_only`）。

## 3.5 `config/cache.php`

当前逻辑为：Redis 可用则默认 Redis，不可用自动降级 File。  
即使降级可运行，也建议生产启用 Redis 以降低并发风险。

## 4. 高风险配置变更 checklist

改动以下任一项前，建议先备份并安排窗口：

1. `ADMIN_AUTH_SECRET_KEY`
2. `OP_SECRET_SALT`
3. `MASTER_VERIFY_PASSWORD`
4. `JMX_*`
5. `TRANSFER_GM_MIGRATION_ENABLED`

## 5. 变更后验证

## 5.1 功能验证

1. 后台登录：`/index.php?s=/login/index`
2. 玩家登录：`/index.php?s=/player/auth/login`
3. 玩家绑定/角色列表查询
4. 支付回调链路（测试环境）

## 5.2 日志验证

检查：

1. `runtime/log/{Ymd}.log`
2. `runtime/log/{Ymd}_warning.log`

确认无新增致命错误与持续告警。

## 6. 常见问题

## 6.1 改了 `.env` 不生效

处理顺序：

1. 检查键名是否与代码读取一致
2. 确认是否被 `config/*.php` 固定值覆盖
3. 重启 PHP-FPM / Web 服务
4. 清理运行时缓存后重试

## 6.2 出现 “CSRF令牌无效”

优先检查：

1. 页面是否长期停留后提交
2. 是否跨标签页复用了旧 token
3. 是否存在代理/缓存层篡改表单或请求头

## 6.3 后台登录异常（高频）

优先检查：

1. `ADMIN_AUTH_SECRET_KEY` 是否为空
2. `MASTER_VERIFY_PASSWORD` 是否为占位值
3. Session 可写性（`runtime` 权限）
