# 配置指南

本指南提供项目配置的操作步骤。详细的配置项说明请参考技术文档：[配置文件说明](../02-技术文档/03-配置文件说明.md)

## 1. 环境变量配置

### 1.1 复制环境变量文件

```bash
# 复制示例文件
cp .env.example .env
```

### 1.2 编辑环境变量文件

使用文本编辑器打开 `.env` 文件，根据实际情况修改配置项。

### 1.3 必需配置项

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| DB_HOST | 数据库服务器地址 | localhost |
| DB_PORT | 数据库端口 | 3306 |
| DB_NAME | 数据库名称 | mhxy |
| DB_USER | 数据库用户名 | root |
| DB_PASS | 数据库密码 | your_password |
| DB_CHARSET | 数据库字符集 | utf8mb4 |
| JMX_AUTH_ENABLED | 是否启用JMX认证 | true |
| JMX_USERNAME | JMX认证用户名 | super_admin |
| JMX_PASSWORD | JMX认证密码 | your_password |
| JMX_TOKEN | JMX认证Token | your_token |
| MASTER_VERIFY_PASSWORD | 超级管理员二次验证密码 | your_password |
| APP_DEBUG | 是否开启调试模式 | false |
| APP_ENV | 运行环境 | production |

**注意**：生产环境务必将 `APP_DEBUG` 设置为 `false`。

### 1.4 可选配置项

| 配置项 | 说明 | 示例值 |
|--------|------|--------|
| PLAYER_AUTH_ENABLED | 是否启用玩家认证 | true |
| OP_SECRET_SALT | 签名密钥 | your_salt |
| SIGNATURE_TIMEOUT | 签名超时时间（秒） | 300 |
| ITEM_WHITELIST_CACHE_TTL | 物品白名单缓存时间（秒） | 3600 |
| PET_WHITELIST_CACHE_TTL | 宠物白名单缓存时间（秒） | 3600 |
| TCP_DIRECT_ENABLED | 是否启用TCP直连 | true |

详细的配置项说明请参考：[配置文件说明](../02-技术文档/03-配置文件说明.md)

## 2. 数据库配置

### 2.1 创建数据库

```sql
CREATE DATABASE mhxy CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2.2 导入数据库结构

```bash
# 使用命令行导入
mysql -u root -p mhxy < database/mhxy.sql

# 或使用MySQL客户端导入
mysql -u root -p
use mhxy;
source database/mhxy.sql;
```

### 2.3 配置数据库连接

在 `.env` 文件中配置数据库连接信息：

```bash
DB_HOST=localhost
DB_PORT=3306
DB_NAME=mhxy
DB_USER=root
DB_PASS=your_password
DB_CHARSET=utf8mb4
```

### 2.4 测试数据库连接

```bash
# 使用命令行测试
mysql -u root -p -h localhost -P 3306 mhxy
```

详细的数据库配置说明请参考：[配置文件说明](../02-技术文档/03-配置文件说明.md)

## 6. 缓存配置

### 6.1 选择缓存驱动

项目支持以下缓存驱动：
- File（文件缓存）
- Redis（Redis缓存）

### 6.2 配置Redis缓存

如果使用Redis缓存，需要安装Redis扩展并配置：

```bash
# 安装Redis扩展
pecl install redis

# 在php.ini中启用
extension=redis.so
```

Redis配置在 `config/cache.php` 中，默认配置：

```php
'redis' => [
    'type'   => 'redis',
    'host'   => '127.0.0.1',
    'port'   => 6379,
    'password' => '',
    'select' => 0,
    'timeout'  => 0,
    'expire'   => 0,
    'persistent' => false,
    'prefix'   => '',
],
```

详细的缓存配置说明请参考：[配置文件说明](../02-技术文档/03-配置文件说明.md)

## 9. 常见问题

### 9.1 数据库连接失败

**问题**：无法连接到数据库

**解决方案**：
1. 检查数据库服务是否启动
2. 检查 `.env` 中的数据库配置是否正确
3. 检查数据库用户名和密码是否正确
4. 检查数据库端口是否正确

### 9.2 环境变量未生效

**问题**：修改 `.env` 文件后配置未生效

**解决方案**：
1. 清除缓存：`php think clear`
2. 重启Web服务器
3. 检查 `.env` 文件格式是否正确

### 9.3 字符集问题

**问题**：数据库存储中文乱码

**解决方案**：
1. 确保数据库字符集为 `utf8mb4`
2. 确保表字符集为 `utf8mb4`
3. 确保 `.env` 中 `DB_CHARSET` 设置为 `utf8mb4`

详细的故障排查请参考：[故障排查指南](04-故障排查.md)
