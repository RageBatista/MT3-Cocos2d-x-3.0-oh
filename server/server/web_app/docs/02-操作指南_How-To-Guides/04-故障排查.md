# 故障排查指南

## 1. 常见问题及解决方案

### 1.1 页面无法访问

#### 问题描述
访问网站时出现以下情况：
- 404 Not Found
- 500 Internal Server Error
- 空白页面

#### 排查步骤

##### 1. 检查Web服务器状态
```bash
# Nginx
sudo systemctl status nginx

# Apache
sudo systemctl status apache2
```

##### 2. 检查Web服务器配置
```bash
# Nginx
sudo nginx -t

# Apache
sudo apache2ctl configtest
```

##### 3. 检查Web服务器错误日志
```bash
# Nginx
tail -f /var/log/nginx/error.log

# Apache
tail -f /var/log/apache2/error.log
```

##### 4. 检查PHP-FPM状态
```bash
sudo systemctl status php8.0-fpm
```

##### 5. 检查PHP错误日志
```bash
tail -f /var/log/php8.0-fpm.log
```

##### 6. 检查应用日志
```bash
tail -f runtime/log/$(date +%Y%m%d).log
```

#### 常见原因及解决方案

| 原因 | 解决方案 |
|------|----------|
| Web服务器未启动 | 启动Web服务器 |
| 配置文件错误 | 修正配置文件 |
| PHP-FPM未启动 | 启动PHP-FPM |
| 目录权限不足 | 修正目录权限 |
| .htaccess文件错误 | 检查重写规则 |

### 1.2 数据库连接失败

#### 问题描述
出现以下错误：
- SQLSTATE[HY000] [2002] Connection refused
- SQLSTATE[HY000] [2002] No such file or directory
- Access denied for user

#### 排查步骤

##### 1. 检查MySQL服务状态
```bash
sudo systemctl status mysql
```

##### 2. 检查MySQL端口
```bash
netstat -tuln | grep 3306
```

##### 3. 测试数据库连接
```bash
mysql -h localhost -u root -p
```

##### 4. 检查环境变量配置
```bash
cat .env | grep DB_
```

##### 5. 检查数据库配置文件
```bash
cat config/database.php
```

#### 常见原因及解决方案

| 原因 | 解决方案 |
|------|----------|
| MySQL服务未启动 | 启动MySQL服务 |
| 端口被占用 | 修改MySQL端口 |
| 用户名或密码错误 | 修正.env文件中的配置 |
| 数据库不存在 | 创建数据库 |
| 防火墙阻止 | 开放MySQL端口 |

### 1.3 登录失败

#### 问题描述
无法登录后台系统

#### 排查步骤

##### 1. 检查Session配置
```bash
cat config/session.php
```

##### 2. 检查runtime目录权限
```bash
ls -la runtime/
```

##### 3. 检查登录日志
```bash
grep -i "login" runtime/log/*.log
```

##### 4. 检查Check中间件
```bash
cat app/middleware/Check.php
```

#### 常见原因及解决方案

| 原因 | 解决方案 |
|------|----------|
| runtime目录权限不足 | 修正runtime目录权限 |
| Session配置错误 | 修正Session配置 |
| 密码错误 | 重置密码 |
| Token验证失败 | 清除Session重新登录 |
| Check中间件错误 | 检查中间件逻辑 |

### 1.4 支付回调失败

#### 问题描述
支付成功但订单状态未更新

#### 排查步骤

##### 1. 检查支付回调日志
```bash
grep -i "notify" runtime/log/*.log
```

##### 2. 检查Notify控制器
```bash
cat app/api/controller/Notify.php
```

##### 3. 检查订单状态
```sql
SELECT * FROM user_order WHERE orderid = '订单号';
```

##### 4. 检查佣金记录
```sql
SELECT * FROM agent_commission WHERE orderid = '订单号';
```

#### 常见原因及解决方案

| 原因 | 解决方案 |
|------|----------|
| 签名验证失败 | 检查支付平台配置 |
| 回调URL错误 | 修正回调URL |
| 数据库连接失败 | 检查数据库连接 |
| 佣金分发失败 | 检查CommissionService |

### 1.5 GM命令执行失败

#### 问题描述
GM命令无法执行或执行失败

#### 排查步骤

##### 1. 检查JMX配置日志
```bash
grep -i "JMX配置" runtime/log/*.log
```

##### 2. 检查GM命令日志
```bash
grep -i "执行GM命令" runtime/log/*.log
```

##### 3. 检查Java环境
```bash
java -version
```

##### 4. 检查JMX工具
```bash
ls -la jmxc/jmxc.jar
```

##### 5. 测试JMX连接
```bash
cd jmxc
java -jar jmxc.jar <username> <password> <server_ip> <port> gm userId=4096 roleId=<player_id> token=<token>
```

#### 常见原因及解决方案

| 原因 | 解决方案 |
|------|----------|
| JMX认证失败 | 检查JMX配置 |
| Java环境未安装 | 安装Java JRE |
| 服务器IP错误 | 修正服务器IP |
| 端口错误 | 修正GM端口 |
| Token错误 | 检查JMX_TOKEN |

## 2. 错误码说明

### 2.1 系统错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 1 | 操作成功 | - |
| 0 | 操作失败 | 检查日志 |
| -1 | 未登录 | 重新登录 |
| -2 | 权限不足 | 联系管理员 |
| -3 | 参数错误 | 检查请求参数 |
| -4 | 数据不存在 | 检查数据ID |
| -5 | 数据已存在 | 检查重复数据 |

### 2.2 HTTP状态码

| 状态码 | 说明 | 解决方案 |
|--------|------|----------|
| 200 | 请求成功 | - |
| 301 | 永久重定向 | 更新URL |
| 302 | 临时重定向 | 更新URL |
| 400 | 请求错误 | 检查请求参数 |
| 401 | 未授权 | 检查登录状态 |
| 403 | 禁止访问 | 检查权限 |
| 404 | 未找到 | 检查URL |
| 500 | 服务器错误 | 检查日志 |
| 502 | 网关错误 | 检查PHP-FPM |
| 503 | 服务不可用 | 检查服务状态 |
| 504 | 网关超时 | 检查超时配置 |

### 2.3 数据库错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 1045 | Access denied | 检查用户名和密码 |
| 1049 | Unknown database | 创建数据库 |
| 1050 | Table exists | 删除已存在的表 |
| 1062 | Duplicate entry | 检查重复数据 |
| 1064 | Syntax error | 检查SQL语法 |
| 1146 | Table doesn't exist | 创建表 |
| 2002 | Connection refused | 检查MySQL服务 |
| 2003 | Can't connect | 检查MySQL端口 |

## 3. 日志分析方法

### 3.1 日志查看命令

#### 查看最新日志
```bash
tail -f runtime/log/$(date +%Y%m%d).log
```

#### 查看最近100行
```bash
tail -n 100 runtime/log/$(date +%Y%m%d).log
```

#### 查看错误日志
```bash
grep -i "error" runtime/log/*.log
```

#### 查看警告日志
```bash
grep -i "warning" runtime/log/*.log
```

#### 查看特定时间段的日志
```bash
grep "2024-01-01 10:" runtime/log/20240101.log
```

### 3.2 日志分析技巧

#### 统计错误数量
```bash
grep -c "error" runtime/log/*.log
```

#### 统计攻击次数
```bash
grep -c "Security Attack" runtime/log/*.log
```

#### 查找特定IP的日志
```bash
grep "192.168.1.1" runtime/log/*.log
```

#### 查找特定用户的操作
```bash
grep "username=admin" runtime/log/*.log
```

#### 查找特定错误
```bash
grep -A 5 -B 5 "具体错误信息" runtime/log/*.log
```

### 3.3 日志分析工具

#### 使用awk分析
```bash
# 统计每小时访问量
awk '{print $2}' runtime/log/*.log | cut -d: -f1 | sort | uniq -c
```

#### 使用sed分析
```bash
# 替换敏感信息
sed 's/password=.*$/password=***/g' runtime/log/*.log
```

#### 使用grep分析
```bash
# 查找所有错误
grep -E "error|Error|ERROR" runtime/log/*.log
```

## 4. 性能问题排查

### 4.1 页面加载慢

#### 排查步骤

##### 1. 检查服务器资源
```bash
top
free -h
df -h
```

##### 2. 检查数据库慢查询
```bash
mysql -u root -p -e "SHOW VARIABLES LIKE 'slow_query_log';"
```

##### 3. 检查PHP-FPM慢日志
```bash
tail -f /var/log/php8.0-fpm-slow.log
```

##### 4. 检查网络延迟
```bash
ping your-domain.com
```

#### 优化建议

| 问题 | 优化方案 |
|------|----------|
| CPU使用率高 | 优化代码，增加服务器 |
| 内存不足 | 增加内存，优化缓存 |
| 磁盘I/O高 | 使用SSD，优化数据库 |
| 网络延迟高 | 使用CDN，优化图片 |

### 4.2 数据库性能差

#### 排查步骤

##### 1. 检查慢查询
```bash
mysql -u root -p -e "SHOW FULL PROCESSLIST;"
```

##### 2. 分析慢查询日志
```bash
mysqldumpslow -s t -t 10 /var/log/mysql/mysql-slow.log
```

##### 3. 检查索引
```sql
SHOW INDEX FROM table_name;
EXPLAIN SELECT * FROM table_name WHERE condition;
```

#### 优化建议

| 问题 | 优化方案 |
|------|----------|
| 慢查询 | 优化SQL语句，添加索引 |
| 索引缺失 | 添加合适的索引 |
| 表锁 | 优化事务，减少锁时间 |
| 连接数过多 | 增加连接池大小 |

## 5. 安全问题排查

### 5.1 SQL注入攻击

#### 排查步骤

##### 1. 检查安全攻击日志
```bash
grep -i "SQL_INJECTION" runtime/log/*.log
```

##### 2. 检查Security中间件
```bash
cat app/middleware/Security.php
```

##### 3. 检查数据库查询
```bash
grep -r "SELECT.*WHERE.*\$" app/
```

#### 防护措施

- 启用Security中间件
- 使用ORM参数绑定
- 输入验证和过滤

### 5.2 XSS攻击

#### 排查步骤

##### 1. 检查XSS攻击日志
```bash
grep -i "XSS" runtime/log/*.log
```

##### 2. 检查输出转义
```bash
grep -r "echo.*\$" app/
```

#### 防护措施

- 启用XSS防护
- 输出时HTML转义
- 使用CSP策略

### 5.3 越权访问

#### 排查步骤

##### 1. 检查越权日志
```bash
grep -i "越权" runtime/log/*.log
```

##### 2. 检查权限验证
```bash
grep -r "if.*myAdmin\['id'\]" app/
```

#### 防护措施

- 严格的权限验证
- 记录权限变更
- 使用PermissionAuditService

## 6. 紧急故障处理

### 6.1 网站无法访问

#### 紧急处理步骤

##### 1. 检查服务状态
```bash
sudo systemctl status nginx php8.0-fpm mysql
```

##### 2. 重启服务
```bash
sudo systemctl restart nginx php8.0-fpm mysql
```

##### 3. 检查防火墙
```bash
sudo firewall-cmd --list-all
```

##### 4. 检查DNS
```bash
nslookup your-domain.com
```

### 6.2 数据库崩溃

#### 紧急处理步骤

##### 1. 检查MySQL状态
```bash
sudo systemctl status mysql
```

##### 2. 查看MySQL错误日志
```bash
tail -f /var/log/mysql/error.log
```

##### 3. 重启MySQL
```bash
sudo systemctl restart mysql
```

##### 4. 检查数据库完整性
```bash
mysqlcheck -u root -p --all-databases
```

### 6.3 服务器被攻击

#### 紧急处理步骤

##### 1. 查看攻击日志
```bash
tail -f runtime/log/*.log | grep -i "Security Attack"
```

##### 2. 封禁攻击IP
```bash
# 使用iptables
sudo iptables -A INPUT -s <攻击IP> -j DROP

# 使用fail2ban
sudo fail2ban-client set mt3-web-security banip <攻击IP>
```

##### 3. 增加安全防护
- 启用所有安全中间件
- 更新黑名单
- 增加验证码
