## 3. 关键配置文件说明

## 3.1 `config/security.php`

当前文件包含以下分组：

- `sql_injection`
- `xss_protection`
- `csrf_protection`
- `file_upload`
- `password_security`
- `login_security`
- `session_security`
- `error_handling`
- `ip_blacklist`
- `jmx_auth`
- `pay_callback`
- `admin_auth`
- `player_auth`

其中与近期代码行为强关联的键：

1. `pay_callback.*`：驱动 `/api/call/epay` 的防重放、幂等锁、日志脱敏策略。
2. `admin_auth.secret_key`：`Check` 中间件生成 Admin/Agent token 时必须存在；为空会抛异常并拒绝鉴权。
3. `player_auth.secret_salt`：玩家认证盐值配置镜像（实际 token 生成在 `config/player.php` + `app/player/common.php` 链路）。

## 3.2 `config/player.php`

重点字段：

- `op_secret_salt` 默认值为 `''`（空字符串）
- `signature_timeout` 默认 `300`
- `session_expire` 默认 `86400`

说明：

- `app/player/common.php` 中 `generatePlayerToken()` / `verifyPlayerToken()` 在盐值为空时会拒绝生成/验证。
- `app/player/middleware/PlayerAuth.php` 在 token 校验失败时会清理玩家会话并阻断请求。

## 3.3 `config/transfer.php`

包含：

- `type.feedback=1`
- `type.transfer=2`
- `status.pending=0`
- `status.approved=1`
- `status.rejected=2`
- `status.processing=3`
- `status.completed=4`
- `rules.*` 与 `fee.*`

与 `app/model/Transfer.php` 的状态常量一致。

## 3.4 `config/cache.php`

默认策略：

- 优先 `redis`
- 若 Redis 扩展/驱动不可用，降级为 `file`

代码里大量并发锁依赖 `Cache::store('redis')`，例如：

- 支付回调锁 `pay_callback_lock:*`
- 支付下单锁 `pay_order_lock:*`
- 转区状态锁 `transfer_status_lock:*`
- 转区执行锁 `transfer_execution_lock:*`

## 5. 生产环境最小安全要求

1. `ADMIN_AUTH_SECRET_KEY` 必须设置高强度随机值。
2. `OP_SECRET_SALT` 必须设置至少 32 字符随机值。
3. `MASTER_VERIFY_PASSWORD` 必须设置，且仅用于超级管理员二次验证。
4. `APP_ENV=production` 时，`/api/call/epay1` 会被拒绝访问（返回 403）。
5. 支付回调安全项建议保持开启：
   - `PAY_CALLBACK_REPLAY_PROTECTION=true`
   - `PAY_CALLBACK_IDEMPOTENCY=true`
   - `PAY_CALLBACK_LOG_MASKING=true`
