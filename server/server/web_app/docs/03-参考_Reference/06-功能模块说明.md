# 功能模块说明（与当前代码对齐）

> 更新时间：2026-02-27  
> 对齐基线：`app/*/controller/*.php`、`route/app.php`、`route/player.php`

## 1. 文档目标

本文件用于描述当前仓库中各应用的真实模块边界与控制器能力，避免历史文档中“方法名与代码不一致”的问题。

说明：

1. `route/player.php`、`route/app.php` 中显式声明的路由，按声明路径为准。
2. 其他未显式声明的控制器方法，遵循 ThinkPHP 多应用常规访问约定（`/{app}/{controller}/{action}`）。
3. 详细参数、返回示例请查看同目录 API 文档分册。

---

## 2. 应用与模块总览

| 应用 | 主要职责 | 控制器数量 |
|---|---|---:|
| `admin` | 超级管理员后台（代理/玩家/订单/GM/配置/日志/转区） | 13 |
| `agent` | 代理后台（下级代理、玩家、订单、提现申请） | 4 |
| `api` | 客户端 API（SDK接入、支付、回调、语音、FAQ、活动奖励） | 10 |
| `player` | 玩家中心（认证、资料、角色、订单、充值、反馈、转区、CDK） | 13 |
| `login` | 历史授权入口（账号登录/CDK授权/GM操作） | 3 |
| `index` | 前台页面（首页、CDK页面、Duty活动页） | 3 |
| `sdk` | SDK 应用壳（页面入口） | 2 |

## 4. 显式路由链路（`route/*.php`）

## 4.1 `route/player.php`

已显式定义：

- 玩家认证：`/player/auth/*`
- CDK链路：`/player/cdk/*`（含 `senditem/*` 子路径）
- 玩家管理员登录：`/player/admin/*`
- 玩家中心：`/player/*`（profile/server/role/order/recharge/feedback/service/transfer）
- 历史兼容重定向：`/login/auth/*`、`/login/index`、`/login/user` 等

说明：`GET /player/server/detail` 对应 `app/player/controller/Server.php::detail()`，用于展示单个服务器详情与当前玩家在该服角色信息。

## 4.2 `route/app.php`

已显式定义：

- `GET /admin/item/test`
- `GET /admin/item/itemList`
- `POST /admin/item/itemSync`
- `POST /admin/item/list_table`
- `POST /admin/item/clearAll`
- `admin/gm` 组下 CDK 管理路径（`cdk*`）
