# 功能模块说明（与当前代码对齐）

> 更新时间：2026-04-26  
> 对齐基线：`app/*/controller/*.php`、`route/app.php`、`route/web_admin_routes.php`、`route/player.php`

> 补充：全局口径以 `00-源码静态分析与对齐基线.md` 为准。

## 1. 文档目标

本文件用于描述当前仓库中各应用的真实模块边界与控制器能力，避免历史文档中“方法名与代码不一致”的问题。

说明：

1. `route/player.php`、`route/app.php` 中显式声明的路由，按声明路径为准；Admin/Agent 后台路由以 `route/web_admin_routes.php` 为单一真源。
2. 其他未显式声明的控制器方法，遵循 ThinkPHP 多应用常规访问约定（`/{app}/{controller}/{action}`）。
3. 详细参数、返回示例请查看同目录 API 文档分册。

## 2. 应用与模块总览

## 5. 服务层功能清单

### 5.1 全局服务（`app/service/`）

| 服务 | 职责 | 关键方法 |
|------|------|----------|
| `BindTicketService` | 账号-角色绑定票据（单次消费+过期控制） | `issue($payload)`、`consume($payload)` |
| `CacheLockService` | 缓存分布式锁（Redis NX + file 降级） | `acquire($key, $ttl, $store)`、`release($key, $token, $store)` |
| `CommissionService` | 佣金计算与分发（直属 70% + 一级上级 5% + 二级上级 5% = 80%） | `distributeCommission($orderData)`、`calculateAgentCommission()` |
| `GmJmxcExecutorService` | GM 命令执行封装（jar + classpath 降级） | `execute($primaryCmd, $fallbackCmd)` |
| `IpLocationService` | IP 地理位置查询 | `locate($ip)` |
| `PermissionAuditService` | 权限审计日志（均为 static 方法） | `logPermissionChange()`、`logGMOperation()`、`logOperation()` |
| `RoleBindService` | 统一账号-角色绑定写入（多入口收敛） | `bind($payload, $context)` |
| `TransferExecutionService` | 转区执行服务（互斥锁、状态机、备份） | `executeTransfer($transferId)`、`batchExecuteTransfer($limit)` |

### 5.2 Player 服务（`app/player/service/`）

| 服务 | 职责 | 关键方法 |
|------|------|----------|
| `AuthService` | 统一认证服务（玩家登录、CDK授权、管理员登录、Token生成/验证） | `playerLogin()`、`cdkAuth()`、`adminLogin()`、`verifyToken()`、`getCurrentPlayer()` |
| `GmService` | 玩家端 GM 操作（发道具、充值仙玉、道具白名单、操作签名） | `sendItem()`、`rechargeXianyu()`、`getItemList()`、`validateOpSignature()` |
| `LogService` | 玩家端日志服务（登录/操作/安全/充值/反馈日志） | `logLogin()`、`logPlayerAction()`、`logSecurityEvent()`、`countLoginFailed()` |
| `ServerService` | 服务器信息服务（列表、连接信息、分组、统计） | `getServerList()`、`getServerById()`、`getGmConnection()`、`getServerStats()` |
| `TransferService` | 转区申请验证服务（数据校验、服务器状态、角色可转区检查） | `validateTransferData()`、`isServerOpenForTransfer()`、`canRoleTransfer()` |

### 5.3 ChargeAward 模块（`app/api/controller/ChargeAward.php`）

充值奖励模块，提供充值后按日/角色维度的奖励领取和密码修改功能：

- `getchargeitem` — 查询充值商品列表
- `receiveday` — 领取每日充值奖励（参数：account、dayawardid）
- `receiverole` — 领取角色充值奖励（参数：account、roleid、itemid）
- `modifypass` — 修改密码（参数：account、password、newpassword，需旧密码验证）

该模块通过 `route/app.php` 隐式路由可达，无独立路由定义。模型层使用 `app/model/ChargeAward.php`。
