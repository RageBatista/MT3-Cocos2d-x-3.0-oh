# Voice 语音识别模块

> 更新时间：2026-02-23

## 1. 模块概述

Voice 模块提供游戏内语音识别功能，基于腾讯云 ASR 服务实现。该模块允许玩家上传语音文件，系统进行语音识别后存储识别结果，供管理员查看和审核。

## 2. 技术架构

### 2.1 核心组件

| 组件 | 说明 |
|------|------|
| `app/api/controller/Voice.php` | 语音识别 API 控制器 |
| `app/model/Voice.php` | 语音数据模型 |
| 腾讯云 ASR | 语音识别服务提供商 |

### 2.2 支持格式

- **文件扩展名**：amr, wav, mp3
- **最大文件大小**：5MB

## 3. API 接口

### 3.1 接收语音文件

- **路径**：`POST /api/voice/receive`
- **功能**：接收玩家上传的语音文件并进行识别
- **请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| uuid | string | 是 | 语音文件唯一标识 |
| speech | string | 是 | Base64 编码的语音数据 |
| channelId | int | 是 | 频道ID |

- **响应示例**：
```json
{
  "uuid": "xxx",
  "channelid": 1,
  "text": "识别结果文本"
}
```

### 3.2 获取语音识别结果

- **路径**：`GET /api/voice/iat`
- **功能**：获取语音识别结果

## 4. 数据库结构

### 4.1 voice 表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int | 主键自增 |
| uuid | varchar(64) | 语音文件唯一标识 |
| text | text | 识别文本内容 |
| channelid | int | 频道ID |
| time | int | 创建时间戳 |

## 5. 安全机制

1. **UUID 格式验证**：验证 UUID 格式合法性
2. **Base64 验证**：验证语音数据 Base64 编码有效性
3. **文件大小检查**：限制最大 5MB
4. **文件头检查**：验证 AMR 文件头
5. **日志记录**：记录所有上传操作

## 6. 管理后台

管理员可在 Admin 后台查看语音识别记录：
- **路径**：`/admin/player/voiceList`
- **数据查询**：支持按 UUID 或内容搜索
