## 使用说明

参考文档用于查阅技术细节，建议：

1. 先阅读 [00-源码静态分析与对齐基线.md](00-源码静态分析与对齐基线.md) 获取当前代码真值口径
2. 再阅读 [13-现代Web管理后台全生命周期架构说明.md](13-现代Web管理后台全生命周期架构说明.md) 了解“现代后台能力”与项目当前实现的映射关系
3. 之后按模块分册查看 API/配置/安全/数据库细节
4. 如与历史文档冲突，以源码与对齐基线为准
