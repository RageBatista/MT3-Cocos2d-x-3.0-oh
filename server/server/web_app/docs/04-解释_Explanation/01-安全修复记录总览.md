## 3. 认证与授权修复

### 3.1 Check 中间件：空值逻辑与 token 认证

`Check` 中间件当前实现：

1. 仅对 `admin`、`agent` 应用执行认证；
2. 读取 `username_*` + `auth_token_*`；
3. 旧 `password_*` session 仅作为迁移输入；
4. 任一关键字段为空即退出（`||`）；
5. token 使用 HMAC-SHA256 并以 `hash_equals` 比较。

关键位置：

- [`app/middleware/Check.php:28`](../../app/middleware/Check.php:28)
- [`app/middleware/Check.php:59`](../../app/middleware/Check.php:59)
- [`app/middleware/Check.php:77`](../../app/middleware/Check.php:77)
- [`app/middleware/Check.php:93`](../../app/middleware/Check.php:93)

### 3.2 后台鉴权密钥外置（P0）

`generateToken()` 不再使用硬编码密钥：

- 从 `security.admin_auth.secret_key` 读取；
- 若密钥为空：记录错误并抛异常；
- 长度不足 32：记录强度告警。

关键位置：

- [`app/middleware/Check.php:109`](../../app/middleware/Check.php:109)
- [`config/security.php:141`](../../config/security.php:141)

## 4. 玩家侧安全修复（P1-A）

### 4.1 Player Token 强制盐值与时效

当前 token 机制：

- 生成：`{sha256}.{timestamp}`；
- 参与摘要：`id|username|timestamp + OP_SECRET_SALT`；
- 有效期：24 小时（86400 秒）；
- `OP_SECRET_SALT` 为空：
  - 生成时抛异常拒绝；
  - 验证时返回失败并记录错误日志。

关键位置：

- [`app/player/common.php:103`](../../app/player/common.php:103)
- [`app/player/common.php:145`](../../app/player/common.php:145)
- [`config/player.php:9`](../../config/player.php:9)
- [`config/security.php:148`](../../config/security.php:148)

### 4.2 PlayerAuth：失效即清会话并阻断

当 `verifyPlayerToken()` 失败时：

1. 记录告警；
2. 清理玩家 session；
3. Ajax 返回 401，页面请求重定向登录。

此外，玩家信息缓存 TTL 已提升为 600 秒。

关键位置：

- [`app/player/middleware/PlayerAuth.php:59`](../../app/player/middleware/PlayerAuth.php:59)
- [`app/player/middleware/PlayerAuth.php:152`](../../app/player/middleware/PlayerAuth.php:152)

### 4.3 PlayerSecurity：频率限制与 Redis 降级

`PlayerSecurity` 当前能力：

- 恶意 IP 拦截；
- 登录频率限制（5 分钟最多 5 次）；
- 请求频率窗口（1 分钟 60 次阈值）；
- Redis 异常时降级到文件缓存。

关键位置：

- [`app/player/middleware/PlayerSecurity.php:21`](../../app/player/middleware/PlayerSecurity.php:21)
