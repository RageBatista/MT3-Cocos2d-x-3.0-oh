# 快速入门

> 面向新用户和运维人员的基础教程，帮助您快速完成系统部署和基础操作。

## 系列概述

本系列教程将引导您从零开始，完成游戏管理系统的环境搭建、部署和基础使用。每个教程都是为初学者设计的，包含详细的步骤说明和验证检查点。

## 学习目标

完成本系列学习后，您将能够：

- ✅ 配置符合要求的开发/运行环境
- ✅ 独立完成系统的部署和初始化
- ✅ 使用系统进行日常管理操作

## 前置要求

- 一台可用的服务器或本地开发机
- 基本的命令行操作能力
- 管理员/root 权限（用于安装软件）

## 常见问题

### Q: 我可以使用虚拟主机吗？
A: 本系统需要完整的 PHP 环境控制权，建议使用 VPS 或云服务器。

### Q: Windows 可以作为开发环境吗？
A: 可以，推荐使用 XAMPP 或 WAMP 集成环境，或使用 Docker。

### Q: 遇到问题怎么办？
A: 请查看 [故障排查](../../03-运维指南/04-故障排查.md) 文档，或联系技术支持。
