## 1. 系统要求

### 1.1 必需软件

| 软件 | 最低版本 | 推荐版本 | 说明 |
|------|----------|----------|------|
| PHP | 8.0 | 8.1+ | 服务端脚本语言 |
| MySQL | 5.7 | 8.0+ | 关系型数据库 |
| Redis | 5.0 | 6.0+ | 缓存服务 |

### 1.2 PHP 扩展要求

```
必需扩展：
- pdo_mysql      # MySQL 数据库连接
- mbstring       # 多字节字符串处理
- openssl        # SSL 加密支持
- tokenizer      # 令牌解析
- xml            # XML 处理
- ctype          # 字符类型检测
- json           # JSON 处理
- bcmath         # 高精度数学运算
- redis          # Redis 客户端
- gd             # 图像处理
- fileinfo       # 文件信息
```

### 1.3 硬件建议

| 环境 | CPU | 内存 | 磁盘 |
|------|-----|------|------|
| 开发环境 | 2核 | 4GB | 20GB |
| 生产环境 | 4核+ | 8GB+ | 50GB+ |

## 2. 开发环境配置

您可以选择以下任一方式配置开发环境：

### 方式一：XAMPP（Windows 推荐）

#### 步骤 1：下载安装 XAMPP

1. 访问 [XAMPP 官网](https://www.apachefriends.org/)
2. 下载 PHP 8.1+ 版本的 XAMPP
3. 运行安装程序，选择安装目录（如 `C:\xampp`）

#### 步骤 2：配置 PHP

编辑 `C:\xampp\php\php.ini`，启用扩展：

```ini
extension=pdo_mysql
extension=mbstring
extension=openssl
extension=redis
extension=gd
```

#### 步骤 3：安装 Redis

1. 下载 Windows 版 Redis：https://github.com/microsoftarchive/redis/releases
2. 解压并运行 `redis-server.exe`

### 方式二：WAMP（Windows 备选）

#### 步骤 1：下载安装 WAMP

1. 访问 [WAMP Server 官网](https://www.wampserver.com/)
2. 下载并安装 WAMP Server
3. 选择 PHP 8.1+ 版本

#### 步骤 2：启用扩展

1. 左键点击 WAMP 图标 → PHP → php.ini
2. 取消注释所需扩展

### 方式三：Docker（推荐，跨平台）

#### 步骤 1：安装 Docker

- **Windows**: 下载 [Docker Desktop](https://www.docker.com/products/docker-desktop)
- **Mac**: 下载 [Docker Desktop for Mac](https://www.docker.com/products/docker-desktop)
- **Linux**: 使用包管理器安装

#### 步骤 2：创建 Docker Compose 文件

创建 `docker-compose.yml` 文件：

```yaml
version: '3.8'

services:
  php:
    image: php:8.1-apache
    ports:
      - "8080:80"
    volumes:
      - ./:/var/www/html
    depends_on:
      - mysql
      - redis

  mysql:
    image: mysql:8.0
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: mt3
    volumes:
      - mysql_data:/var/lib/mysql

  redis:
    image: redis:6-alpine
    ports:
      - "6379:6379"

volumes:
  mysql_data:
```

#### 步骤 3：启动容器

```bash
docker-compose up -d
```

### 方式四：Linux 原生安装

#### CentOS/RHEL

```bash
# 安装 PHP 8.1
sudo yum install -y epel-release
sudo yum install -y https://rpms.remirepo.net/enterprise/remi-release-8.rpm
sudo yum module reset php
sudo yum module enable php:remi-8.1
sudo yum install -y php php-mysqlnd php-mbstring php-xml php-gd php-redis

# 安装 MySQL
sudo yum install -y mysql-server

# 安装 Redis
sudo yum install -y redis
```

#### Ubuntu/Debian

```bash
# 添加 PHP 仓库
sudo apt update
sudo apt install -y software-properties-common
sudo add-apt-repository ppa:ondrej/php
sudo apt update

# 安装 PHP 8.1
sudo apt install -y php8.1 php8.1-mysql php8.1-mbstring php8.1-xml php8.1-gd php8.1-redis

# 安装 MySQL
sudo apt install -y mysql-server

# 安装 Redis
sudo apt install -y redis-server
```

## 3. 依赖安装

### 3.1 安装 Composer

Composer 是 PHP 的依赖管理工具。

#### Windows

1. 下载 [Composer-Setup.exe](https://getcomposer.org/Composer-Setup.exe)
2. 运行安装程序，选择 PHP 可执行文件路径

#### Linux/Mac

```bash
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
```

### 3.2 验证 Composer 安装

```bash
composer --version
# 预期输出：Composer version 2.x.x
```

### 3.3 安装项目依赖

进入项目目录后执行：

```bash
composer install
```

> 💡 **提示**：首次安装可能需要几分钟时间，请耐心等待。

## 4. 环境验证清单

完成环境配置后，请逐项验证：

### 4.1 PHP 验证

```bash
# 检查 PHP 版本
php -v
# 预期：PHP 8.x.x

# 检查已安装扩展
php -m | grep -E "pdo_mysql|mbstring|openssl|redis|gd"
```

### 4.2 MySQL 验证

```bash
# 连接 MySQL
mysql -u root -p

# 在 MySQL 中执行
SHOW DATABASES;
EXIT;
```

### 4.3 Redis 验证

```bash
# 连接 Redis
redis-cli ping
# 预期输出：PONG
```

### 4.4 Composer 验证

```bash
composer --version
# 预期输出：Composer version 2.x.x
```

### 4.5 完整验证脚本

创建 `check_env.php` 文件：

```php
<?php
echo "=== 环境检查 ===\n\n";

// PHP 版本
echo "PHP 版本: " . PHP_VERSION . "\n";
echo "PHP 版本检查: " . (version_compare(PHP_VERSION, '8.0.0', '>=') ? '✅ 通过' : '❌ 失败') . "\n\n";

// 必需扩展
$required = ['pdo_mysql', 'mbstring', 'openssl', 'tokenizer', 'xml', 'ctype', 'json', 'bcmath', 'redis', 'gd', 'fileinfo'];
echo "扩展检查:\n";
foreach ($required as $ext) {
    $status = extension_loaded($ext) ? '✅' : '❌';
    echo "  $status $ext\n";
}

echo "\n环境检查完成！\n";
```

运行检查：

```bash
php check_env.php
```

## 5. 常见问题

### Q: PHP 扩展无法加载？

**解决方案**：
1. 检查 `php.ini` 文件位置是否正确
2. 确认 `extension_dir` 配置正确
3. 重启 Web 服务器

### Q: Redis 连接被拒绝？

**解决方案**：
1. 确认 Redis 服务已启动
2. 检查 Redis 监听端口（默认 6379）
3. 检查防火墙设置

### Q: Composer 下载速度慢？

**解决方案**：使用国内镜像

```bash
composer config -g repo.packagist composer https://mirrors.aliyun.com/composer/
```
