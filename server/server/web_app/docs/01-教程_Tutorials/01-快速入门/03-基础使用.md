# 基础使用（源码对齐版）

> 目标：完成后台常用模块的首轮上手  
> 范围：`admin` 管理后台 + `player` 玩家侧入口

## 1. 进入系统

管理员入口（主链路）：

1. `GET /index.php?s=/login/index`
2. 提交登录：`POST /index.php?s=/login/index/submit`

玩家侧入口（常见）：

1. 玩家账号登录：`GET /index.php?s=/player/auth/login`
2. 玩家授权控制台：`GET /index.php?s=/player/cdk/index`

## 2. 后台核心模块速览

登录后台后，建议按下面顺序熟悉：

1. 玩家列表：`/index.php?s=/admin/player/list`
2. 绑定列表：`/index.php?s=/admin/player/bindList`
3. 角色管理：`/index.php?s=/admin/player/roleList`
4. 订单管理：`/index.php?s=/admin/order/list`
5. GM 操作：`/index.php?s=/admin/gm/player`
6. CDK 管理：`/index.php?s=/admin/gm/cdk`
7. 运营清理：`/index.php?s=/admin/gm/cleanData`

## 3. 三个高频页面如何看

## 3.1 玩家列表

用途：

1. 按账号/代理筛选
2. 编辑玩家信息
3. 封禁/解封与日志审计

## 3.2 绑定列表

用途：

1. 查看账号与角色绑定关系（`user_bind`）
2. 核查角色ID、区服、充值累计

注意：页面显示“所属账号”依赖 `user_bind.userid -> user_account.id` 映射。

## 3.3 角色管理

用途：

1. 从 `role` 表查看角色基础信息
2. 联表展示所属账号

当前接口为：

- `GET /index.php?s=/admin/player/role_table`

## 4. 常见操作建议

1. 写操作前先确认当前页 CSRF token 未过期
2. 涉及封禁、补充充值、清理数据时先做截图或导出留痕
3. 批量操作后立即查看 `runtime/log/{Ymd}.log` 是否有异常

## 5. 你最容易遇到的问题

1. “非法请求：CSRF令牌无效”：刷新页面后重试；避免跨标签页长期停留后直接提交
2. 列表为空但数据库有数据：优先检查账号映射关系（`user_account` / `user_bind` / `role.userid`）
3. 页面字段显示 UID 而非账号：说明该 `userid` 尚未匹配到 `user_account.username`
