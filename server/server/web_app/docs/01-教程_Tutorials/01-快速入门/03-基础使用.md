## 1. 管理员登录

### 1.1 访问登录页面

打开浏览器，访问管理后台地址：

```
http://你的域名/admin
```

### 1.2 登录步骤

1. 输入管理员账号
2. 输入密码
3. 点击「登录」按钮

![登录页面示意]

### 1.3 登录后界面

登录成功后，您将看到管理后台首页，包含：

- **顶部导航栏**：系统名称、用户信息、退出按钮
- **侧边菜单栏**：各功能模块入口
- **主内容区**：数据概览和快捷操作

## 2. 玩家管理基础操作

### 2.1 访问玩家管理

点击侧边菜单 **玩家管理** 进入玩家列表页面。

### 2.2 查看玩家列表

玩家列表显示以下信息：

| 字段 | 说明 |
|------|------|
| 玩家ID | 唯一标识符 |
| 昵称 | 玩家游戏昵称 |
| 账号 | 登录账号 |
| 等级 | 当前等级 |
| 注册时间 | 账号创建时间 |
| 状态 | 正常/禁用 |

### 2.3 搜索玩家

1. 在搜索框输入关键词（玩家ID、昵称或账号）
2. 点击「搜索」按钮
3. 查看搜索结果

### 2.4 查看玩家详情

1. 在玩家列表中找到目标玩家
2. 点击「查看」或玩家ID
3. 查看详细信息：
   - 基本信息（ID、昵称、等级、经验）
   - 账户信息（余额、充值金额）
   - 游戏数据（角色属性、装备等）

### 2.5 常用操作

| 操作 | 说明 |
|------|------|
| 编辑 | 修改玩家基本信息 |
| 禁用 | 禁止玩家登录 |
| 解禁 | 恢复玩家登录权限 |
| 发送物品 | 给玩家发送游戏道具 |
| 发送邮件 | 发送系统邮件 |

---

## 3. 订单查看

### 3.1 访问订单管理

点击侧边菜单 **订单管理** 进入订单列表页面。

### 3.2 订单列表说明

| 字段 | 说明 |
|------|------|
| 订单号 | 唯一订单标识 |
| 玩家ID | 下单玩家 |
| 商品名称 | 购买的商品 |
| 金额 | 订单金额 |
| 支付方式 | 支付宝/微信/其他 |
| 状态 | 待支付/已完成/已取消 |
| 创建时间 | 下单时间 |

### 3.3 订单筛选

可按以下条件筛选订单：

- **时间范围**：选择日期区间
- **订单状态**：全部/待支付/已完成/已取消
- **支付方式**：全部/支付宝/微信
- **玩家ID**：指定玩家的订单

### 3.4 查看订单详情

1. 点击订单号或「查看」按钮
2. 查看订单详细信息：
   - 订单基本信息
   - 支付信息
   - 商品明细
   - 操作日志

---

## 4. 代理管理

### 4.1 访问代理管理

点击侧边菜单 **代理管理** 进入代理列表页面。

### 4.2 代理列表说明

| 字段 | 说明 |
|------|------|
| 代理ID | 唯一标识符 |
| 代理名称 | 代理账号名称 |
| 联系方式 | 电话/微信 |
| 推广人数 | 通过该代理注册的玩家数 |
| 佣金余额 | 可提现佣金 |
| 状态 | 正常/禁用 |

### 4.3 代理操作

| 操作 | 说明 |
|------|------|
| 添加代理 | 创建新的代理账号 |
| 编辑 | 修改代理信息 |
| 结算 | 处理佣金结算 |
| 查看下级 | 查看该代理推广的玩家 |

### 5.1 功能导航图

```
管理后台
├── 首页
│   ├── 数据概览
│   └── 快捷操作
├── 玩家管理
│   ├── 玩家列表
│   ├── 玩家详情
│   └── 发送物品
├── 订单管理
│   ├── 订单列表
│   └── 订单详情
├── 代理管理
│   ├── 代理列表
│   ├── 添加代理

├── 物品管理
│   ├── 物品列表
│   └── 物品分类
├── 系统设置
│   ├── 基础配置

│   └── 安全配置
└── 操作日志
```

### 5.2 快捷操作

在首页通常提供以下快捷入口：

- **今日充值**：查看今日充值金额
- **新增玩家**：今日新注册玩家数
- **在线玩家**：当前在线玩家数
- **待处理订单**：需要处理的订单数

### 5.3 个人设置

点击右上角用户名，可进行：

- **修改密码**：更改登录密码
- **个人资料**：修改个人信息
- **退出登录**：安全退出系统

## 6. 操作技巧

### 6.1 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + F` | 页面内搜索 |
| `Esc` | 关闭弹窗 |

### 6.2 数据导出

多数列表页面支持数据导出：

1. 设置筛选条件
2. 点击「导出」按钮
3. 选择导出格式（Excel/CSV）
4. 下载文件

### 6.3 批量操作

部分页面支持批量操作：

1. 勾选多条记录
2. 选择批量操作类型
3. 确认执行

## 7. 安全操作建议

### 7.1 日常操作安全

- ✅ 定期修改密码（建议每 90 天）
- ✅ 操作完成后及时退出登录
- ✅ 不要在公共电脑保存密码
- ✅ 重要操作前确认信息无误

### 7.2 敏感操作注意

以下操作需谨慎执行：

- ⚠️ 禁用玩家账号
- ⚠️ 修改玩家数据
- ⚠️ 发送贵重物品
- ⚠️ 佣金结算

### 7.3 操作日志

系统会记录所有重要操作，可在「操作日志」中查看：

- 操作人
- 操作时间
- 操作内容
- IP 地址

## 8. 常见问题

### Q: 忘记密码怎么办？

请联系超级管理员重置密码。

### Q: 为什么看不到某些菜单？

菜单显示与账号权限相关，请联系管理员分配相应权限。

### Q: 数据加载很慢怎么办？

1. 检查网络连接
2. 尝试刷新页面
3. 清除浏览器缓存
4. 联系技术支持

### Q: 操作失误如何恢复？

部分操作可撤销，请查看操作日志或联系技术支持。
