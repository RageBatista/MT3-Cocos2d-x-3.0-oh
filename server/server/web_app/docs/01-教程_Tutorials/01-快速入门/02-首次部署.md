# 首次部署

> 本教程将指导您完成游戏管理系统的第一次部署。

## 学习目标

完成本教程后，您将能够：

- ✅ 获取并安装系统源码
- ✅ 正确配置环境变量
- ✅ 初始化数据库
- ✅ 配置 Web 服务器
- ✅ 验证系统正常运行

预计完成时间：20 分钟

## 前置条件

在开始本教程前，请确保：

- ✅ 已完成 [环境搭建](./01-环境搭建.md)
- ✅ PHP、MySQL、Redis 服务正常运行
- ✅ Composer 已安装

## 1. 获取源码

### 方式一：Git 克隆（推荐）

```bash
# 克隆项目到本地
git clone <项目仓库地址> mt3_web

# 进入项目目录
cd mt3_web
```

### 方式二：下载压缩包

1. 从项目仓库下载最新版本的压缩包
2. 解压到 Web 目录
3. 进入项目目录

```bash
# 解压后进入目录
cd mt3_web
```

## 2. 安装依赖

```bash
# 安装 PHP 依赖
composer install

# 如果是生产环境，使用以下命令（跳过开发依赖）
composer install --no-dev --optimize-autoloader
```

> ⚠️ **注意**：如果 Composer 下载速度慢，请配置国内镜像：
> ```bash
> composer config repo.packagist composer https://mirrors.aliyun.com/composer/
> ```

## 3. 配置环境变量

### 3.1 创建环境配置文件

```bash
# 复制示例配置文件
copy .env.example .env    # Windows
# cp .env.example .env    # Linux/Mac
```

### 3.2 编辑 .env 文件

打开 `.env` 文件，修改以下关键配置：

```ini
# ===========================================
# 应用配置
# ===========================================
APP_DEBUG = false                    # 生产环境设为 false
APP_TRACE = false                    # 生产环境设为 false

# ===========================================
# 数据库配置（ThinkPHP 8.x 扁平键值对格式）
# ===========================================
DB_TYPE = mysql                      # 数据库类型
DB_HOST = 127.0.0.1                  # 数据库地址
DB_NAME = mt3                        # 数据库名
DB_USER = root                       # 数据库用户名
DB_PASS = your_password              # 数据库密码（请修改）
DB_PORT = 3306                       # 数据库端口
DB_CHARSET = utf8mb4                 # 字符集
DB_PREFIX = mt_                      # 表前缀

# ===========================================
# Redis 配置（ThinkPHP 8.x 扁平键值对格式）
# ===========================================
REDIS_HOST = 127.0.0.1               # Redis 地址
REDIS_PORT = 6379                    # Redis 端口
REDIS_PASSWORD =                     # Redis 密码（如有）
REDIS_SELECT = 0                     # 数据库索引

# ===========================================
# 缓存配置
# ===========================================
[CACHE]
DRIVER = redis                       # 使用 Redis 缓存
```

### 3.3 重要安全设置

```ini
# 生产环境必须修改的配置
APP_DEBUG = false                    # 关闭调试模式
APP_TRACE = false                    # 关闭追踪

# 安全密钥（请生成随机字符串）
SESSION_HASH = your_random_secret_key_here
```

## 4. 数据库初始化

### 4.1 创建数据库

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE mt3 DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户（可选）
CREATE USER 'mt3_user'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON mt3.* TO 'mt3_user'@'localhost';
FLUSH PRIVILEGES;

EXIT;
```

### 4.2 导入数据库结构

```bash
# 导入 SQL 文件
mysql -u root -p mt3 < database/mhxy.sql
```

### 4.3 验证数据库

```sql
-- 检查表是否创建成功
mysql -u root -p mt3 -e "SHOW TABLES;"
```

## 5. Web 服务器配置

### 5.1 Apache 配置

#### 方式一：虚拟主机配置

编辑 Apache 配置文件（如 `httpd-vhosts.conf`）：

```apache
<VirtualHost *:80>
    ServerName mt3.local
    DocumentRoot "F:/GB-ZMXY2/mt3_web/public"
    
    <Directory "F:/GB-ZMXY2/mt3_web/public">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
    
    ErrorLog "logs/mt3-error.log"
    CustomLog "logs/mt3-access.log" common
</VirtualHost>
```

#### 方式二：修改主配置

确保 Apache 启用了 `mod_rewrite` 模块：

```apache
LoadModule rewrite_module modules/mod_rewrite.so
```

### 5.2 Nginx 配置

创建 Nginx 站点配置：

```nginx
server {
    listen 80;
    server_name mt3.local;
    root /var/www/mt3_web/public;
    index index.php index.html;

    # 日志
    access_log /var/log/nginx/mt3-access.log;
    error_log /var/log/nginx/mt3-error.log;

    # 主规则
    location / {
        if (!-e $request_filename) {
            rewrite ^(.*)$ /index.php?s=$1 last;
        }
    }

    # PHP 处理
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.1-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # 禁止访问敏感目录
    location ~ ^/(\.git|runtime|vendor|extend)/ {
        deny all;
    }
}
```

### 5.3 PHP 内置服务器（仅开发环境）

```bash
# 进入 public 目录
cd public

# 启动内置服务器
php -S localhost:8080
```

访问：http://localhost:8080

## 8. 常见问题

### Q: 访问页面显示 500 错误？

**排查步骤**：
1. 检查 `.env` 文件配置是否正确
2. 查看 `runtime/log/` 目录下的日志文件
3. 临时开启 `APP_DEBUG = true` 查看详细错误

### Q: 数据库连接失败？

**排查步骤**：
1. 确认 MySQL 服务已启动
2. 检查数据库用户名、密码、数据库名
3. 检查防火墙是否阻止了 3306 端口

### Q: 页面样式丢失？

**排查步骤**：
1. 检查 `public/static/` 目录是否存在
2. 检查 Web 服务器是否正确配置了静态文件访问
3. 清除浏览器缓存重试

### Q: Redis 连接失败？

**排查步骤**：
1. 确认 Redis 服务已启动：`redis-cli ping`
2. 检查 `.env` 中的 Redis 配置
3. 检查 Redis 是否需要密码认证

## 9. 安全建议

首次部署完成后，请务必：

1. **修改默认密码** - 更改管理员默认密码
2. **关闭调试模式** - 设置 `APP_DEBUG = false`
3. **配置 HTTPS** - 生产环境强烈建议使用 SSL
4. **设置防火墙** - 只开放必要端口（80、443）
5. **定期备份** - 配置数据库自动备份
