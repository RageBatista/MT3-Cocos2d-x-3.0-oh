# 首次部署（源码对齐版）

> 目标：在一台全新环境上完成 `web_app` 首次可用部署  
> 口径：以 `.env.example`、`config/*.php`、`route/*.php` 当前实现为准

## 学习目标

完成本文后，你可以：

1. 完成代码与依赖安装
2. 正确配置 `.env`
3. 初始化 `mhxy` 数据库
4. 配置 Web 入口并完成首轮连通性验证

预计耗时：20~30 分钟。

## 1. 获取代码

```bash
git clone <仓库地址> web_app
cd web_app
```

## 2. 安装依赖

```bash
composer install
```

生产环境建议：

```bash
composer install --no-dev --optimize-autoloader
```

## 3. 配置环境变量

复制模板：

```bash
cp .env.example .env
```

按实际环境修改以下最小必填项（节选）：

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=mhxy
DB_USER=root
DB_PASS=your_password
DB_CHARSET=utf8mb4

JMX_AUTH_ENABLED=true
JMX_USERNAME=super_admin
JMX_PASSWORD=change_me
JMX_TOKEN=change_me

MASTER_VERIFY_PASSWORD=change_me
ADMIN_AUTH_SECRET_KEY=change_me_admin_auth_secret
OP_SECRET_SALT=change_me_op_secret_salt_at_least_32_chars

APP_DEBUG=false
APP_ENV=production
```

注意：

1. `ADMIN_AUTH_SECRET_KEY` 与 `OP_SECRET_SALT` 为空会导致鉴权链路失败。
2. `OP_SECRET_SALT` 建议至少 32 位随机串。
3. `config/app.php` 当前 `app_debug` 为固定 `false`，不要把调试开关完全依赖在 `.env`。

## 4. 初始化数据库

```sql
CREATE DATABASE mhxy DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

```bash
mysql -u root -p mhxy < database/mhxy.sql
```

快速校验（当前基线为 28 表）：

```bash
mysql -u root -p -e "USE mhxy; SHOW TABLES;"
```

## 5. 配置 Web 服务

Nginx 最小示例：

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/web_app/public;
    index index.php index.html;

    location / {
        try_files $uri $uri/ /index.php?s=$uri&$args;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        fastcgi_pass unix:/run/php/php8.1-fpm.sock;
    }

    location ~ /\.(?!well-known).* { deny all; }
    location ~ /\.env { deny all; }
}
```

## 6. 目录权限

确保 `runtime/` 可写：

```bash
chmod -R 755 runtime
chown -R www-data:www-data runtime
```

## 7. 首轮访问验证

建议按下面顺序验证：

1. 管理员登录页：`/index.php?s=/login/index`
2. 玩家后台管理员登录：`/index.php?s=/player/admin/login`
3. 玩家授权入口：`/index.php?s=/player/cdk/index`
4. 玩家账号登录页：`/index.php?s=/player/auth/login`

验证通过标准：

1. 页面可打开，无 500
2. 登录表单可提交（无 CSRF 报错）
3. `runtime/log/` 仅出现可解释日志，无致命错误堆栈

## 8. 部署后安全检查

上线前至少确认：

1. `.env` 中所有 `CHANGE_ME_*` 已替换
2. `APP_ENV=production`
3. Web 服务不可直接下载 `.env`、`runtime/*`、`vendor/*`
4. 已配置数据库定时备份
