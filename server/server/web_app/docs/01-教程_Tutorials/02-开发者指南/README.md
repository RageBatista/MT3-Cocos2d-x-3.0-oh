# 开发者指南

> 面向开发人员的学习教程，帮助您理解项目架构并遵循规范进行开发。

## 系列概述

本系列教程面向需要参与项目开发或进行二次开发的技术人员。通过学习，您将深入理解项目的架构设计、代码组织方式以及团队协作规范。

## 学习目标

完成本系列学习后，您将能够：

- ✅ 理解多应用架构设计
- ✅ 掌握各目录的职责划分
- ✅ 遵循项目编码规范
- ✅ 进行规范的代码提交

## 常见问题

### Q: 我是新加入的开发者，应该从哪里开始？

建议学习顺序：
1. 阅读 [项目结构认知](./01-项目结构认知.md)
2. 本地搭建开发环境
3. 阅读 [编码规范](./02-编码规范.md)
4. 从小功能开始参与开发

### Q: 如何快速定位功能代码？

1. 理解 URL 路由规则
2. 根据模块定位控制器
3. 查看对应的模型和视图

### Q: 代码审查有什么要求？

所有代码提交需要：
1. 遵循 PSR-12 编码规范
2. 通过静态代码分析
3. 添加必要的注释
4. 编写单元测试（如适用）
