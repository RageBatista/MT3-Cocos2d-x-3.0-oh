# 教程 (Tutorials)

> 学习导向的文档，帮助用户从零开始掌握项目。

## 目录结构

```text
01-教程_Tutorials/
├── README.md           # 本文件
├── 01-快速入门/        # 快速上手指南
│   ├── README.md
│   ├── 01-环境搭建.md
│   ├── 02-首次部署.md
│   └── 03-基础使用.md

```

## 适用人群

- **01-快速入门**：新用户、运维人员、项目管理者
- **02-开发者指南**：新加入的开发者、前端/后端工程师

## 学习路径

### 新用户推荐路径

1. 阅读 [环境搭建](01-快速入门/01-环境搭建.md)
2. 执行 [首次部署](01-快速入门/02-首次部署.md)
3. 了解 [基础使用](01-快速入门/03-基础使用.md)

### 开发者推荐路径

1. 先完成快速入门路径
2. 学习 [项目结构认知](02-开发者指南/01-项目结构认知.md)
3. 遵循 [编码规范](02-开发者指南/02-编码规范.md)
