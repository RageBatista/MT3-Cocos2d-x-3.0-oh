## 3. 关键对齐结论

1. 路由：显式路由 + 隐式路由并存（`url_route_must=false`）
2. 转区：`TransferExecutionService` 默认 `binding_only`，不是默认 GM 全量迁移
3. SendItem：主链路白名单来源为 `public/txt/itemid.txt`
4. Voice：当前仅接受 AMR 头校验，识别文本为占位值
5. 回调调试端点：`/api/call/test`、`/api/call/checkurl` 默认关闭
6. 数据库：`mhxy.sql` 为 27 表；代码还访问运行期扩展日志表
