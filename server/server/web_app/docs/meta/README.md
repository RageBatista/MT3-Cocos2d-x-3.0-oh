# Meta 元信息目录（与当前仓库对齐）

本目录用于存放文档体系的元信息文件。

## 当前目录结构

```text
meta/
├── README.md        # 本文件
├── CHANGELOG.md     # 文档/版本变更记录
└── CONTRIBUTING.md  # 文档贡献规范
```

说明：

- 当前仓库中 **不存在** `meta/archive/` 目录；
- 如历史记录中出现归档路径描述，按历史语义理解，不代表目录现存。

## 文件说明

### 1) CHANGELOG.md

用于记录文档与版本层面的关键变更，包括新增、修改、修复与历史说明。

### 2) CONTRIBUTING.md

用于说明文档命名、格式、提交流程与维护约定。

1. 新变更优先写入 [`CHANGELOG.md`](./CHANGELOG.md)
2. 文档规范以 [`CONTRIBUTING.md`](./CONTRIBUTING.md) 为准
3. 目录结构变更后需同步更新索引与本说明
