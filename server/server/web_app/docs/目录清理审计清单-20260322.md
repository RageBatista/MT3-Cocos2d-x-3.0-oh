## 5. 自动化清理脚本

脚本路径：`scripts/safe_cleanup.ps1`

- 默认行为：`DryRun`，只展示将被清理的目标，不执行删除。
- 执行删除：`.\scripts\safe_cleanup.ps1 -Apply`
- 连同待确认候选一起删除：`.\scripts\safe_cleanup.ps1 -Apply -IncludeOptional`
- 安全校验：
  - 校验项目根目录关键结构（`app/config/public/runtime/composer.json`）
  - 校验目标路径必须在项目根目录内
  - 仅清理白名单目标，不支持任意路径输入删除
