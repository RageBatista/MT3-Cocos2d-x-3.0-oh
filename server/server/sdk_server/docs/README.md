## 🎯 模块概述

### 功能定位

SDK Server 是 MT3 服务器架构中的**第三方SDK接入服务**，负责：

1. **SDK对接** - 对接第三方SDK（登录、支付、统计等）
2. **协议转换** - 转换SDK协议和游戏协议
3. **数据同步** - 同步SDK数据到游戏服务器
4. **统计上报** - 向SDK平台上报统计数据
5. **版本管理** - 管理不同版本的SDK接口

### 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| **C++/Java** | 实现语言 | 混合实现 |
| **HTTP/HTTPS** | 通信协议 | RESTful API |
| **JSON/XML** | 数据格式 | SDK数据交换 |
| **log4cpp** | 日志框架 | C++日志 |

## ⚙️ 配置说明

### 主要配置项

```ini
[SDKServer]
# 网络配置
type            = tcp
port            = 10040
address         = 0.0.0.0

# SDK配置
sdk_type        = default       # SDK类型
sdk_app_id      = your_app_id   # SDK应用ID
sdk_app_key     = your_app_key  # SDK密钥

# 缓冲区配置
so_sndbuf       = 65536
so_rcvbuf       = 65536
ibuffermax      = 1048576
obuffermax      = 1048576
```
