## 🎯 模块概述

### 功能定位

Zone Server 是 MT3 服务器架构中的**社交空间服务**，负责：

1. **社交空间管理** - 管理玩家的社交空间
2. **好友系统** - 好友关系管理
3. **空间互动** - 空间访问和互动
4. **装饰系统** - 空间装饰和个性化

### 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| **Java/C++** | 实现语言 | 混合实现 |
| **XDB** | 数据存储 | 空间数据 |
| **TCP** | 通信协议 | 网络传输 |

## 🔧 核心功能

### 1. 社交空间管理

- **空间创建**: 玩家创建个人社交空间
- **空间访问**: 访问其他玩家空间
- **空间装饰**: 自定义空间装饰
- **空间留言**: 好友留言互动

### 2. 好友系统

- **好友添加**: 添加游戏好友
- **好友分组**: 好友分组管理
- **在线状态**: 实时在线状态
- **好友互动**: 好友互动功能

## ⚙️ 配置说明

### 主要配置项

```ini
[ZoneServer]
# 网络配置
type            = tcp
port            = 10060
address         = 0.0.0.0

# 空间配置
max_zones       = 100000    # 最大空间数
max_decorations = 1000      # 每空间最大装饰数

# 缓冲区配置
so_sndbuf       = 65536
so_rcvbuf       = 65536
ibuffermax      = 1048576
obuffermax      = 1048576
```

## 🚀 运维指南

### 启动服务

```bash
cd zone_server
./start.sh
```

### 停止服务

```bash
./stop.sh
```

### 日志查看

```bash
tail -f logs/zone.log
```

### 监控指标

| 指标 | 说明 | 正常范围 |
|------|------|---------|
| **活跃空间数** | 当前活跃空间 | <10000 |
| **访问量** | 空间访问次数 | <100000/天 |
| **好友数量** | 平均好友数 | <500/人 |
