## 🎯 模块概述

### 功能定位

Spirit Server 是 MT3 服务器架构中的**精灵社交平台服务**，负责：

1. **精灵管理** - 管理玩家的精灵系统
2. **社交平台** - 提供社交功能和互动
3. **数据同步** - 与主游戏服务器同步数据
4. **活动支持** - 支持精灵相关活动

### 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| **Java/C++** | 实现语言 | 混合实现 |
| **MySQL** | 数据库 | mt3_jingling 数据库 |
| **HTTP** | 通信协议 | Web平台接口 |

## 💾 数据库说明

### 数据库信息

- **数据库名**: mt3_jingling
- **服务器**: 192.168.32.2:3306
- **说明**: 专门存储精灵相关数据

### 数据迁移

如需数据迁移：

```bash
# 1. 登录数据库服务器
ssh 192.168.32.2

# 2. 导出数据库
mysqldump -u root -p mt3_jingling > mt3_jingling.sql

# 3. 根据平台指引进行数据迁移
```

## 🚀 运维指南

### 管理平台访问

**平台地址**: http://192.168.32.2:8802/index/login

**功能**:
- 精灵数据管理
- 用户数据查询
- 活动配置
- 统计报表

### 启动服务

```bash
cd spirit_server
./start.sh
```

### 停止服务

```bash
./stop.sh
```

### 日志查看

```bash
tail -f logs/spirit.log
```
