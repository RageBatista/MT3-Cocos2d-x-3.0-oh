# 当前产品验收基线（2026-06-08）

> 状态：当前发布验收基线草案  
> 适用范围：Win32 / Android / iOS / Server / 资源热更新  
> 事实来源：`AGENTS.md`、`.claude/BUILD_GUIDE.md`、现有构建脚本、P0 安全/CI/资源任务单。若本文与源码或已验证命令冲突，以工程实物为准并回写本文。

## 1. 验收分级

| 等级 | 定义 | 发布策略 |
| --- | --- | --- |
| P0 / 致命 | 阻断登录、入世界、支付、更新、安全门禁或崩溃级问题 | 必须修复，不允许带入发布 |
| P1 / 严重 | 核心路径可用但存在明显稳定性、体验或定位缺口 | 发布前必须有修复或负责人签字豁免 |
| P2 / 一般 | 非核心路径缺陷、弱提示、低频兼容问题 | 可进入迭代计划，需记录影响面 |
| P3 / 提示 | 文案、清单、低风险体验优化 | 进入优化池，不阻断发布 |

## 3. 发布准入最小命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./tools/scripts/Test-MT3-SecurityGate.ps1 -ReportPath build_logs/security-gate.json
powershell -NoProfile -ExecutionPolicy Bypass -File ./tools/scripts/Test-MT3-ResourceUiGate.ps1 -ReportPath build_logs/resource-ui-gate.json
powershell -NoProfile -ExecutionPolicy Bypass -File ./tools/scripts/Build-MT3-Exe-Canonical.ps1 -Configuration Release -Platform Win32 -BuildMode Incremental -MaxParallelJobs 8
ant -f ./server/server/game_server/build.xml genfiles
ant -f ./server/server/game_server/build.xml dist
```

### 3.1 Android arm64 当前补充门禁（2026-06-19）

Android `free` 渠道若作为当前发布候选，至少需要满足：

1. `Build-Android-Locojoy-WithGate.ps1` 使用 `arm64-v8a + c++_shared + android-21 + clang` 链路重编成功；
2. APK 结构门禁通过（非 ZIP64，EntryCount 不超限）；
3. APK ABI 门禁通过（`libgame.so / libc++_shared.so / libdu.so / liblocSDK6a.so` 均存在于 `lib/arm64-v8a/`）；
4. MuMu 安装成功，`dumpsys package` 显示 `primaryCpuAbi=arm64-v8a`；
5. 最终进入游戏场景，且运行日志无：
   - `FATAL EXCEPTION`
   - `SIGSEGV`
   - `UnsatisfiedLinkError`
   - `ProcessKeyExchange identity empty`
   - `服务器断开连接`

## 4. 当前未闭环外部项

- 真实 FTP/上传账号的凭证轮换与旧凭证禁用需运维/安全负责人执行。
- Android/iOS 真机安装、支付沙箱、渠道 SDK 回调需对应设备和渠道环境。
- HTTP/私网/测试地址迁移需配置中心/服务端联动；当前安全门禁默认告警，发布严格链路可加 `-StrictHttp` 阻断。
