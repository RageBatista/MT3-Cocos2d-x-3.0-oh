# 核心 UI 资源健康门禁清单（2026-06-08）

> 状态：P0 资源/UI 静态门禁基线  
> 聚合入口：`tools/scripts/Test-MT3-ResourceUiGate.ps1`  
> 注意：`check-cegui-bindings.ps1` 必须传 `-All` / `-Family` / `-Layout`，不得使用无参调用。

## 1. 门禁阻断条件

| 条件 | 等级 | 处理 |
| --- | --- | --- |
| 核心 layout 缺失或 XML 解析失败 | P0 | 阻断发布 |
| 核心 imageset/font 缺失 | P0 | 阻断发布 |
| 核心按钮 Lua 回调缺失 | P0 | 阻断发布 |
| `Validate-UnpackedResources.ps1` 报 failed/missing final path | P0 | 阻断发布 |
| `validate-cegui-resources.ps1` 返回 WARN 且 failed > 0 | P0 | 聚合层提升为 FAIL |
| 非核心 LuaEventOnClicked 死引用 | P1 | 修复或负责人豁免 |
| 性能类大纹理/布局数量告警 | P2 | 进入优化计划 |

## 2. 十条核心 UI 路径清单

| 玩家路径 | Lua/模块锚点 | Layout/资源锚点 | 必需事件 | Smoke 验收 |
| --- | --- | --- | --- | --- |
| 启动更新 | 更新器/资源发布链 | `ver.ljvi`、`fl.ljpi`、PFS 根 | 进度、重试、错误提示 | 断网/弱网/正常更新各一次 |
| 登录首屏 | `switchaccountdialog.lua`、登录背景 | 登录 layout / 背景资源 | 登录、注册、切换账号 | 输入账号密码后发起登录；不自动填充旧密码 |
| 选服 | `selectserverentry.lua` | 选服 layout / 服务器列表资源 | 选择区服、进入游戏 | 维护/爆满/正常区服提示正确 |
| 创建角色 | `createroledialog*.lua` | 创建角色 layout、职业/头像资源 | 创建、返回、随机名 | 名称非法/重复提示正确 |
| 入世界主界面 | 主界面 Lua、任务/菜单模块 | 主 HUD layout / 图标资源 | 背包、商城、聊天、活动入口 | 入世界后核心按钮可点击 |
| 背包 | `logic/item/**` | 背包 layout、道具图标 imageset | 切页、使用、查看详情 | 打开、切页、使用普通道具 |
| 商城/充值 | `chargedialog.lua`、`vip/*chargedlg.lua` | 充值/商城 layout | 拉取商品、创建订单 | 商品列表正常；请求不携带登录密码 |
| 战斗入口 | 战斗 UI Lua/C++ | 战斗 HUD、技能图标 | 技能、自动、逃跑/防御 | 进入战斗并完成一回合 |
| 聊天/社交 | 聊天 Lua/社交模块 | 聊天框、好友/帮派 layout | 发送、切频道、私聊 | 发送消息并看到回显 |
| 客服/公告 | 公告/客服 WebView 或 Lua | 公告/客服 layout | 打开、关闭、重试 | 公告可打开；失败可重试 |
