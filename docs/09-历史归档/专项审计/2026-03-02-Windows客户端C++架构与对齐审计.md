## 4. 本次修复项

### 4.1 `Resource.h` 编码损坏（阻塞编译）

- 文件: `client/MT3Win32App/Resource.h`  
- 问题: UTF-8 BOM + UTF-16 字节混杂，触发 `error C2059`。  
- 处理: 重写为 `UTF-8 with BOM + CRLF`，内容恢复为标准资源头定义。  

### 4.2 `cegui.lib` 导出符号缺失（链接失败）

- 文件: `dependencies/cegui/project/win32/cegui.win32.vcxproj`  
- 问题: Release 宏包含 `FORCEGUIEDITOR`，导致 `PFSResourceProvider` 编译到错误重载分支。  
- 处理: 移除 Release 宏中的 `FORCEGUIEDITOR` 并重建 `cegui.lib`。  

### 4.3 FMOD / Curl 导入库缺失（链接失败）

- 产物:  
  - `cocos2d-2.0-rc2-x-2.0.1/external/fmod/win32/lib/fmodex_vc.lib`  
  - `cocos2d-2.0-rc2-x-2.0.1/external/curl/prebuilt/win32/libcurl_imp.lib`  
- 处理: 由现有 `fmodex.dll` / `libcurl.dll` 自动生成 `.def + .lib`。  

### 4.4 兼容桥接符号（历史 ABI）

- 文件: `client/MT3Win32App/main.cpp`  
- 问题: `engine.lib` 依赖 `_FMOD_System_Create@4`，与现有导入库导出形式不匹配。  
- 处理: 添加 `stdcall` 桥接函数，转调 `fmodex.dll` 导出 `FMOD_System_Create`。

## 6. 残留风险与建议

1. 协议差异风险：`pet.xml` 的 `CPetLevelReset` 客户端/服务端未对齐，建议确认是否废弃并统一协议源。  
2. 构建告警：`MSB3245 platform.winmd` 为历史工程引用告警，当前不阻塞构建，但建议后续清理无效托管引用。  
3. `client/Build-MT3-v120.ps1` 当前更适合作为增量构建脚本；从空仓库全量构建建议优先走 `FireClient.sln /t:MT3` 路径。

> **更新（2026-04-29）**: 当前仓库对外固定构建入口已收敛为 `tools/scripts/Build-MT3-Exe-Canonical.ps1`，内部调用 `client/Build-MT3-v120.ps1` 完成 ABI 安全链路。直接使用 `FireClient.sln` 的方式仅作为历史参考，不再作为推荐入口。
