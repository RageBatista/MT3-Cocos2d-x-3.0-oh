1. `[P0][BOOT] multiSampleType=%d bEnableMipMap=%d dwRenderFlags=0x%08X appInitStep=%d`
2. `[P0][EFFECT] SelectRenderEffect effect=%d prev=%d`
3. `[P0][EFFECT] SetShaderParam effect=%d param=%p`

## 6. 验收命令（联调/QA 可直接执行）

```powershell
rg -n "\[P0\]\[BOOT\]|\[P0\]\[EFFECT\]" <运行日志文件>
```

通过标准：
1. 启动阶段至少 1 条 `[P0][BOOT]`。
2. 夜景场景每帧可见 effect 相关日志，不出现长时间空窗。
3. `SelectRenderEffect` 和 `SetShaderParam` 对应 effectId 一致。
