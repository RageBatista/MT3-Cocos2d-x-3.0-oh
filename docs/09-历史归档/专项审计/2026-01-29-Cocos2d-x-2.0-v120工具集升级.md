## 1. 升级概述

### 1.1 升级原因

- **FireClient.lib ABI 兼容性**: FireClient.lib 是预编译库 (v120)，需要所有依赖项目使用 v120 工具集
- **VS2013 编译环境**: 项目需要使用 Visual Studio 2013 (v120) 工具集进行编译
- **避免链接错误**: 升级到 v120 可以避免 LNK2001/LNK2019 链接错误

### 1.2 升级范围

本次升级主要针对 `cocos2d-2.0-rc2-x-2.0.1` 目录下的 Win32 平台项目文件。

### 2.2 升级详情

#### cocos2d.vcxproj

**文件路径**: `cocos2d-2.0-rc2-x-2.0.1/cocos2dx/proj.win32/cocos2d.vcxproj`

**修改内容**:

```xml
<!-- Release 配置 -->
<PropertyGroup Condition="'$(Configuration)|$(Platform)'=='Release|Win32'" Label="Configuration">
  <ConfigurationType>DynamicLibrary</ConfigurationType>
  <CharacterSet>Unicode</CharacterSet>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '10.0'">v100</PlatformToolset>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '11.0'">v110</PlatformToolset>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '11.0' and exists('$(MSBuildProgramFiles32)\Microsoft SDKs\Windows\v7.1A')">v110_xp</PlatformToolset>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '12.0'">v120</PlatformToolset>  <!-- 新增 -->
</PropertyGroup>

<!-- Debug 配置 -->
<PropertyGroup Condition="'$(Configuration)|$(Platform)'=='Debug|Win32'" Label="Configuration">
  <ConfigurationType>DynamicLibrary</ConfigurationType>
  <CharacterSet>Unicode</CharacterSet>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '10.0'">v100</PlatformToolset>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '11.0'">v110</PlatformToolset>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '11.0' and exists('$(MSBuildProgramFiles32)\Microsoft SDKs\Windows\v7.1A')">v110_xp</PlatformToolset>
  <PlatformToolset Condition="'$(VisualStudioVersion)' == '12.0'">v120</PlatformToolset>  <!-- 新增 -->
</PropertyGroup>
```

## 3. 编译验证

### 3.1 编译命令

```powershell
cmd /c "call \"%VS120COMNTOOLS%..\..\VC\vcvarsall.bat\" x86 && msbuild \"cocos2d-2.0-rc2-x-2.0.1/cocos2dx/proj.win32/cocos2d-win32.sln\" /t:Rebuild /p:Configuration=Release /p:Platform=Win32 /p:PlatformToolset=v120 /m /nologo"
```
