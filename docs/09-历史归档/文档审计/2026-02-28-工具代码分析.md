**P0 优化模块（2025-12 引入）**:
- `DirtyFlags.h` (218 行) - 位打包枚举，统一管理文档状态、显示状态、装备层状态等
- `CommandManager.h` (693 行) - 命令模式实现，支持命令合并优化

- `EquipmentLayer.h` (318 行) - 装备层系统，消除 800+ 行宏重复代码

**关键实现**:
```cpp
// 贝塞尔曲线轨迹计算 (SpriteEditorView.cpp:76-89)
static Nuclear::FPOINT EvalQuadraticBezier(
    const Nuclear::FPOINT& p0,
    const Nuclear::FPOINT& p1,
    const Nuclear::FPOINT& p2,
    float t)
{
    const float oneMinusT = 1.0f - t;
    const float a = oneMinusT * oneMinusT;
    const float b = 2.0f * oneMinusT * t;
    const float c = t * t;
    return Nuclear::FPOINT(
        a * p0.x + b * p1.x + c * p2.x,
        a * p0.y + b * p1.y + c * p2.y);
}
```
