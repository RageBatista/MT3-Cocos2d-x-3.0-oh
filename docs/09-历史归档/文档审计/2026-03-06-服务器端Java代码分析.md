## 2. 服务模块分析

### 2.1 服务模块清单

MT3 服务器端包含 **10个服务模块**（比文档中记录的 8 个多 2 个）：

| 序号 | 目录名称 | 目录 | 主要语言/形态 | 职责描述 |
|------|---------|------|--------------|---------|
| 1 | **common** | server/server/common | C++ + XML | 公共协议/日志组件目录（含 `logservice`、`logclient`） |
| 2 | **game_server** | server/server/game_server | Java + XML | 游戏核心逻辑服务 |
| 3 | **game_server_f** | server/server/game_server_f | 目录占位 | 游戏服务副本（可能用于分线） |
| 4 | **gate_server** | server/server/gate_server | C++ + XML | 网关服务（连接客户端） |
| 5 | **name_server** | server/server/name_server | Java + XML | 名称服务（唯一 ID 生成） |
| 6 | **proxy_server** | server/server/proxy_server | C++ + XML | 代理服务（跨服通信） |
| 7 | **sdk_server** | server/server/sdk_server | Java + XML | SDK 服务（第三方平台对接） |
| 8 | **spirit_server** | server/server/spirit_server | XML/配置 | 精灵服务配置目录 |
| 9 | **trans_server** | server/server/trans_server | Java + XML | 事务服务 |
| 10 | **web_app** | server/server/web_app | XML/资源 | Web 相关资源目录 |
| 11 | **zone_server** | server/server/zone_server | XML/资源 | 区域服务资源目录 |

> 说明：`server/server/common/logservice/` 以 C++ 文件为主，属于 `common` 目录下的日志组件实现，不再单独按 Java 服务目录统计。

## 3. gnet 网络框架分析

### 3.1 框架架构

gnet 是 MT3 项目的自研高性能 RPC 网络框架，采用分层架构：

```
┌─────────────────────────────────────────┐
│              gnet 框架架构               │
├─────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐     │
│  │   Protocol  │    │    RPC      │     │
│  │  Definition │ →  │  Generator  │     │
│  │   (.xml)    │    │  (rpcgen)   │     │
│  └─────────────┘    └──────┬──────┘     │
│                            │            │
│  ┌─────────────┐    ┌──────▼──────┐     │
│  │   Handler   │ ←  │   Manager   │     │
│  │  (业务逻辑)  │    │   (路由)    │     │
│  └─────────────┘    └──────┬──────┘     │
│                            │            │
│  ┌─────────────────────────▼───────────┐│
│  │           Network Layer             ││
│  │       (NIO + 多线程处理器)           ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

### 3.2 核心类定义

#### Rpc.java（RPC 基类）

```java
package com.locojoy.IO.Protocol;

public class Rpc extends Protocol {
    private static Map<XID,Rpc> map = Collections.synchronizedMap(new HashMap<XID,Rpc>());
    private static HouseKeeper housekeeper = new HouseKeeper();
    private XID xid = new XID();
    private TimerObserver.WatchDog timer = new TimerObserver.WatchDog();
    protected Data argument;
    protected Data result;
    protected long time_policy;
    
    // 超时处理
    private static class HouseKeeper implements Observer {
        public void update(Observable o, Object arg) {
            // 检查并清理超时的 RPC 调用
        }
    }
    
    // XID 用于唯一标识 RPC 请求
    private static class XID implements Marshal, Cloneable {
        public int count = 0;
        private boolean is_request = true;
    }
}
```

## 4. xbean 数据系统分析

### 4.1 框架架构

xbean 是 MT3 项目的数据持久化系统，基于 XDB 文件数据库：

```

│              xbean 框架架构              │
├─────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐     │
│  │   xbean     │    │    Table    │     │
│  │  Definition │ →  │   Schema    │     │
│  │   (.xml)    │    │  (生成代码)  │     │
│  └─────────────┘    └──────┬──────┘     │
│                            │            │
│  ┌─────────────┐    ┌──────▼──────┐     │
│  │  Procedure  │ ←  │   Cache     │     │
│  │  (事务处理)  │    │   Layer     │     │
```

### 4.5 Procedure 事务模式

代码中发现的 Procedure 子类数量：**300+ 个**

主要 Procedure 类命名模式：

| 前缀 | 说明 | 示例 |
|------|------|------|
| P | 普通事务处理 | PAddExpProc, PLevelUpProc |
| C | 客户端请求处理 | CEnterWorld, CCreateRole |
| S | 服务器响应 | SRoleList, SEnterWorld |
| D | 数据库操作 | DPGiveItem |

典型 Procedure 实现：

```java
public class PAfterEnterWorld extends Procedure {
    @Override
    protected boolean process() {
        // 事务处理逻辑
        // 1. 获取数据
        // 2. 修改数据
        // 3. 返回 true 提交事务
        return true;
    }
}
```
