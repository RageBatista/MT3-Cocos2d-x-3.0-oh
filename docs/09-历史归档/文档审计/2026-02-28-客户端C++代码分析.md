## 2. 核心接口分析

### 2.1 IEngine 接口（图形引擎）

**文件位置**: [`engine/nuiengine.h`](../../../engine/nuiengine.h)

```cpp
class IEngine
{
public:
    // 屏幕信息
    virtual int GetScreenWidth() = 0;
    virtual int GetScreenHeight() = 0;
    virtual int GetLogicWidth() = 0;
    virtual int GetLogicHeight() = 0;
    
    // 引擎生命周期
    virtual bool Run(const EngineParameter &ep) = 0;
    virtual bool Exit() = 0;
    
    // 核心接口获取
    virtual IWorld* GetWorld() = 0;
    virtual IEnv* GetEnv() = 0;
    virtual IApp* GetApp() = 0;
    virtual Renderer* GetRenderer() = 0;
    virtual INuclearFileIO* GetFileIO() = 0;
    
    // Cocos2d-x 层集成
    virtual void SetEngineLayer(cocos2d::CCLayer* aPLayer) = 0;
    virtual cocos2d::CCLayer* GetEngineLayer() = 0;
    
    // 精灵管理（非世界精灵）
    virtual EngineSpriteHandle CreateEngineSprite(const std::wstring &modelname, bool async, bool isUISprite=false) = 0;
    virtual void ReleaseEngineSprite(EngineSpriteHandle handle) = 0;
    
    // 特效管理
    virtual IEffect* CreateEffect(const std::wstring &effectname, bool async = true) = 0;
    virtual void DrawEffect(IEffect* pEffect) = 0;
    virtual void ReleaseEffect(IEffect* pEffect) = 0;
    
    // 性能相关
    virtual float GetFPS() const = 0;
    virtual float GetCurMemSize() = 0;
    virtual void GCNow() = 0;
};
```

**关键发现**:
- IEngine 通过 `SetEngineLayer()` 与 Cocos2d-x 集成
- 提供完整的精灵和特效生命周期管理
- 支持 FPS 控制和内存管理

## 5. 架构验证

### 5.1 五层架构确认

根据代码分析，MT3 项目实际实现为 **四层架构**（而非文档中描述的五层）：

```
┌─────────────────────────────────────────────────────────────┐
│  Layer 4: FireClient 业务层 (C++)                           │
│  - GameApplication (继承 IApp)                              │
│  - Lua 脚本系统 (LuaEngine, LuaFireClient)                  │
│  - UI管理 (GameUIManager)                                   │
│  - 战斗系统 (BattleManager, Battler, Skill)                 │
│  - 网络通信 (NetConnection, MessageManager)                 │
│  - 配置数据 (ConfigManager, GameTable)                      │
└─────────────────────────────────────────────────────────────┘
                         ↓ IApp 接口
┌─────────────────────────────────────────────────────────────┐
│  Layer 3: Nuclear 引擎层 (~17k 行)                          │
│  - IEngine/IWorld/IEnv/IQuery 核心接口                      │
│  - 场景/精灵/动画/特效管理                                   │
│  - A* 寻路系统 (astar/)                                     │
│  - 粒子系统 (particlesystem/)                               │
│  - 渲染器 (renderer/)                                       │
└─────────────────────────────────────────────────────────────┘
                         ↓ CCLayer 桥接
┌─────────────────────────────────────────────────────────────┐
│  Layer 2: Cocos2d-x 2.2.6 层                                │
│  - libcocos2d + CocosDenshion                               │
│  - OpenGL ES 渲染                                           │
└─────────────────────────────────────────────────────────────┘
                         ↓ Platform API
┌─────────────────────────────────────────────────────────────┐
│  Layer 1: 平台层                                            │
│  - Win32/Android/iOS                                        │
│  - OpenGL, DirectShow, FMOD                                 │
└─────────────────────────────────────────────────────────────┘
```

**架构说明**:
- Lua 脚本与 C++ 业务逻辑深度耦合在 FireClient 业务层中
- 实际为四层架构，而非文档中描述的五层架构

### 5.2 跨层调用验证

| 调用路径 | 实现方式 | 代码证据 |
|----------|----------|----------|
| Lua → FireClient | tolua++ 绑定 | `LuaFireClient.cpp`, `engine.pkg` |
| FireClient → Nuclear | IEngine 接口 | `GameApplication.h` 包含 `nuiengine.h` |
| Nuclear → Cocos2d-x | CCLayer 桥接 | `IEngine::SetEngineLayer(cocos2d::CCLayer*)` |
| Cocos2d-x → Platform | Platform API | cocos2dx/platform/ |

**说明**: 精灵支持最多 12 层装备组件，用于实现角色换装系统。

### 6.2 坐标系统

```cpp
// 精灵使用两套坐标系:
// 世界坐标: 对应实际地图上的像素坐标
// 逻辑坐标: 对应可达图、服务器逻辑格子
// 
// 换算关系:
// 世界坐标.x == 逻辑坐标.x * N
// 世界坐标.y == 逻辑坐标.y
// N = [1, 2]
```

### 6.3 动作加载类型

## 7. 与现有文档的差异点

### 7.1 架构描述差异

| 文档描述 | 实际实现 | 说明 |
|----------|----------|------|
| 五层架构 | 四层架构 | Lua 脚本层与 FireClient 业务层深度耦合 |
| Layer 5: Lua 脚本层 | 集成在 Layer 4 | Lua 通过 tolua++ 直接调用 C++ |

### 7.2 接口命名差异

| 文档描述 | 实际代码 | 说明 |
|----------|----------|------|
| IEngine::Initialize() | IEngine::Run() | 引擎启动方法名不同 |
| IWorld::CreateSprite() | IWorld::NewSprite() | 精灵创建方法名不同 |

### 7.3 未在文档中记录的接口

- `IQuery` 接口 - 用于查询动作信息和精灵层信息
- `IImmovableObj` 接口 - 地图上不可移动对象
- `ISelectableObj` 接口 - 可选择对象基类
- `SpriteNotify` 类 - 精灵帧通知回调
- `SpriteEventNotify` 类 - 精灵事件通知回调

### 7.4 未在文档中记录的枚举

- `XPSPRITE_ACTION_LOAD_TYPE` - 动作加载类型
- `XPSPREFF_FLAG` - 特效绑定标志
- `XPUSA_TYPE` - 精灵动作更新类型
- `Nuclear_Mouse_TestMode` - 鼠标检测模式
