## 二、Android客户端核心业务流程

### 2.1 应用启动流程

#### 2.1.1 流程定义

```
Mt3Application.attachBaseContext()
    ↓
MultiDex.install()
    ↓
GameApp.onCreate()
    ↓
setIsYYBByCfgFile()  // 读取渠道配置
    ↓
SDKShare.init()  // 初始化分享SDK
    ↓
MQManager.init()  // 初始化美洽客服SDK
    ↓
nativeStartResourceUpdate()  // 开始资源更新
    ↓
initializeGame()  // 初始化游戏引擎
```

#### 2.1.2 关键调用点

| 步骤 | 调用点 | 文件位置 | 说明 |
|------|---------|----------|------|
| 1 | `Mt3Application.attachBaseContext()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/Mt3Application.java:8` | 应用附加上下文 |
| 2 | `MultiDex.install()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/Mt3Application.java:11` | 安装MultiDex支持 |
| 3 | `GameApp.onCreate()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/GameApp.java:252` | Activity创建 |
| 4 | `setIsYYBByCfgFile()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/GameApp.java:193` | 设置应用宝渠道标识 |
| 5 | `SDKShare.init()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/GameApp.java:268` | 初始化分享SDK |
| 6 | `MQManager.init()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/GameApp.java:272` | 初始化美洽客服SDK |
| 7 | `nativeStartResourceUpdate()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/GameApp.java:154` | 开始资源更新 |
| 8 | `initializeGame()` | `client/android/LocojoyProject/src/com/locojoy/mini/mt3/GameApp.java:1039` | 初始化游戏引擎 |

#### 2.1.3 异常处理机制

| 异常类型 | 处理方式 | 代码位置 |
|-----------|---------|----------|
| MultiDex安装失败 | 系统自动处理 | Android系统 |
