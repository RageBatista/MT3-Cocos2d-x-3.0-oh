# Android 环境配置

> 返回 [Android 文档索引](00-README.md)。本页只负责固定工具链的安装、配置与验证。

## 1. 当前主线

```text
NDK r16 clang + Ant + JDK 8 + Python 2.7
```

当前工作机已验证样例：

| 组件 | 样例路径 | 必要条件 |
| --- | --- | --- |
| JDK 8 | `C:\Program Files\Java\jdk1.8.0_144` | `java`、`javac` 为 1.8 |
| Android SDK | `D:\android-sdk_r24.1.2-windows\android-sdk-windows` | 同时含 Ant、platform-tools、22.0.1、android-22 |
| NDK r16 | `D:\Android\android-sdk-64\ndk\16.1.4479499` | `source.properties` 为 r16，使用 clang |
| Ant | `D:\apache-ant-1.9.7` | `bin/ant.bat` 可执行 |
| Python 2.7 | `C:\Python27` | `python.exe --version` 为 2.7 |

固定路径是已验证样例，不代表允许降低版本或混用不完整 SDK。

## 2. SDK 完整性

以下路径必须同时存在：

```text
tools/ant/build.xml
platform-tools/adb.exe
build-tools/22.0.1/aapt.exe
build-tools/22.0.1/zipalign.exe
platforms/android-22/android.jar
```

```powershell
$sdk = "D:\android-sdk_r24.1.2-windows\android-sdk-windows"
@(
  "$sdk\tools\ant\build.xml",
  "$sdk\platform-tools\adb.exe",
  "$sdk\build-tools\22.0.1\aapt.exe",
  "$sdk\build-tools\22.0.1\zipalign.exe",
  "$sdk\platforms\android-22\android.jar"
) | ForEach-Object { [PSCustomObject]@{ Path = $_; Exists = Test-Path -LiteralPath $_ } }
```

## 3. 当前 PowerShell 进程配置

优先使用进程级变量，避免全局 PATH 漂移：

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk1.8.0_144"
$env:ANDROID_HOME = "D:\android-sdk_r24.1.2-windows\android-sdk-windows"
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:ANDROID_NDK_HOME = "D:\Android\android-sdk-64\ndk\16.1.4479499"
$env:NDK_HOME = $env:ANDROID_NDK_HOME
$env:ANT_HOME = "D:\apache-ant-1.9.7"
$env:Path = "$env:JAVA_HOME\bin;$env:ANDROID_HOME\tools;$env:ANDROID_HOME\platform-tools;$env:ANDROID_HOME\build-tools\22.0.1;$env:ANT_HOME\bin;$env:ANDROID_NDK_HOME;$env:Path"
```

Python 2.7 验证：

```powershell
& "C:\Python27\python.exe" --version
```

## 5. 常见环境漂移

| 现象 | 直接原因 | 动作 |
| --- | --- | --- |
| `source option 5 is no longer supported` | 新版 JDK 抢占旧 Ant 工程 | 在当前进程强制 JDK8，再运行 JDK8 门禁 |
| `tools/ant/build.xml` 缺失 | SDK 根不完整 | 切换到完整旧 SDK |
| `SDK Platform Tools component is missing` | 缺 `platform-tools` | 补齐或切换完整 SDK |
| `ndk-build.cmd` 解析到错误版本 | PATH/环境变量漂移 | 显式传 `-NdkBuildPath` |
| `ant.bat` 找不到 | `ANT_HOME` 或 PATH 错误 | 显式传 `-AntPath` 或修正 Ant 1.9.x |

不要通过修改业务代码绕过工具链门禁。
