# Android 排错手册

> 返回 [Android 文档索引](00-README.md)。本页按“首个失败阶段”处理环境、Ant/dx、资源、ABI、安装和运行故障。

## 1. 先保留证据

记录以下信息后再修改：

- wrapper 的首个失败命令与退出码；
- `-PlanOnly -Json` 输出；
- `java/javac/ant/ndk-build` 实际路径和版本；
- APK 路径、大小、SHA256 与 `aapt dump badging`；
- 运行问题的 `adb logcat` 和设备 ABI。

当前入口为 `tools/scripts/Build-Android-Locojoy-WithGate.ps1`，当前输出为 `client/android/LocojoyProject/bin/mt3-*.apk`。

## 2. 首错矩阵

| 现象 | 直接阻塞点 | 最小动作 |
| --- | --- | --- |
| `tools/ant/build.xml` 缺失 | SDK 根不完整 | 切换到完整旧 SDK |
| `SDK Platform Tools component is missing` | 缺 `platform-tools` | 补齐 SDK 组件 |
| `source option 5 is no longer supported` | 非 JDK8 抢占 Ant | 强制当前进程使用 JDK8并跑门禁 |
| `ndk-build` 版本门禁失败 | 未使用 NDK r16 | 显式传正确 `-NdkBuildPath` |
| `antcontrib` 类找不到 | Ant 扩展缺失 | 恢复 `ANT_HOME/lib/ant-contrib*.jar` |
| `ParseException ... version (0034.0000)` | MeiqiaSdk 字节码不兼容旧 dx | 检查 [MeiqiaSdk/dx 专项](08-MeiqiaSdk-dx兼容修复.md) |
| `com.locojoy.sdk` 缺类 | 源码/jar 基线不全 | 恢复 `GameSDK`、`SDKShare`、`ljsdk_sample.jar` |
| APK not found | 仍查旧路径 | 使用 wrapper 回显的 `bin/mt3-*.apk` |
| `INSTALL_FAILED_NO_MATCHING_ABIS` | 设备 ABI 与 APK 不匹配 | 对比设备 ABI 与 APK `native-code` |
| `UnsatisfiedLinkError` | APK 缺 so、ABI 错或 JNI 初始化失败 | 跑 ABI/ARM64 门禁并抓完整 logcat |
| 获取版本信息失败 | 配置/哈希/热更索引不一致 | 回到 [登录注册 URL 链路](05-登录注册URL链路.md) 与资源指南 |

## 3. 环境与 Ant/dx

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk1.8.0_144"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Assert-AndroidJdk8Gate.ps1 -JdkHome $env:JAVA_HOME
Get-Command java.exe,javac.exe -All | Select-Object Name,Source
```

SDK 完整性与环境体检见 [环境配置](03-环境配置.md)。不要通过调整业务 Java 源码掩盖工具链漂移。

## 4. 资源不同步

```text
源目录: client/resource/res/**
打包入口: client/resource/tools/LJFilePack_打包安卓.bat
生成目录: client/android/LocojoyProject/assets/res/**
规则: 生成目录不接受业务手工修改
```

处理顺序：

1. 回到源目录修正资源。
2. 运行 `LJFilePack_打包安卓.bat`。
3. 用 wrapper `-SyncRes -ResSourceDir client/res_android/res` 刷新工程。
4. 若删除过资源，额外核对目标多余文件；当前 `robocopy /E` 不做镜像删除。
5. 重跑 LJFM 资源路径与 APK 结构门禁。

## 5. ABI 与 Native

当前基线：`arm64-v8a + android-21 + c++_shared + clang`。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Assert-AndroidArm64Migration.ps1 -RequireBuiltSharedLibs
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Assert-ApkAbiContents.ps1 `
  -ApkPath .\client\android\LocojoyProject\bin\mt3-debug.apk `
  -RequiredAbis arm64-v8a `
  -RequiredSoByAbi "arm64-v8a:libgame.so;arm64-v8a:libc++_shared.so;arm64-v8a:libdu.so;arm64-v8a:liblocSDK6a.so"
```

设备侧：

```powershell
adb shell getprop ro.product.cpu.abi
adb shell getprop ro.product.cpu.abilist
```

`UnsatisfiedLinkError` 还需检查 `nativeInitJniBridge(this)` 是否先于 `nativeSetPaths(...)`，以及 `JniHelper` 的 ClassLoader 兜底；详见 [ARM64 适配](09-ARM64适配.md)。

## 6. 安装与 MuMu

- 签名冲突：确认包名和签名，必要时先卸载测试包，再安装当前产物。
- `adb devices` 为空：先确认模拟器已启动，再检查模拟器内 `adbd` 是否监听。
- 安装成功但启动崩溃：保留从进程启动前开始的 logcat，搜索 `FATAL EXCEPTION`、`SIGSEGV`、`UnsatisfiedLinkError`。

```powershell
adb install -r .\client\android\LocojoyProject\bin\mt3-debug.apk
adb logcat -c
adb logcat
```

## 7. 渠道与历史路径

- 当前 wrapper 只接受 `free`。
- 其他渠道 build file 未恢复并复验前，不把旧批处理菜单当作可用入口。
- `2026-06-19` 的 `build/bin/mt3-release.apk` 是历史样本；现行 wrapper 使用 `bin/mt3-debug.apk` 或 `bin/mt3-release.apk`。

## 8. 运行验收

1. 登录首屏显示正常。
2. 点击进入游戏连续 3 次稳定进入。
3. logcat 无新增 `FATAL EXCEPTION`、`SIGSEGV`、`UnsatisfiedLinkError`。

仍有问题时，把首个失败阶段、命令、退出码和日志交给对应专题，不跨域同时修改 UI、网络与构建链。
