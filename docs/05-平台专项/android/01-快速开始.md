# Android 快速开始

> 返回 [Android 文档索引](00-README.md)。本页只提供当前 free 构建的最短路径。

## 1. 前置条件

- 已按 [环境配置](03-环境配置.md) 固定 `NDK r16 clang + Ant + JDK 8 + Python 2.7`。
- 已完成 [打包前检查清单](02-打包前检查清单.md)。
- 当前目录为仓库根 `E:\MT3`。

先查看 wrapper 计划：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Build-Android-Locojoy-WithGate.ps1 `
  -ProjectDir "client/android/LocojoyProject" -BuildType Debug -Channel free -Jobs 4 `
  -NdkBuildPath "D:\Android\android-sdk-64\ndk\16.1.4479499\ndk-build.cmd" `
  -JdkHome "C:\Program Files\Java\jdk1.8.0_144" `
  -AndroidSdkRoot "D:\android-sdk_r24.1.2-windows\android-sdk-windows" `
  -PlanOnly -Json
```

## 2. 资源有改动时

```text
源目录: client/resource/res/**
打包入口: client/resource/tools/LJFilePack_打包安卓.bat
生成目录: client/android/LocojoyProject/assets/res/**
规则: 生成目录不接受业务手工修改
```

先生成 Android 同步输入：

```powershell
cmd /c "cd /d E:\MT3\client\resource\tools && LJFilePack_打包安卓.bat"
```

## 3. 构建 Debug 包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Build-Android-Locojoy-WithGate.ps1 `
  -ProjectDir "client/android/LocojoyProject" -BuildType Debug -Channel free -Jobs 4 `
  -SyncRes -ResSourceDir "client/res_android/res" `
  -NdkBuildPath "D:\Android\android-sdk-64\ndk\16.1.4479499\ndk-build.cmd" `
  -JdkHome "C:\Program Files\Java\jdk1.8.0_144" `
  -AndroidSdkRoot "D:\android-sdk_r24.1.2-windows\android-sdk-windows" `
  -RequireArm64InApk
```

无资源变化时可去掉 `-SyncRes -ResSourceDir ...`。日常增量不加 `-Clean`；只有工具链/ABI 漂移、脏中间产物或发版验收时才清理。

## 4. 产物与安装

当前 Debug 产物：

```text
client/android/LocojoyProject/bin/mt3-debug.apk
```

```powershell
& "D:\android-sdk_r24.1.2-windows\android-sdk-windows\build-tools\22.0.1\aapt.exe" dump badging .\client\android\LocojoyProject\bin\mt3-debug.apk
& "D:\android-sdk_r24.1.2-windows\android-sdk-windows\platform-tools\adb.exe" install -r .\client\android\LocojoyProject\bin\mt3-debug.apk
```

Release 构建需要通过参数或 `MT3_ANDROID_*` 环境变量提供签名信息，详见 [构建流程](04-构建流程.md)。

## 5. 失败时

- 环境或工具解析失败：回到 [环境配置](03-环境配置.md)。
- wrapper 阶段失败：查看 [构建流程](04-构建流程.md)。
- ABI、安装、运行或 MuMu 问题：查看 [排错手册](06-排错手册.md)。
