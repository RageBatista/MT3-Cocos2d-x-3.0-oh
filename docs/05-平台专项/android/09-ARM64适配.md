# Android ARM64 适配

> 返回 [Android 文档索引](00-README.md)。本页只保留可复用的 arm64 代码、第三方库、构建和验证步骤；日期交付证据位于历史归档。

## 1. 当前 ARM64 基线

`client/android/LocojoyProject/jni/Application.mk` 必须保持：

```text
APP_ABI := arm64-v8a
APP_PLATFORM := android-21
APP_STL := c++_shared
NDK_TOOLCHAIN_VERSION := clang
```

Native 主线固定为 NDK r16 clang；Java/打包链固定为 Ant、JDK8，辅助脚本环境包含 Python 2.7。

## 4. 可复用示例：重建 libjpeg-turbo ARM64 静态库

### 4.1 边界与准备

- 外部源码目录由操作者自行选择；下例 `E:\thirdparty\libjpeg-turbo` 只是示例，不是仓库固定入口。
- 使用与主工程一致的 NDK r16 clang、`arm64-v8a`、`android-21`。
- 静态库必须以 PIC 构建，供 `libgame.so` 链接。
- 使用 CMake `>= 3.22` 与 Ninja，并同时满足所选 libjpeg-turbo 源码版本；先确认二者可执行。
- 从仓库根 `E:\MT3` 执行以下 PowerShell。

```powershell
$repoRoot = (Resolve-Path .).Path
$sourceRoot = "E:\thirdparty\libjpeg-turbo" # 示例外部源码目录
$buildRoot = Join-Path $sourceRoot "build-arm64-r16"
$ndkRoot = "D:\Android\android-sdk-64\ndk\16.1.4479499"
$toolchain = Join-Path $ndkRoot "build\cmake\android.toolchain.cmake"
$readelf = Join-Path $ndkRoot "toolchains\aarch64-linux-android-4.9\prebuilt\windows-x86_64\bin\aarch64-linux-android-readelf.exe"
$cmake = (Get-Command cmake.exe -ErrorAction Stop).Source
$ninja = (Get-Command ninja.exe -ErrorAction Stop).Source
$cmakeVersionText = (& $cmake --version | Select-Object -First 1)
$cmakeVersion = [version]([regex]::Match($cmakeVersionText, '\d+\.\d+\.\d+').Value)
if ($cmakeVersion -lt [version]'3.22.0') { throw "CMake >= 3.22 is required, found $cmakeVersion" }
& $ninja --version
if ($LASTEXITCODE -ne 0) { throw "Ninja version check failed: $LASTEXITCODE" }

@(
  (Join-Path $sourceRoot "CMakeLists.txt"),
  $toolchain,
  $readelf
) | ForEach-Object {
  if (-not (Test-Path -LiteralPath $_ -PathType Leaf)) { throw "Missing prerequisite: $_" }
}
```

### 4.2 CMake + Ninja 配置与构建

```powershell
& $cmake -S $sourceRoot -B $buildRoot -G Ninja `
  "-DCMAKE_MAKE_PROGRAM=$ninja" `
  "-DCMAKE_TOOLCHAIN_FILE=$toolchain" `
  "-DANDROID_ABI=arm64-v8a" `
  "-DANDROID_PLATFORM=android-21" `
  "-DCMAKE_BUILD_TYPE=Release" `
  "-DCMAKE_POSITION_INDEPENDENT_CODE=ON" `
  "-DENABLE_SHARED=OFF" `
  "-DENABLE_STATIC=ON" `
  "-DWITH_SIMD=ON"
if ($LASTEXITCODE -ne 0) { throw "libjpeg-turbo CMake configure failed: $LASTEXITCODE" }

& $cmake --build $buildRoot -- -j4
if ($LASTEXITCODE -ne 0) { throw "libjpeg-turbo build failed: $LASTEXITCODE" }
```

不锁定具体 CMake target 名，避免不同 libjpeg-turbo 版本在 `jpeg` / `jpeg-static` 命名上产生差异；构建完成后按文件定位产物。

### 4.3 定位、ELF 核验与回填

```powershell
$candidates = @(Get-ChildItem -LiteralPath $buildRoot -Recurse -File -Filter "libjpeg.a")
if ($candidates.Count -eq 0) { throw "libjpeg.a was not produced under $buildRoot" }
$candidates | Select-Object FullName,Length,LastWriteTime

# 多个候选时必须结合本轮 Release 构建输出选择，禁止静默猜测。
if ($candidates.Count -ne 1) { throw "Expected one libjpeg.a candidate, found $($candidates.Count)" }
$jpeg = $candidates[0]

& $readelf -h $jpeg.FullName | Select-String "Class:|Machine:"
if ($LASTEXITCODE -ne 0) { throw "readelf failed for $($jpeg.FullName)" }

$targetDir = Join-Path $repoRoot "dependencies\jpeg\prebuilt\android\arm64-v8a"
$target = Join-Path $targetDir "libjpeg.a"
New-Item -ItemType Directory -Path $targetDir -Force | Out-Null
Copy-Item -LiteralPath $jpeg.FullName -Destination $target -Force

Select-String -Encoding UTF8 -SimpleMatch `
  -LiteralPath (Join-Path $repoRoot "dependencies\jpeg\prebuilt\android\Android.mk") `
  -Pattern 'LOCAL_SRC_FILES := $(TARGET_ARCH_ABI)/libjpeg.a'
& $readelf -h $target | Select-String "Class:|Machine:"
if ($LASTEXITCODE -ne 0) { throw "readelf failed for $target" }
```

期望 `readelf` 显示 `ELF64` / `AArch64`。PIC 由 `CMAKE_POSITION_INDEPENDENT_CODE=ON` 固定，并在后续 `libgame.so` 链接的 `--no-undefined` 门禁中继续验证。

`dependencies/jpeg/prebuilt/android/Android.mk` 当前引用：

```make
LOCAL_SRC_FILES := $(TARGET_ARCH_ABI)/libjpeg.a
```

因此回填目标固定为 `dependencies/jpeg/prebuilt/android/arm64-v8a/libjpeg.a`，不通过绝对路径修改 `Android.mk` 绕过目录约定。

## 5. Cocos2d-x 与 JNI

- `cocos2d-x-2.2.6/cocos2dx/Android.mk` 不得导入历史 2.0 树的 `libxml2/libwebp`。
- `libwebp.a`、`libxml2.a` 必须位于当前 2.2.6 树并纳入版本控制/LFS 基线。
- `Cocos2dxActivity` 声明并调用 `nativeInitJniBridge(this)`。
- `nativeInitJniBridge(this)` 必须先于 `nativeSetPaths(...)`。
- `JniHelper` 缓存 Activity `ClassLoader`，供 Native 线程加载 Java 类。

## 7. ELF、APK 与设备验证

```powershell
$readelf = "D:\Android\android-sdk-64\ndk\16.1.4479499\toolchains\aarch64-linux-android-4.9\prebuilt\windows-x86_64\bin\aarch64-linux-android-readelf.exe"

powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Assert-ApkAbiContents.ps1 `
  -ApkPath .\client\android\LocojoyProject\bin\mt3-debug.apk `
  -RequiredAbis arm64-v8a `
  -RequiredSoByAbi "arm64-v8a:libgame.so;arm64-v8a:libc++_shared.so;arm64-v8a:libdu.so;arm64-v8a:liblocSDK6a.so"
adb install -r .\client\android\LocojoyProject\bin\mt3-debug.apk
adb shell dumpsys package com.locojoy.mini.mt3.locojoy | Select-String 'primaryCpuAbi|secondaryCpuAbi'
```
