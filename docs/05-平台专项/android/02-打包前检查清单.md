# Android 打包前检查清单

> 返回 [Android 文档索引](00-README.md)。本页只负责发版前的逐项准入判断。

## 1. 工具链

- [ ] 当前主线为 `NDK r16 clang + Ant + JDK 8 + Python 2.7`。
- [ ] `ANDROID_HOME` / `ANDROID_SDK_ROOT` 指向完整旧 SDK。
- [ ] SDK 同时包含 `tools/ant/build.xml`、`platform-tools`、`build-tools/22.0.1`、`platforms/android-22`。
- [ ] `ant.bat`、`ndk-build.cmd`、Python 2.7、JDK8 的 `java/javac` 均可执行。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Assert-AndroidJdk8Gate.ps1 -JdkHome "C:\Program Files\Java\jdk1.8.0_144"
powershell -NoProfile -ExecutionPolicy Bypass -File .\.agents\skills\android-r10e-build\scripts\verify-android-r10e-env.ps1 -Json
```

技能脚本文件名保留历史命名，检查结果必须显示当前 r16/clang/Ant/JDK8 链。

## 2. 工程与渠道

- [ ] `client/android/LocojoyProject/build.xml`、`AndroidManifest.xml`、`project.properties` 存在。
- [ ] `tools/scripts/Build-Android-Locojoy-WithGate.ps1` 存在。
- [ ] 本轮渠道为 `free`；其他渠道未恢复并重新验收前不进入当前主线。
- [ ] `client/android/common/libs/ljsdk_sample.jar`、`GameSDK.java`、`SDKShare.java` 存在。

```powershell
Test-Path .\client\android\LocojoyProject\build.xml
Test-Path .\client\android\common\libs\ljsdk_sample.jar
Test-Path .\client\android\common\src\com\locojoy\sdk\GameSDK.java
Test-Path .\client\android\common\src\com\locojoy\sdk\SDKShare.java
```

## 3. 资源边界

```text
源目录: client/resource/res/**
打包入口: client/resource/tools/LJFilePack_打包安卓.bat
生成目录: client/android/LocojoyProject/assets/res/**
规则: 生成目录不接受业务手工修改
```

- [ ] 业务资源差异全部来自 `client/resource/res/**`。
- [ ] 已运行 `LJFilePack_打包安卓.bat` 生成 `client/res_android/res/**`。
- [ ] `assets/res/**` 只由资源打包与 wrapper 同步链刷新。
- [ ] 需要删除旧镜像文件时已显式核对；wrapper 当前 `robocopy /E` 不删除目标多余文件。

## 4. 构建计划

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Build-Android-Locojoy-WithGate.ps1 `
  -ProjectDir "client/android/LocojoyProject" -BuildType Release -Channel free -Jobs 4 `
  -SyncRes -ResSourceDir "client/res_android/res" `
  -NdkBuildPath "D:\Android\android-sdk-64\ndk\16.1.4479499\ndk-build.cmd" `
  -JdkHome "C:\Program Files\Java\jdk1.8.0_144" `
  -AndroidSdkRoot "D:\android-sdk_r24.1.2-windows\android-sdk-windows" `
  -RequireArm64InApk -PlanOnly -Json
```

- [ ] `project.dir` 指向 `LocojoyProject`。
- [ ] `project.buildSystem` 为 `Ant`。
- [ ] `native.abi` 为 `arm64-v8a`，`appPlatform` 为 `android-21`，STL 为 `c++_shared`。
- [ ] `build.outputApk` 为 `client/android/LocojoyProject/bin/mt3-release.apk`。

## 5. ABI 与依赖

- [ ] `Application.mk` 为 `APP_ABI := arm64-v8a`、`APP_PLATFORM := android-21`、`APP_STL := c++_shared`、`NDK_TOOLCHAIN_VERSION := clang`。
- [ ] `Assert-AndroidArm64Migration.ps1` 通过。
- [ ] arm64 静态库、`libdu.so`、`liblocSDK6a.so` 与 JNI ClassLoader bridge 齐全。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Assert-AndroidArm64Migration.ps1 -RequireBuiltSharedLibs
```

## 6. Release 签名

- [ ] keystore 与 alias 来自显式参数、CI Secret 或 `MT3_ANDROID_*` 环境变量。
- [ ] 已跟踪的 `ant.properties` 中没有密码。
- [ ] 已准备升级覆盖与签名一致性验证。

```powershell
$env:MT3_ANDROID_KEYSTORE = "KEYSTORE_PATH"
$env:MT3_ANDROID_KEY_ALIAS = "KEY_ALIAS"
$env:MT3_ANDROID_KEYSTORE_PASSWORD = "SECRET_FROM_LOCAL_OR_CI"
$env:MT3_ANDROID_KEY_ALIAS_PASSWORD = "SECRET_FROM_LOCAL_OR_CI"
```

## 7. 构建后门禁

- [ ] 当前产物位于 `client/android/LocojoyProject/bin/mt3-debug.apk` 或 `mt3-release.apk`。
- [ ] APK 非 ZIP64，Entry Count 不超过门禁值。
- [ ] APK 仅含 `arm64-v8a`，且包含 `libgame.so`、`libc++_shared.so`、`libdu.so`、`liblocSDK6a.so`。
- [ ] 资源路径、音频 JNI、启动黑屏防护、`zipalign -c 4`、`aapt dump badging` 通过。
- [ ] 安装、登录首屏、连续 3 次进入游戏与 logcat 门禁通过。

`2026-06-19` 归档中的 `build/bin/mt3-release.apk` 仅是当日样本；现行输出以 wrapper 的 `bin/mt3-*.apk` 为准。
