# Android 构建流程

> 返回 [Android 文档索引](00-README.md)。本页解释 Canonical wrapper 的真实阶段、输入、输出与门禁。

## 1. 当前入口与工具链

- 入口：`tools/scripts/Build-Android-Locojoy-WithGate.ps1`
- 工程：`client/android/LocojoyProject`
- 渠道：`free`
- 工具链：`NDK r16 clang + Ant + JDK 8 + Python 2.7`

先用 `-PlanOnly -Json` 查看解析后的工程、SDK/JDK/NDK/Ant、ABI 与输出路径；计划阶段不会编译。

## 2. 资源阶段

```text
源目录: client/resource/res/**
打包入口: client/resource/tools/LJFilePack_打包安卓.bat
生成目录: client/android/LocojoyProject/assets/res/**
规则: 生成目录不接受业务手工修改
```

实际链路：

```text
client/resource/res/**
  -> LJFilePack_打包安卓.bat
  -> client/res_android/res/**
  -> wrapper -SyncRes
  -> client/android/LocojoyProject/assets/res/**
```

`-SyncRes` 当前使用 `robocopy /E`，会复制子目录但不会删除目标多余文件。删除资源时必须额外核对生成目录，且所有差异仍须来自打包/同步链。

## 3. wrapper 阶段

1. 解析完整旧 SDK、JDK8、NDK r16 与 Ant。
2. 拒绝非 `free` 渠道、非 `LocojoyProject` 工程或检测到的非 Ant 后端。
3. 可选执行 Git LFS 关键输入检查/拉取。
4. 可选 `-SyncRes` 同步资源。
5. 可选 `-Clean`/`-CleanIntermediates` 删除工程中间目录；只有此时才执行 `ndk-build clean` 与 Ant `clean`。
6. 执行 `ndk-build NDK_DEBUG=0|1 -jN`，再复制必需 Native 运行库。
7. 在 `client/android/LocojoyProject` 根目录执行 `ant -buildfile build.xml debug|release`。
8. Release 从参数或 `MT3_ANDROID_*` 环境变量注入签名信息。
9. 验证固定输出 APK。
10. 依次运行 APK 结构、ABI、LJFM 资源路径、音频 JNI、启动黑屏防护与 `zipalign` 门禁，并输出 MD5/SHA256/badging。

## 4. 构建命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Build-Android-Locojoy-WithGate.ps1 `
  -ProjectDir "client/android/LocojoyProject" -BuildType Release -Channel free -Jobs 4 `
  -SyncRes -ResSourceDir "client/res_android/res" `
  -NdkBuildPath "D:\Android\android-sdk-64\ndk\16.1.4479499\ndk-build.cmd" `
  -JdkHome "C:\Program Files\Java\jdk1.8.0_144" `
  -AndroidSdkRoot "D:\android-sdk_r24.1.2-windows\android-sdk-windows" `
  -RequireArm64InApk
```

Release 密码不得写入仓库。若未提供密码，非交互构建会在打包前停止。

## 5. 当前输出

wrapper 在工程根目录固定查找：

```text
Debug:   client/android/LocojoyProject/bin/mt3-debug.apk
Release: client/android/LocojoyProject/bin/mt3-release.apk
```

`2026-06-19` 专项审计中的 `client/android/LocojoyProject/build/bin/mt3-release.apk` 是当时构建批次样本，只用于历史哈希与验收对照。

## 6. 手工分段定位

仅在 wrapper 已给出首个失败阶段后，才分段执行：

```powershell
Push-Location .\client\android\LocojoyProject
cmd /c "set ProgramW6432=C:\Program Files&& D:\Android\android-sdk-64\ndk\16.1.4479499\ndk-build.cmd NDK_DEBUG=0 -j4"
& "D:\apache-ant-1.9.7\bin\ant.bat" -buildfile build.xml debug
Pop-Location
```

手工链只用于定位 Native 或 Ant 首错，不替代 wrapper 的门禁和最终产物判定。
