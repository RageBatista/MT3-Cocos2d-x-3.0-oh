## 2. 样本操作检查单

### 打开

- 记录样本路径、文件版本和引用资源根。
- 检查缺失资源、日志首错、时间轴长度和预览初始帧。

### 编辑

- 记录修改的特效对象、参数、时间/关键帧和插值方式。
- 检查面板值、Document 数据和预览状态一致。

### 撤销/重做

- 单次操作对应一个可预期的命令。
- 撤销后数据和预览同时恢复，重做后结果一致。

### 保存/导出

- 保留原始样本备份。
- 保存后重新打开，检查资源引用、关键帧和时间。
- 在客户端预览同一产物，对比工具效果。

## 3. 排障顺序

1. 当前日志首错。
2. 资源路径/文件格式。
3. Document 加载状态。
4. 时间轴/关键帧数据。
5. 预览渲染与摄像机。
6. 保存/导出与客户端加载。

## 4. 维护提醒

- 不将工具内文档的示意代码无核对复制到当前实现。
- 不使用旧行号作为当前 API 存在的证据。
- 涉及引擎/文件格式时，保留历史样本和回滚产物。
