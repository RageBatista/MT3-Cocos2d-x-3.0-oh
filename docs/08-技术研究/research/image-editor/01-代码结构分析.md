# ImageEditor 代码结构分析

> **证据边界**：当前工作树缺少完整 ImageEditor 源码；下述结构是工具内 2026-04 文档记录的阶段性架构。
> **导航**：[00-README](00-README.md)。

## 1. 阶段性结构

```text
MFC application/frame
  -> CImageEditorDoc (document/data/file I/O)
  -> CImageEditorView (render/input/selection/zoom/pan)
  -> CImageInfoView (image list/properties)
  -> PImg and engine texture/data types
  -> dialogs/resource commands
```

## 2. 核心职责

| 区域 | 阶段性职责 |
| --- | --- |
| Document | PImg/图像数据、打开、保存、版本兼容和 dirty 状态。 |
| View | DirectX/引擎渲染、缩放平移、坐标转换、边界/遮罩交互。 |
| Info View | 图像列表、属性查看和选择同步。 |
| PImg | 图像模型、纹理/遮罩/边界数据和格式版本。 |

## 3. 输入输出

工具内文档记录 ImageEditor 支持图像资源与 PImg 类格式的加载/保存。实际签名、版本字段、序列化顺序和运行时兼容性必须在完整源码回流后用真实样本重新核对。

## 4. 高风险区

- 文件格式版本和历史样本兼容。
- 纹理资源的所有权、锁定/解锁和设备恢复。
- 屏幕坐标、图像坐标、缩放和滚动的双向转换。
- 遮罩/多边形点顺序、边界和命中检测。
- 保存失败、部分写入和回滚。

## 5. 维护建议

1. 使用可回滚的历史样本建立打开/编辑/保存/重打开回归。
2. 对坐标算法使用多种缩放、滚动位置和边界点测试。
3. 保留运行时客户端加载验证，不只在工具内预览。
