# ImageEditor 架构与工作流

> **证据边界**：本页基于工具内 2026-04 文档整理；当前工作树没有完整源码供重做行级验证。
> **导航**：[00-README](00-README.md)。

## 1. 打开流程

```text
select file
  -> Document detects format/version
  -> load PImg/image data
  -> create/update texture resources
  -> update ImageInfoView
  -> View calculates scroll/zoom/coordinates
  -> render image + mask/boundary overlays
```

失败时保留原 Document，记录文件版本、失败阶段和资源错误，不让部分加载数据进入可保存状态。

## 2. 编辑流程

```text
mouse/keyboard command
  -> screen-to-image coordinate transform
  -> hit test / edit mode
  -> mutate mask/boundary/image properties
  -> mark document dirty
  -> invalidate and render
```

坐标转换必须同时考虑 zoom、scroll offset、client origin 和图像边界。

## 3. 渲染流程

```text
View paint/update
  -> device/engine state
  -> image texture
  -> optional mask/boundary/control points
  -> selection/guide overlays
  -> present
```

预览与保存数据使用同一坐标语义，避免“工具显示正确、运行时边界偏移”。

## 4. 保存流程

1. 验证当前 Document 完整性。
2. 写入临时文件或可回滚副本。
3. 按格式版本序列化图像、属性、遮罩/边界数据。
4. 成功后替换目标并清除 dirty 状态。
5. 重新打开并与保存前模型对比。

## 5. 验证矩阵

| 维度 | 样本 |
| --- | --- |
| 格式/版本 | 当前样本、至少一个历史样本、损坏/截断样本。 |
| 坐标 | 100%、放大、缩小、滚动后四角/边界/中心点。 |
| 编辑 | 新增/删除/拖动控制点、遮罩与边界切换。 |
| 保存 | 无修改保存、有修改保存、写入失败、重打开。 |
| 运行时 | 客户端加载、渲染、碰撞/点选或对应业务流。 |
