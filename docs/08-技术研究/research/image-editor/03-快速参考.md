## 1. 按问题定位

| 现象 | 先查 |
| --- | --- |
| 打不开文件 | 格式魔数/版本、文件长度、资源路径、Document 错误。 |
| 图像黑块/缺图 | 纹理创建、格式、设备状态、资源生命周期。 |
| 点选/拖动偏移 | zoom、scroll、client origin、screen/image 坐标转换。 |
| 遮罩/边界异常 | 点顺序、边界、命中检测和保存语义。 |
| 保存后客户端不读 | 文件版本、序列化顺序、产物回流路径和打包索引。 |

## 2. 安全操作

1. 复制样本到隔离目录。
2. 记录原始 SHA256。
3. 打开后不修改直接保存一次，验证无变更往返。
4. 只做一个小修改，保存并重打开。
5. 在客户端验证同一产物。
6. 保留日志、截图、产物哈希和回滚副本。
