# 发布检查清单

> 当前跨平台发布入口。平台构建命令以对应 Canonical 文档为准，日期批次证据只在历史归档中引用。

## 1. 发布参数

- [ ] 客户端/资源/服务器版本号已冻结。
- [ ] 渠道、包名/Bundle ID、登录与热更新环境已冻结。
- [ ] Windows/Android/iOS 使用匹配的配置源与资源索引。
- [ ] 签名、证书、支付环境由本机或 CI Secret 注入，无凭证进入仓库。
- [ ] 上一版平台包、服务端包、资源索引和回滚负责人已确认。

## 2. 通用门禁

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Test-MT3-SecurityGate.ps1 -ReportPath build_logs/security-gate.json

powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Test-MT3-SecurityGate.ps1 -StrictHttp -ReportPath build_logs/security-gate-strict.json
```

- [ ] Add/Mod/Del、Size/CRC32 与平台配置哈希已复核。
- [ ] 冷启动、断网恢复、旧版升级和回滚路径已验证。

## 5. Android

主线固定为 `NDK r16 clang + Ant + JDK 8 + Python 2.7`。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\scripts\Build-Android-Locojoy-WithGate.ps1 `
  -ProjectDir "client/android/LocojoyProject" -BuildType Release -Channel free -Jobs 4 `
  -SyncRes -ResSourceDir "client/res_android/res" `
  -NdkBuildPath "D:\Android\android-sdk-64\ndk\16.1.4479499\ndk-build.cmd" `
  -JdkHome "C:\Program Files\Java\jdk1.8.0_144" `
  -AndroidSdkRoot "D:\android-sdk_r24.1.2-windows\android-sdk-windows" `
  -RequireArm64InApk
```

- [ ] 现行产物为 `client/android/LocojoyProject/bin/mt3-release.apk`。
- [ ] wrapper 的结构、ABI、资源路径、JNI、黑屏防护、`zipalign` 与 badging 门禁通过。
- [ ] 正式签名、升级覆盖、连续 3 次入世界与 logcat 门禁通过。

详细入口：[Android 文档索引](../../05-平台专项/android/00-README.md)。

- [ ] 若源定义变化，先执行对应 `genrpc`、`genxdb`、`gengbeans` 目标并审查生成差异。
- [ ] 执行 `dist`，保存 `server/server/game_server/dist/` 与日志。

```powershell
& ant -f .\server\server\game_server\build.xml dist
```

## 8. Artifact 留存

| 类型 | 当前路径/内容 |
| --- | --- |
| 通用门禁 | `build_logs/security-gate*.json`、`build_logs/resource-ui-gate.json` |
| Windows | `build_logs/**`、`client/resource/bin/Release/MT3.exe`、匹配 PDB |
| Android | `client/android/LocojoyProject/bin/mt3-release.apk`、wrapper JSON/日志、MD5/SHA256 |
| iOS | Archive/IPA、导出日志、签名摘要、设备日志 |
| Server | `server/server/game_server/dist/` 与 Ant 日志 |
| 热更新 | 成套 `ver.ljvi`/`fl.ljpi`、发布目录快照与回滚索引 |

`2026-06-19` Android arm64 的 `build/bin` APK、哈希与 MuMu 结果属于历史批次，见 [专项审计最终发布说明](../../09-历史归档/专项审计/Android-arm64-free/2026-06-19-最终发布说明.md)。

## 9. 回滚

- [ ] 停止继续分发失败产物。
- [ ] 恢复上一版平台包、服务端包或成套热更新索引/资源。
- [ ] 回滚后重新执行安装/升级、冷启动、登录和入世界。
- [ ] 记录触发条件、负责人、时间、影响范围与复验结果。
