# MT3 第三方依赖资产清单

> **定位**：盘点仓库内的第三方源码、头文件、静态库和运行时资产。
> **边界**：资产存在不表示当前主线正在使用；引用与兼容状态只见 [02-依赖矩阵](02-依赖矩阵.md)。
> **文档索引**：[docs/07-参考文档/02-文档索引.md](../07-参考文档/02-文档索引.md)

## 1. 客户端基础资产

| 资产 | 已核对版本/边界 | 位置 | 主要用途 |

## 4. 运行时产物

Win32 运行目录在 `client/resource/bin/<Configuration>/`。实际 DLL 集合应以当次构建产物、`mt3.win32.vcxproj` 后构建事件和启动验证为准，不在本页冻结一份可能过期的 DLL 文件名清单。

## 5. 维护方法

```powershell
Get-ChildItem -LiteralPath .\dependencies -Directory | Sort-Object Name
rg -n 'AdditionalDependencies|AdditionalLibraryDirectories|AdditionalIncludeDirectories' client engine tools --glob '*.vcxproj'
rg -n 'LOCAL_(C|CPP)_INCLUDES|LOCAL_(STATIC|SHARED)_LIBRARIES' client --glob 'Android.mk'
```

更新本页时只记录资产事实；版本兼容、CRT、ABI 和当前引用状态同步回写 [02-依赖矩阵](02-依赖矩阵.md)。
