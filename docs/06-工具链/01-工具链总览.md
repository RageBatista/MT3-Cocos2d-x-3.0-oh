## 2. 工具目录路由

| 目录 | 角色 | 常见任务 |
| --- | --- | --- |
| `tools/scripts/` | 已入库构建和校验脚本 | Win32 主链构建、产物校验、资源处理。 |
| `tools/engine/` | Nuclear 编辑器和资源工具 | MapEditor、EffectEditor、ImageEditor、SpriteEditor 等。 |
| `tools/CEGUI-0.7.1/` | CEGUI 0.7.1 配套源码/工具研究副本 | 仅供旧工具与差异对照。 |
| `tools/CEGUI-0.7.1-bulid/` | 历史预构建资产 | 保留用于旧工具与产物对照；目录名中的 `bulid` 是实际名称。 |
| `tools/CEGUI-0.7.9-r5/` | Win32 canonical CEGUI 0.7.9-r5 | `Upgrade30` 主线工程、renderer 与静态库入口。 |
| `dependencies/` | 客户端与工具的第三方资产 | 是否处于主线必须回到工程引用确认。 |

## 3. 主线版本边界

- Win32 客户端基础层：`cocos2d-x-3.0-oh/`，配置名为 `Upgrade30`。
- Win32 客户端 UI：`tools/CEGUI-0.7.9-r5/`。
- Android/iOS 兼容链：`cocos2d-x-2.2.6/` 与平台对应的 CEGUI 资产；不从 Win32 文档外推。
- 历史 `cocos2d-2.0-rc2-x-2.0.1/` 在当前工作树中不存在，其旧引用仅见于历史工程文件和日期化归档记录。

## 4. 维护规则

1. 先核对工程文件、脚本和产物，再更新文档。
2. 构建命令只收敛到 `03-开发指南/`、`05-平台专项/` 或本目录。
3. 研究文档中的路线图、示意代码和预期结果必须显式标为研究或规划。
4. 任何 ABI 敏感变更都按 [`.claude/RULES.md`](../../.claude/RULES.md) 和 [`.claude/BUILD_GUIDE.md`](../../.claude/BUILD_GUIDE.md) 执行整链重编。
