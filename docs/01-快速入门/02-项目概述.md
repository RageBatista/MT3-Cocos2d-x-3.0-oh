# 02-项目概述

> **项目**：MT3（梦幻西游 MG 版本）
> **形态**：Win32 / Android / iOS 客户端、Java 服务端及配套工具
> **当前事实基线**：根 `AGENTS.md`、源码、构建脚本与 `.claude/RULES.md`

## 1. 仓库定位

MT3 是一个混合技术栈的 2D MMORPG 工程。仓库包含共享 C++ 客户端主链、Lua 业务脚本、Java 服务端、资源发布链和多套历史工具工程。

当前规模不作为根级固定事实：根 `AGENTS.md` 第 10 节明确"不在根规则中固化会快速失真的代码行数"。如需统计，应由当前工作树重新生成，不复制历史数字。

## 2. 客户端四层主链

客户端运行时统一按以下四层理解：

```text
FireClient 业务层（C++、Lua、UI、协议与业务管理器）
        ↓
Nuclear 引擎层（场景、精灵、动画、特效与渲染抽象）
        ↓
Cocos2d-x 2.2.6 层（图形、音频与平台适配基础）
        ↓
Win32 / Android / iOS 平台层
```

Win32 canonical 已使用 `cocos2d-x-3.0-oh/`，并与 `engine/`、`FireClient`、`tools/CEGUI-0.7.9-r5/` 组成 `Upgrade30` 构建链；Android/iOS 仍使用 `cocos2d-x-2.2.6/`。历史 `cocos2d-2.0-rc2-x-2.0.1/` 在当前工作树中不存在。

## 3. 主要目录

| 路径 | 职责 |
| --- | --- |
| `client/MT3Win32App/` | Win32 入口与最终主工程 |
| `client/FireClient/Application/` | 共享 C++ 业务主链 |
| `client/resource/res/` | 业务资源源目录 |
| `client/android/` | Android 公共工程与渠道工程 |
| `engine/` | Nuclear 引擎源码 |
| `cocos2d-x-2.2.6/` | Android/iOS Cocos2d-x 基线 |
| `cocos2d-x-3.0-oh/` | Win32 canonical Cocos2d-x 3.0-oh 主线 |
| `common/` | 平台、文件、Lua、认证等基础库 |
| `dependencies/` | 第三方/vendor 依赖 |
| `gbeans/` | 服务端策划配置源 XML（`gengbeans` 输入） |
| `lib/` | 预编译库归置（`vs2013/`） |
| `server/server/` | 服务端模块与主构建目录 |
| `scheme_doc/` | 策划与测试文档 |
| `plans/` | 规划/分析报告 sidecar（非规范入口） |
| `build_logs/` | 构建日志与依赖审计证据 |
| `tools/` | 构建、编辑器、资源与发布工具 |
| `docs/` | 现行说明、专题资料与历史归档 |

## 4. 主线工具链

| 平台 | 当前主线 |
| --- | --- |
| Windows | VS2013、`v120`、Windows SDK 8.1、MSBuild 12.0 |
| Android | NDK r16 clang、Ant、JDK 8、Python 2.7 |
| Server | JDK 1.7/1.8、Ant |

Windows 构建 `MT3.exe` 的外部固定入口是：

```text
tools/scripts/Build-MT3-Exe-Canonical.ps1
```

该入口内部调用 `client/Build-MT3-v120.ps1`。后者是内部 ABI 安全链路，不作为日常文档的外部入口。

## 5. 生成物与维护边界

以下路径默认属于生成代码或生成产物，应回到源定义或生成入口修改：

- `server/**/xbean/*.java`
- `server/**/rpc/*.java`
- tolua++ 生成的绑定 `.cpp`（如 `client/FireClient/Application/Framework/LuaFireClient.cpp`、`LuaEngine.cpp`）
- `client/FireClient/Application/ProtoDef/**`
- `client/android/LocojoyProject/assets/res/**`

Android 业务资源应先修改 `client/resource/res/**`，再通过 `client/resource/tools/LJFilePack_打包安卓.bat` 和后续同步/构建链刷新 APK 工程资源。
