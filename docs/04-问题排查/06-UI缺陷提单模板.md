# Android与Windows客户端UI缺陷提单模板

---
**文档版本**: 1.0.0
**最后更新**: 2026-04-07
**适用范围**: Android 客户端、Windows 客户端、共享 UI 链路
**状态**: 已完成
---

## 1. 文档目的

本文档用于统一 MT3 Android 客户端与 Windows 客户端的 UI 显示类缺陷提单格式，减少测试、美术、客户端程序之间的来回补充信息成本。

适用问题包括：

- 布局错位、裁切、留白异常
- 分辨率或纵横比导致的占屏比例异常
- 字体发虚、缺字、字号和行高异常
- 位图图集、按钮、边框、图标清晰度异常
- 输入框、聊天框、键盘弹出后的遮挡或错位
- Tooltip、悬停反馈、点击命中、双击等交互差异
- UI 动画发硬、过渡不流畅、FPS 正常但体感不顺

## 2. 使用原则

- 只在 Android 出现的问题，优先补齐机型、系统版本、分辨率、导航方式、输入法信息。
- 只在 Windows 出现的问题，优先补齐显示器分辨率、系统缩放比例、窗口尺寸、是否改过 `frameSize.txt` 或 `frameResolutionSize.txt`。
- 双端都出现的问题，优先补齐同界面的 Android/Windows 对比截图，并标明是否怀疑共享 UI 链路。
- 任何 UI 问题都尽量同时提供截图和录屏；静态问题看截图，动态问题看录屏。

## 3. 标题规范

建议标题格式：

`[UI][平台][模块] 简述问题现象`

示例：

- `[UI][Android][聊天输入] 键盘弹出后输入框遮挡发送按钮`
- `[UI][Windows][背包] 150% 缩放下物品格边框发虚`
- `[UI][双端][登录界面] 选服面板在 16:10 分辨率下被裁切`

## 5. 最少取证要求

### 5.1 Android UI 问题

- 异常截图至少 1 张
- 复现录屏至少 1 段
- 机型、Android 版本、分辨率
- 是否手势导航
- 是否和键盘弹出、系统栏显示有关

### 5.2 Windows UI 问题

- 异常截图至少 1 张
- 显示器分辨率
- Windows 缩放比例
- 当前窗口大小
- 是否存在 `frameSize.txt`
- 是否存在 `frameResolutionSize.txt`

### 5.3 双端共性 UI 问题

- 同一界面的 Android/Windows 对比图各 1 张
- 问题版本和资源版本一致性说明
- 是否同一布局、字体或图集同时异常

## 6. 快速判断建议

### 6.1 更像 Android 壳层问题的特征

- 只在 Android 出现
- 与输入法、系统栏、沉浸式全屏、全面屏手势相关
- 聊天输入、命名输入、原生浮层输入框更容易复现

### 6.2 更像 Windows 壳层问题的特征

- 只在 Windows 出现
- 只在某些电脑、某个系统缩放比例或某个窗口尺寸下出现
- 清晰度、边框发虚、窗口变化后观感异常更常见

### 6.3 更像共享 UI 问题的特征

- Android 和 Windows 都能复现
- 同一界面的布局比例、字体密度、图集缩放都相近地异常
- 更换平台后问题形态一致，只是程度不同

## 8. 使用建议

- 测试提单时不要只写“UI 有问题”或“显示异常”，必须指出是布局、比例、清晰度、字体还是输入问题。
- 美术反馈问题时，尽量补一张正常设计稿或历史正确版本截图，便于区分资源问题和适配问题。
- 客户端程序接单后，先根据平台范围判断优先检查 Android 壳层、Windows 壳层还是共享 UI 链路。
