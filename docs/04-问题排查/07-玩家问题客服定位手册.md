# 玩家问题客服定位手册（2026-06-08）

> 状态：客服/QA/技术联动基线  
> 红线：工单、截图、日志、沟通记录中不得要求、记录或展示用户密码、token、cookie、session 原文。

## 1. 工单必填字段

| 字段 | 必填场景 | 说明 |
| --- | --- | --- |
| 账号 ID | 全部 | 不填密码，不填登录 token |
| 角色 ID | 入世界后问题 | 未创建角色可为空 |
| 区服 | 登录后问题 | 包含大区/服务器名 |
| 客户端版本 | 全部 | 安装包版本 |
| 资源版本 | 更新/UI/资源问题 | 热更新索引版本 |
| 平台/渠道 | 全部 | Win32/Android/iOS + 渠道 ID |
| 设备型号/系统版本 | 移动端/兼容问题 | Android/iOS 必填 |
| 订单号 | 支付问题 | 支付失败必须填写 |
| 截图/错误码 | 全部 | 玩家可见提示、错误码、时间 |
| 发生时间 | 全部 | 精确到分钟，便于查日志 |

## 2. 问题类型处理

| 类型 | 玩家侧确认 | 客服采集 | 技术定位入口 | 升级条件 |
| --- | --- | --- | --- | --- |
| 更新失败 | 是否可重试、网络类型、剩余空间 | 资源版本、错误码、截图 | `resource-ui-gate.json`、热更新/CDN 日志 | P0：大量用户无法更新 |
| 登录失败 | 账号是否可用、是否维护 | 账号ID、渠道、错误码、时间 | 登录接口日志、`LoginManager.cpp` | P0：无法登录或密码泄露风险 |
| 选服失败 | 服务器是否维护/爆满 | 区服、服务器列表版本 | `ConnectGetServerInfo.cpp`、选服日志 | P1：单区服不可进入 |
| 创建角色失败 | 名称、职业、是否重复 | 账号ID、角色名、错误码 | 创建角色协议与 Lua 日志 | P1：新用户无法创建角色 |
| 入世界失败 | 是否卡加载、是否闪退 | 角色ID、地图ID、区服、日志时间 | GameServer 连接、客户端启动日志 | P0：大面积无法入世界 |
| 支付失败 | 是否扣款、订单号 | 订单号、商品ID、支付渠道 | 支付网关/回调日志、`chargedialog.lua` | P0：扣款不到账；P1：订单创建失败 |
| UI 按钮无响应 | 具体界面/按钮 | 截图、资源版本、操作路径 | CEGUI/Lua 绑定检查 | P1：核心路径按钮不可用 |
| 战斗/地图显示异常 | 地图/战斗 ID | 截图、角色ID、地图ID、技能ID | 战斗/地图日志、资源检查 | P1：核心玩法不可完成 |
