# 跨平台 UI 交互

> **定位**：说明三端平台壳、Cocos2d-x/Nuclear、CEGUI 0.7.1、FireClient 和 Lua 的 UI 分工。
> **当前 UI 主线**：`dependencies/cegui/` 中的 MT3 定制 CEGUI 0.7.1，不是模糊的“CEGUI 0.x”。
> **文档索引**：[docs/07-参考文档/02-文档索引.md](../../07-参考文档/02-文档索引.md)

## 1. UI 分层

```text
平台窗口 / Activity / UIApplication
                 |
                 v
       Cocos2d-x 2.2.6 + Nuclear
                 |
                 v
        CEGUI 0.7.1 Cocos2D Renderer
                 |
                 v
 FireClient GameUIManager / C++ widget bridge
                 |
                 v
       Lua dialog / layout / event / protocol
```

| 层 | 主要职责 |
| --- | --- |
| 平台壳 | 窗口、GL 容器、触摸/鼠标/键盘、WebView/平台控件、生命周期。 |
| Cocos2d-x/Nuclear | 底层渲染、场景、视口、输入桥接和引擎资源。 |
| CEGUI 0.7.1 | Window、Scheme、Falagard、LookNFeel、Imageset、Font、Layout 与事件。 |
| FireClient | UI Manager、C++ 业务桥接、根窗口、游戏状态与协议分发。 |
| Lua | Dialog 生命周期、控件查找、事件处理、数据刷新与子布局加载。 |

## 2. 三端差异

| 平台 | 平台 UI 容器 | 共享游戏 UI | 关键差异 |
| --- | --- | --- | --- |
| Win32 | Win32 窗口/消息循环 | CEGUI 0.7.1 + Lua | 鼠标/键盘、窗口尺寸、DPI 和本地文件路径。 |
| Android | Activity + GLSurfaceView/Renderer + JNI | CEGUI 0.7.1 + Lua | 触摸、系统 UI、软键盘、WebView、前后台与 GL 恢复。 |
| iOS | UIApplicationDelegate + Cocos2d 视图 | CEGUI 0.7.1 + Lua | 触摸、UIKit 容器、平台 SDK 和前后台生命周期。 |

三端不各自维护一套游戏布局；共享资源真源位于 `client/resource/res/ui/` 和 `client/resource/res/script/`。

## 3. CEGUI 资源闭环

```text
Scheme
  -> FalagardMapping
  -> LookNFeel / WidgetLook
  -> Imageset / Font
  -> Layout
  -> Lua/C++ Window path
  -> Event handler
```

布局问题依此顺序取证：

1. Layout 的 `Type` / `Name` / 父子路径。
2. Scheme 是否声明对应 `FalagardMapping`。
3. LookNFeel 的 `WidgetLook` 是否存在且 XML 可解析。
4. Imageset/Font 声明和物理资源是否可读。
5. Lua `getWindow()`、`loadWindowLayout()`、事件名与 C++ 查找路径是否完全一致。

## 4. 根窗口与 Lua Dialog

[`GameUIManager.cpp`](../../../client/FireClient/Application/Manager/GameUIManager.cpp) 创建/设置 CEGUI GUISheet，业务 Lua 通过 `LuaUIManager` 和各 Dialog 管理布局实例。

关键不变量：

- `GetLayoutFileName()` 与实际 `.layout` 文件一致。
- 根窗口和子布局 nameprefix 可预测。
- 销毁时解绑事件、释放子布局和清除 Manager 引用。
- 协议回包只在 Dialog 存活且当前业务状态允许时刷新 UI。

## 5. 分辨率与坐标

[`ResolutionAdapter`](../../../client/FireClient/Application/Framework/ResolutionAdapter.cpp) 同时实现 CEGUI 和 Nuclear adapter，将物理视口映射到场景/UI 逻辑尺寸。Android 当前 UI 逻辑基线为 1080x720，`maxUiScale=2.0`；详见 [06-Android客户端UI显示比例](06-Android客户端UI显示比例.md)。

输入映射必须与显示的 logic/display/safe inset 使用同一份视口计算结果，否则会出现“看得见但点不中”。

## 6. PC Launcher UI

`client/Launcher/` 使用独立 DUI/OLE 控件链，不使用游戏 CEGUI Layout/Lua Dialog。Launcher 只负责登录前更新和启动容器，架构见 [Launcher 技术说明](../../06-工具链/06-Launcher技术说明.md)。

## 7. 变更验证

1. 入口 layout 和所有动态子 layout 可加载。
2. Scheme -> LookNFeel -> Imageset/Font 无首个解析/注册阻断。
3. Lua/C++ 控件路径查找成功，事件可达。
4. Win32 鼠标/键盘、Android/iOS 触摸在多种长宽比下命中正确。
5. 前后台、纹理重载、切场景和销毁重建后 UI 状态正确。
6. 当前 `CEGUI_ct.log` 中没有新增的首个 blocker。
