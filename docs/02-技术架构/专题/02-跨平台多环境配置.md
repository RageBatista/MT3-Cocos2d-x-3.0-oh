# 跨平台多环境配置

> **定位**：记录 MT3 客户端当前的平台 INI、用户设置、资源路径与渠道分流。
> **事实源**：`GameApplication.cpp`、`IniManager.cpp`、`FileUtil`、`DeviceInfo`、`ChannelManager` 和平台壳层。
> **文档索引**：[docs/07-参考文档/02-文档索引.md](../../07-参考文档/02-文档索引.md)

## 1. 配置层次

| 层次 | 代表资产 | 职责 |
| --- | --- | --- |
| 平台/渠道编译层 | 平台宏、Android 渠道工程、iOS target、Win32 配置 | 决定壳层、SDK 和编译时分支。 |
| 平台客户端 INI | `cfg/clientsetting_win.ini`、`clientsetting_ios.ini`、`clientsetting_android.ini` | 平台特性、服务与资源参数。 |
| 用户运行时设置 | `SystemSetting.ini` | 显示、音频、用户选项等可写配置。 |
| 文件与资源路径 | `CFileUtil`、Cocos2d-x 搜索路径 | 区分 root、cache、doc、temp、log 和资源根。 |
| 渠道运行时 | `ChannelManager` / `ChannelPlatformInterface` | 登录、支付、切换账号和 SDK 能力分流。 |

## 2. 平台 INI 选择

[`GameApplication.cpp`](../../../client/FireClient/Application/Framework/GameApplication.cpp) 依平台宏选择：

```text
WIN32   -> cfg/clientsetting_win.ini
OS_IOS  -> cfg/clientsetting_ios.ini
ANDROID -> cfg/clientsetting_android.ini
```

Android APK 中的资源可经 LJFilePack 打包后以数字名落地；业务真源仍是 `client/resource/res/**`，不手工维护 `client/android/LocojoyProject/assets/res/**` 生成物。

## 3. `SystemSetting.ini`

`IniManager` 结合 `CFileUtil::GetDocDir()` 读写用户可变设置。排障时必须区分：

- 包内或安装目录中的默认值。
- 文档/缓存目录中已持久化的用户值。
- 代码默认值和缺少配置时的回退逻辑。

修改默认配置后，旧用户的持久化文件可能仍覆盖新默认值。

## 4. 路径分流

| 路径 | 用途 | 排障关注点 |
| --- | --- | --- |
| Root | 包内/安装根 | 平台壳层和安装方式差异。 |
| Cache | 更新和可重建资源 | 版本、索引和缓存内容是否同步。 |
| Doc | 用户设置与持久数据 | 旧值覆盖、权限和写入失败。 |
| Temp | 录音、临时下载等 | 生命周期、磁盘空间和清理。 |
| Log | `mt3*.log`、`CEGUI*.log` | 先区分当前日志与 history 日志。 |

## 5. 设备与渠道

- `DeviceInfo::sGetDeviceType()` 返回编译平台/设备类型，不应被误写成运行时环境发现服务。
- `ChannelManager` 和 Android `ChannelPlatformInterface` 承接渠道 SDK 能力。
- 渠道用户标识、token 和支付参数不写入文档示例或日志。

## 6. 配置变更验证

1. 确认修改的是真源，不是 Android 资源生成目录。
2. 在 Win32、Android、iOS 分别确认选中的 INI 文件名。
3. 分别测试“首次启动无用户配置”与“存在旧 `SystemSetting.ini`”。
4. 记录 Root/Cache/Doc/Log 的实际路径，不打印敏感数据。
5. 渠道变更覆盖登录、切换账号、退出和支付回调。
