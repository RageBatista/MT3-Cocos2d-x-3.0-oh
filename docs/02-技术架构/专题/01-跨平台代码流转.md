# 跨平台代码流转

> **定位**：说明 Win32、Android、iOS 平台壳层如何进入共享 C++ 应用主链。
> **当前架构**：平台层 -> Cocos2d-x 2.2.6 -> Nuclear -> FireClient。
> **文档索引**：[docs/07-参考文档/02-文档索引.md](../../07-参考文档/02-文档索引.md)

## 1. 总体流转

```text
Win32 _tWinMain / Android JNI nativeInit / iOS UIApplicationDelegate
                              |
                              v
                    gRunGameApplication()
                              |
                              v
                 FireClient::GameApplication
                              |
             +----------------+----------------+
             |                |                |
          Nuclear       Cocos2d-x 2.2.6   CEGUI 0.7.1
             |                |                |
             +----------------+----------------+
                              |
                   Lua / Manager / Scene / Net
```

`gRunGameApplication()` 定义在 [`GameApplication.cpp`](../../../client/FireClient/Application/Framework/GameApplication.cpp)，是三端平台壳进入共享业务主链的关键边界。

## 2. 平台入口

| 平台 | 壳层入口 | 进入共享主链的位置 | 壳层职责 |
| --- | --- | --- | --- |
| Win32 | [`client/MT3Win32App/main.cpp`](../../../client/MT3Win32App/main.cpp) | `_tWinMain()` 调用 `gRunGameApplication()` | 窗口/进程、CrashDump、本地启动参数。 |
| Android | [`client/android/common/jni/main.cpp`](../../../client/android/common/jni/main.cpp) 及渠道副本 | `nativeInit()` 首次创建 GL View 后调用 | JNI、Activity/Renderer 生命周期、渠道 SDK、Breakpad。 |
| iOS | [`client/FireClient/FireClient/FireClientAppDelegate.mm`](../../../client/FireClient/FireClient/FireClientAppDelegate.mm) | AppDelegate 初始化链调用 | UIApplication 生命周期、平台 SDK、KSCrash。 |

渠道工程可复制 Android 壳层文件，但 `client/FireClient/Application/` 仍是共享业务真源。

## 3. 共享主链

`gRunGameApplication()` 之后的主要职责为：

1. 初始化文件路径、INI、日志和资源索引。
2. 初始化 Cocos2d-x 2.2.6 和 Nuclear 运行环境。
3. 注册 CEGUI 0.7.1、Lua 绑定、Manager 与业务模块。
4. 进入登录、场景、UI、网络和游戏循环。

共享应用主链的分层和启动边界见 [项目架构](../02-项目架构.md)。

## 4. 网络与协议流转

```text
Lua / FireClient 业务
        |
        v
Game::NetConnection
        |
        v
FireNet::ILoginConnection / Octets / Marshal
        |
        v
client/FireClient/Application/ProtoDef (generated)
```

Win32、Android、iOS 都编译 [`NetConnection.cpp`](../../../client/FireClient/Application/Framework/NetConnection.cpp)。协议源定义在 XML/模块定义和生成入口，`ProtoDef/**` 是生成物，不作为长期手工修改点。

详细数据模型见 [跨平台 API 接口](../../07-参考文档/API/01-跨平台API接口.md) 和 [跨平台数据传输模型](../../07-参考文档/API/02-跨平台数据传输模型.md)。

## 5. UI 流转

```text
平台输入/窗口
      -> Cocos2d-x 2.2.6 / Nuclear
      -> CEGUI 0.7.1
      -> FireClient GameUIManager
      -> Lua dialog / layout / protocol handler
```

布局、Scheme、LookNFeel、Imageset/Font 和 Lua 窗口路径必须闭环；具体边界见 [05-跨平台UI交互](05-跨平台UI交互.md)。

## 6. PC Launcher 的独立边界

`client/Launcher/` 是 Win32 独立进程，使用 DUI + HTTP/JSON + 下载/更新引擎，不经由 `gRunGameApplication()` 和游戏 ProtoDef 主链。只有在 Launcher 启动游戏 EXE 后，流程才进入本文前述的 Win32 平台壳层。

## 7. 维护规则

- 平台生命周期/JNI/ObjC++ 变更先落在平台壳层。
- 三端共享业务优先回到 `client/FireClient/Application/`。
- 基础渲染或引擎行为分别回到 `cocos2d-x-2.2.6/` 与 `engine/`。
- 协议生成物先回源定义和生成脚本。
- 修改 ABI 敏感公共接口时评估三端整链重编。
