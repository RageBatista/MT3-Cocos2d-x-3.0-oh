# 跨平台状态机

> **定位**：区分共享游戏状态、操作状态、网络生命周期和 Launcher 更新状态。
> **结论**：Win32、Android、iOS 的游戏状态主链在 `FireClient/Application` 共享；平台壳只转发生命周期和平台事件。
> **文档索引**：[docs/07-参考文档/02-文档索引.md](../../07-参考文档/02-文档索引.md)

## 1. 共享游戏状态

[`GameCommon.h`](../../../client/FireClient/Application/Common/GameCommon.h) 定义当前 `eGameState`：

| 状态 | 含义 |
| --- | --- |
| `eGameStateNull` | 未进入有效游戏状态或正在切换/重置。 |
| `eGameStateLogin` | 登录阶段。 |
| `eGameStateRunning` | 已进入主游戏运行阶段。 |
| `eGameStateBattleDemo` | 战斗录像播放。 |
| `eGameStateEditBattleAni` | 战斗动画编辑。 |

[`GameStateManager`](../../../client/FireClient/Application/Manager/GameStateManager.h) 只负责保存、设置和查询该枚举；转换条件分布在 `GameApplication`、`LoginManager`、`NetConnection` 和相关业务处理中。

```text
Null -> Login -> Running
  ^        |        |
  +--------+--------+

Null <-> BattleDemo
Null <-> EditBattleAni
```

上图只表示高层状态关系，不替代源码中的具体触发条件。

## 2. 操作与光标状态

[`GameOperateState`](../../../client/FireClient/Application/Framework/GameOperateState.h) 管理战斗内外的光标和当前操作，例如攻击、组队、交易、给予、技能、物品、保护、捕捉和指挥。

它与 `eGameState` 不是同一状态机：

- `eGameState` 描述客户端所处的高层游戏阶段。
- `eCursorState` / `eGameCursorType` 描述当前交互和光标语义。
- 退出、切场景或离开战斗时需要显式重置操作状态。

## 3. 网络生命周期

[`NetConnection`](../../../client/FireClient/Application/Framework/NetConnection.h) 实现 `FireNet::ILoginConnection`，承担连接、鉴权回调、协议分发、ping 统计和关闭。这条链与游戏状态相关，但不应虚构一套源码中不存在的通用 `NetworkStateMachine` 类。

```text
创建 NetConnection
  -> FireNet connector 建立连接
  -> 鉴权/服务器响应
  -> DispatchProtocol / DispatchLuaProtocol
  -> 进入世界条件
  -> close / error / reconnect 业务
```

具体分支以 [`NetConnection.cpp`](../../../client/FireClient/Application/Framework/NetConnection.cpp) 和 FireNet 实现为准。

## 4. 平台生命周期

| 事件 | 平台壳层职责 | 共享层影响 |
| --- | --- | --- |
| 首次创建/GL 就绪 | 创建容器并调用 `gRunGameApplication()` | 初始化共享 Manager、UI、资源和状态。 |
| 进入后台 | 暂停渲染/音频、转发通知 | 网络保活、计时器和恢复策略受影响。 |
| 回到前台 | 恢复 GL 与平台资源 | Android 可重载纹理并通知共享层。 |
| 内存告警 | 转发平台告警 | 共享缓存/资源管理执行释放策略。 |

## 5. Launcher 更新状态

PC Launcher 的 HTTP/JSON 检查、下载、校验、替换和启动游戏是独立进程的更新状态链，不与 `eGameState` 合并。详见 [Launcher 技术说明](../../06-工具链/06-Launcher技术说明.md)。

## 6. 变更规则

1. 新增高层游戏状态时，同时核对 C++、tolua 生成绑定、Lua 调用和退出/恢复路径。
2. 操作状态修改覆盖战斗内外、禁用光标和重置路径。
3. 网络处理以真实 FireNet/`NetConnection` 接口为准，不在文档中增加抽象类当作现行实现。
4. 平台恢复需验证纹理、UI、音频、网络和当前游戏状态。
