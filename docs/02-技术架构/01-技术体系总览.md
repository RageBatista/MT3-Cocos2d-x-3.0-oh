# 01-技术体系总览

> **职责**：提供 MT3 当前技术栈、主线工具链和目录边界的短入口。启动流、模块依赖和 ABI 影响见 [项目架构](./02-项目架构.md)。

## 1. 技术栈摘要

| 领域 | 当前事实 |
| --- | --- |
| 客户端业务 | C++ + Lua，业务主链位于 `client/FireClient/Application/` |
| 客户端运行时 | 平台层 -> Cocos 基础层 -> Nuclear -> FireClient；Win32 canonical 使用 Cocos2d-x 3.0-oh |
| UI | Win32 canonical 使用 CEGUI 0.7.9-r5 (`tools/CEGUI-0.7.9-r5/`)；Android/iOS 保留 0.7.1/平台兼容链 |
| Win32 | Visual Studio 2013、`v120`、Windows SDK 8.1、MSBuild 12.0 |
| Android | NDK r16 clang、Ant、JDK 8、Python 2.7；当前 free 主渠道为 `client/android/LocojoyProject/` |
| iOS | Objective-C/Objective-C++ 平台桥接 + 共享 C++ 主链 |
| 服务端 | Java、Ant、gnet/xbean，主构建入口为 `server/server/game_server/build.xml` |
| 资源 | 业务源位于 `client/resource/res/**`，Android `assets/res/**` 为生成产物 |

Lua 深度嵌入 FireClient 业务层，不作为独立的第五个运行时层。Android Java 与 iOS Objective-C/Objective-C++ 负责平台生命周期、SDK 和系统能力桥接，也不替代共享 C++ 主链。

## 2. 当前与历史 Cocos 路径

- `cocos2d-x-3.0-oh/`：Win32 `Upgrade30` canonical 基础层，与 CEGUI 0.7.9-r5、Nuclear、FireClient 组成当前升级主线；
- `cocos2d-x-2.2.6/`：Android/iOS 及历史兼容链，不能作为 Win32 `Upgrade30` 的输入；
- 历史 `cocos2d-2.0-rc2-x-2.0.1/` 在当前工作树中不存在，其旧引用仅见于历史工程文件和日期化归档记录；
- 对当前 Cocos2d-x 的修改必须保持原编码，并按对应库到下游的顺序重编。

## 4. 客户端组件关系

```text
FireClient
├── Framework / Manager：应用生命周期与业务编排
├── Battle / SceneObj：战斗与场景对象
├── GameUI / Lua：界面、脚本与交互
└── ProtoDef：协议生成结果
        ↓
Nuclear
├── IEngine / IWorld / IEnv / IQuery
└── 场景、精灵、动画、特效与渲染抽象
        ↓
Cocos2d-x 3.0-oh / audio / Box2D / extensions（Win32 Upgrade30）
        ↓
Win32 / Android / iOS
```

FireClient 的 `Framework` 与 `Manager` 互相编排，属于高耦合主链；调整公共接口或对象布局时必须评估整链重编，而不是只验证单个工程。

## 5. 服务端与生成链

`server/server/game_server/build.xml` 定义 `genrpc`、`genxdb`、`gengbeans` 和 `dist` 等目标。协议、XBean/XDB 和策划配置相关变更应先修改源定义，再执行对应生成目标。

当前 `server/server/` 的直接子目录包括：

```text
common, game_server, game_server_f, gate_server, name_server,
proxy_server, sdk_server, spirit_server, trans_server, web_app, zone_server
```

## 6. Windows 构建入口

- 外部固定入口：`tools/scripts/Build-MT3-Exe-Canonical.ps1`
- 内部构建链：`client/Build-MT3-v120.ps1`
- 环境检查：`tools/scripts/Check-v120Toolset.ps1`
- Debug + Release 里程碑验证：`tools/scripts/Build-MT3-FullValidation.ps1`

`Build-MT3-Exe-Canonical.ps1` 会完成环境收敛、源码 NUL 检查、v120 预检、链接依赖补齐、Git LFS 指针检查，并调用内部链构建 `MT3.exe`。

## 7. 事实与维护边界

以下说法不应再作为当前事实：

- 把 Cocos2d-x 2.2.6 写成 Win32 `Upgrade30` 当前输入；
- 把 `client/Build-MT3-v120.ps1` 写成外部统一入口；
- 把 Android 主线写成 NDK r10e/GCC、Gradle 或新 JDK；
- 把第一方 `.lib` 误写成不可修改源码；
- 把 `xbean`、`rpc`、`tolua++`、`ProtoDef` 生成结果当长期手写源；
- 直接修改 `client/android/LocojoyProject/assets/res/**`。

工程文件、源码、构建脚本和已验证输出优先于历史文档。
